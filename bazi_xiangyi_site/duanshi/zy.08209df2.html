一、常识：职业是怎么回事

1.1 职业大类

《中华人民共和国职业分类大典》（2022 年版）把职业分成八个大类：

大类包括
一党的机关、国家机关、群众团体和社会组织、企事业单位负责人
二专业技术人员（医生、教师、工程师、律师、会计、艺术工作者……）
三办事人员和有关人员（行政、文秘、保卫……）
四社会生产服务和生活服务人员（销售、餐饮、运输、快递、美容理发、保安……）
五农、林、牧、渔业生产及辅助人员
六生产制造及有关人员（工人、技工）
七军队人员
八不便分类的其他从业人员

1.2 就业的几种形式

形式特点
体制内公务员、事业编（学校、医院）、国企——稳定、有级别
私企、外企打工拿工资，流动性大
自己当老板个体户、开公司
自由职业设计、写作、咨询、主播，按单子挣钱
灵活就业外卖、网约车、快递——按件按单
务农种地、养殖
兼职、副业一份正职之外再挣一份

1.3 一份工作要分几层看

说一个人做什么，其实有好几层：

层例
行业金融、教育、医疗、建筑、餐饮、运输……
单位银行、学校、医院、工地、饭店……
岗位同在银行：柜员、信贷、会计、行长、保安、司机
层级普通员工、主管、负责人
收入方式工资、提成、分红、按件
稳不稳铁饭碗、合同工、常换工作

⭐ 跟断命有关的一点：老师给的定职业示范正好是一层层往下缩——定行业 → 缩范围 → 定职位（见 2.2）。说金融还不够，要说银行里管放贷的。

1.4 工作的变动

换工作、跳槽、失业、下岗、调动、退休、创业、转行——一辈子做好几个行当在现在很常见。

2.2 三步定职业

⭐ 面授的完整示范（题758邮政局领导）：先由乙＝传播、庚与酉＝印＝书信资料定出传播类；再用庚申为马星把它从电视台、出版社缩到邮政；最后用庚申酉都入了我坐下的丑库，由我统一控制定出是领导。2012 面授 p91–96

  第一步  定行业：用十神组合或象，定出大方向（传播类）
  第二步  缩范围：再找一个象，在同类里挑出具体的（马星 ⇒ 邮政）
  第三步  定职位：看是不是我控制、在不在主位（入我坐下库 ⇒ 领导）

对照常识 1.3：正好对上行业 → 单位 → 层级。

八字里没有那样东西，就去抓它的源头中级班 p6：

八字无财，伤食当财看，印主权，是中央银行行长……食为财之源，八字不见财，需抓其源，故命主是管银行与财政的官，曾任财政部长。

五、断之前先问清

先问为什么不问会错在哪
现在做什么、做过什么定职业最难，先拿已知的校准（老师：先点两件事校准）一上来就断行业，断错了后面全不信
体制内还是外面？2.3：官印相生、在单位做事、上班族、老板各有样子把国企经理断成个体户
老家、在哪里工作？老师：要注意地方风俗环境山区和城市同一个象落成不同行当
问的是哪件事：适合做什么？要不要换？两个选择哪个好？2.6：择业看两个字活不活只说行业，不回答他真正想问的换不换
学的什么专业学业篇：专业方向和职业常常相连学医的断成做生意
问的是谁太极点不同孩子的职业断到本人盘上

六、读完这一篇，你能断什么

  1. 三条路径：十神组合、象、职业歌（口诀会失灵）。
  2. 三步定职业：定行业 → 缩范围 → 定职位。
  3. 体制内还是外面：官印相生；食伤在年是单位、在日时是企业；禄合官只表有工作。
  4. 行业取象：公检法、金融、医疗、教育、媒体、技术、服务、运输、体力、农业、宗教各有命例。
  5. 体力、技术、智力、口才。
  6. 稳不稳、换不换：禄被冲、伏吟、穿；两个行业看各自的字活不活。

还断不了的（资料未讲）：互联网、主播等新职业的专门象；六壬专门占职业的一门；什么时候换工作（只能借大运流年的一般规则）。
