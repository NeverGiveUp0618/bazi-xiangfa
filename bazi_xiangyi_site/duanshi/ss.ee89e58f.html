一、常识：官司是怎么回事

1.1 三种官司

种类是什么谁和谁打例子
民事平等的人之间的纠纷个人、公司之间欠钱不还、合同纠纷、离婚、继承、房产、劳动争议、交通事故赔偿
刑事国家追究犯罪检察院代表国家起诉被告人盗窃、诈骗、抢劫、伤害、杀人、贪污受贿、非法集资、交通肇事
行政告政府个人、公司告行政机关不服罚款、拆迁、吊销执照

⭐ 跟断命有关的一点：资料里的官司多数是刑事（牢狱），也有民事（讨债官司、财产官司）。先分清是哪一种，才知道该看输赢还是看坐不坐牢。

1.2 民事官司怎么走

  起诉 → 法院立案 → （调解）→ 开庭 → 一审判决
          → 不服可上诉 → 二审判决（二审终审）→ 申请强制执行
  • 赢了不等于拿到钱：对方没钱或转移财产，判了也执行不到。
  • 很多纠纷在调解阶段就和解了。

1.3 刑事案怎么走

  犯事 → 被发现、立案 → 公安侦查（刑事拘留 → 逮捕 或 取保候审）
       → 检察院审查起诉 → 法院审判 → 判决 → 执行（进监狱）
       → 服刑中可能减刑、假释 → 刑满释放
环节要点
刑事拘留人先被关进看守所；一般最长 30 多天，要么转逮捕，要么放人或取保
取保候审交保证金或找保证人，人先放出来等审判
逮捕继续关押等起诉、审判
职务犯罪公职人员涉嫌贪腐，由监察委留置调查，再移送检察院
判决有罪或无罪

⭐ 跟断命有关的一点：资料专门说『犯事』与『被抓』是两件事——有人犯事多年抓不到，有人一犯就被抓。现实里也是这样：很多案子要过很久才被发现。

1.4 刑罚有哪几种

刑罚是什么
管制不关押，在社区里限制自由
拘役短期关押（一个月到六个月）
有期徒刑六个月到十五年；几罪并罚最高可到二十年或二十五年
无期徒刑关押终身（服刑表现好可以减刑）
死刑包括死刑立即执行、死刑缓期两年执行（死缓）
附加刑罚金、没收财产、剥夺政治权利
后续是什么
缓刑判了刑但暂不执行（拘役、三年以下有期徒刑才可能），考验期内不再犯就不用坐牢
减刑服刑期间表现好，刑期减少
假释服刑到一定程度，提前有条件放出

⭐ 跟断命有关的一点：资料里的取数案例正好走了这一整条：判 9 年 → 减到 7 → 减到 4 → 缓刑 3 年必须花钱（题511）；还有无期变有期死刑住了不到一年——每一层在盘上都有来处。

1.5 常见罪名和起因

起因常见罪名
为钱盗窃、诈骗、抢劫、贪污、受贿、职务侵占、非法集资
冲动、打斗故意伤害、聚众斗殴、故意杀人

三、六壬怎么看（出自《大六壬通解》）

六壬是一事一课：问的是这一场官司谁赢谁输、会不会有事。

3.1 主线：日辰分主客、官鬼断输赢

占讼日辰分主客，课传官鬼断输赢。
日为客，辰为主；先动为客，后动为主。
日上有鬼不利客，支上有鬼不利主。发用克日客输，克支主输。通解上 p242｜PDF p257

情形断
日上有鬼不利客（先动的那方）
支上有鬼不利主
发用克日客输
发用克支主输

对照常识 1.2：先动为客＝原告（起诉的一方）；后动为主＝被告。定主客先问谁先起诉。

3.2 其余要点

子孙制鬼患有救，父母化官祸无伤……朱勾克日莫兴词，妄举轻为自投死。二将若也生日干，勘官昭雪人欣喜。虎头蛇尾祸不凶，雀入勾乡讼为最。通解上 p242｜PDF p257

见到断对照常识
子孙制鬼患有救有人帮忙、有转机
父母化官祸无伤—
朱雀、勾陈克日别打这个官司——妄举轻为自投死劝人和解、别起诉
朱、勾生日干勘官昭雪冤情得到平反
雀入勾乡讼事最重拖得久、闹得大
虎头蛇尾祸不凶雷声大雨点小

占词讼，最爱天空发用及终传，主讼解、谋不成。若求财物，又深忌之。通解上 p107｜PDF p122——天空让事情落空，占讼时＝官司散了（好事），占财时＝财没了（坏事）。

六、读完这一篇，你能断什么

  1. 会不会犯事：牢灾门歌诀、阴坏阳、食伤＝自由、倒象。
  2. 为什么犯：为财、为色、打架、团伙、贪污、被连累。
  3. 犯事和被抓分开断：穿＝抓不到，官来合＝官方来找。
  4. 关在哪：丑是牢房，辰是医院。
  5. 判多久：晦轻于穿破；官杀两头＝无期；取数七步。
  6. 怎么化解：破财免灾。
  7. 六壬断这一场官司：先动为客，日上有鬼客输、支上有鬼主输；朱勾克日别起诉。
