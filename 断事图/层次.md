# 断事图 · 层次：这个人在社会上大概在哪一档——钱、官、学历、职业的尺子

> **为什么要这一篇**：老师说过，**算不了认知以外的命**。「这个命好」「层次高」落到现实里，到底是县城开店的小老板，还是上市公司董事长？是科员还是厅长？不先知道社会上有哪几档、每档大概什么样，盘上看出「做功效率高」，你说不出**具体是哪一档**。资料讲得很清楚：「**原局定层次**」〔初级班 p51〕，「甚至一生能当到多大的官或赚到多少钱，都在原命局中有显示」〔第1章〕。
>
> **这一篇和别篇的分工**：「财运」「公司经营」讲钱，「官职」讲官，「学业」讲学历，「职业」讲行业——这一篇**把四把尺子放在一起**，讲怎么定档、各档之间怎么换算、不要混。
>
> **这一篇分四部分**：
> **一、常识**：社会上的几把尺子：钱、官、学历、职业、城乡（这部分是常识，不是命理规则）
> **二、八字怎么定层次**：总纲 → 两把尺子（宫位定上限、做功定实得）→ 清纯 → 象法定层次 → 几条别混（出自资料，逐条带出处）
> **三、速查表**
> **四、断之前先问清**
>
> ⚠️ **读法**：第一部分是常识，数字是**大致**的，随地方和年代变；第二部分只用老师资料，逐条带出处，资料没讲的写明。

## 一、常识：社会上的几把尺子

### 1.1 钱（家产、资产）

| 档 | 大致资产 | 现实里多是 |
|---|---|---|
| 贫困 | 负债或几乎没有 | 低保户、欠债的人 |
| 普通 | 几万到几十万 | 打工的、普通上班族 |
| 小康 | 几十万到几百万（含房） | 有房有车的工薪家庭、小店主 |
| 富 | 几百万到几千万 | 中小老板、高管、专业人士 |
| 大富 | 几千万到几亿 | 企业主、上市公司高管 |
| 巨富 | 几十亿以上 | 大企业家 |

⚠️ **房子算不算**：资料的口径是「**财＝一切可归自身、自由支配的资产**（房产土地都算）；数字按时代调整，方法不变」〔公开课课时笔记3 p3〕。

### 1.2 官（体制内级别）

科员 → **科级**（科长、乡镇长）→ **处级**（县长、县委书记、市里的局长）→ **厅级**（市长、市委书记、省里的厅长）→ **省部级** → 国家级。详见「官职」篇一。

⚠️ **有级别≠有权**：很多人只有职级、没有领导职务；国企、事业单位另有一套「参照级别」。

### 1.3 学历

初中及以下 → 高中、中专 → 大专 → 本科（普通／重点）→ 硕士 → 博士。详见「学业」篇一。

### 1.4 职业的社会位置（大致）

| 档 | 例子 |
|---|---|
| 体力劳动 | 工人、搬运、农民、外卖 |
| 技术、技能 | 技工、司机、厨师、修车 |
| 一般白领 | 文员、销售、会计 |
| 专业人员 | 医生、律师、教师、工程师 |
| 管理者 | 经理、主管、公务员领导 |
| 老板、企业主 | 小老板到大企业家 |

### 1.5 城乡和地域

同样是「富」，县城和一线城市差一个量级；同样是「当官」，村干部和市里的局长不是一回事。**来问的人在哪儿，尺子就要按哪儿调**。

### 1.6 四把尺子不一定一致

| 常见情况 | 例子 |
|---|---|
| 学历高、收入一般 | 博士在高校拿死工资 |
| 学历低、很有钱 | 初中毕业的老板 |
| 官大、不算富 | 清廉的处长 |
| 有钱、没地位 | 暴发户 |

⭐ **跟断命有关的一点**：资料里正好有这一条——「**学历仅是一个名而已，不表财富能力、也不表权利、地位**」〔面授 p98〕。**四把尺子分开量**。

## 二、八字怎么定层次（出自资料）

### 2.1 总纲

| 原话 | 出处 |
|---|---|
| 「一般来讲，**原局定层次，大运定吉凶，流年定应期**。」 | 初级班 p51 |
| 「人生的层次等级及重大事情，**都在八字原命局中有显示**……甚至一生能当到多大的官或赚到多少钱」 | 第1章 |
| 「**制/做功**——谁制住了谁——**定层次高低**」；它是「判断层次高低的**唯一刻度**」 | 第1章 |
| 「何知其人富，财气通门户；何知其人贵，官星有理会」——「这话不错，但**命里有财星，这个财不一定是你的**……**得到了才属于你**」 | 小任 · 公开课第2课 |

### 2.2 两把尺子：宫位定上限，做功定实得

> 「**宫位定上限，做功定实得**，两把尺子不冲突。」〔第4章七·D③〕

**尺子一：宫位定「池子」**（年 ＞ 月 ＞ 日 ＞ 时：**年月主大，日时主小**）〔公开课课时笔记3 p3–4；初中级课时笔记3 p5〕

| 宫位 | 财富（现今社会） | 官位 |
|---|---|---|
| 时柱 | 十万、百万——大概率难破千万 | 科级 |
| 日柱 | 百万、千万 | 处级 |
| 月柱 | 正常千万，搞好上亿——「千万的苗子」 | 厅级 |
| 年柱 | 起步千万，正常上亿，可到百亿千亿 | 省部级、中央级 |

⚠️ 「宫位只定池子，**最终看财官得到没有、被不被穿冲耗**：年上的财被穿跑了就顺延看别柱，落到时柱就只是小康」〔公开课课时笔记3 p4〕；「**年柱的财大，但不一定是你的**」〔v课 677 讲【题390】〕。

**尺子二：做功定「实得」**

| 维度 | 原话 | 出处 |
|---|---|---|
| **钱** | 财星本身＝小财；制尽、制财和财源、制财库＝大财（**起步百万级**，做功能量大可达千万到亿级）；官杀当财＝财富级别很高 | 面授 p64–65；财运篇 p3、p4 |
| **官** | 「**一次功是科级，二次功是处级，三次级是厅级**」；制官与官的元神或墓库为大官 | 面授 p59【题682】；v课 825 讲 |
| **效率** | 申寅冲制印（效率高）⇒ 元朝丞相；午克酉制印（力小）⇒ **开出租车糊口** | 第13章七 |
| 做功效率不高 | 「是个**工薪取财**的命」 | 财运篇 p12 |

### 2.3 清纯：同样成格，层次差在哪

> 「命中五行分清浊，八字格局看杂纯。**纯粹轻清定富贵，驳杂重浊主夭贫**。命局五行都有度，**过多都以凶事论**——**财多是灾不叫财，官多是病不为官**。」（**清就是目标，明确无杂质**）〔第5章五〕

| 现象 | 层次 | 出处 |
|---|---|---|
| 「天干不同为夹（次一点），**天干同为拱（层次好）**」 | — | 十二道门法 第八门 |
| 「**禄印得用多厚禄**」；「**禄为喜被坏，表层次低贱**」 | — | 讲义例（第6章） |
| 食神只克不制官、克掉自己最喜的 ⇒ **倒象，没有层次**——普通农民 | — | 小任 · 公开课第4课 |
| 戌月火库冲克金库 ⇒ 坏根 ⇒ **格局低**（公司最基层打工） | — | 小任 · 初中级第17课 |
| 「源头还有源头，这种命大概率差不了」 | — | 小任 · 初中级第11课 |

### 2.4 象法也能定层次

> 「此命如果**从做功的角度来分析，就一无是处**……**但从象的角度来分析却大有玄机**」——辰墓表示一个巨大的财富集团，日主控制住了庚辰一柱 ⇒ **上市公司董事长，掌管数十亿**〔财运篇 p6〕

⭐ 「**做功路线走不通，象法可以单独定层次**」〔第13章三〕；「**带象可以直接定层次**」（康熙命例）〔第6章〕。

### 2.5 几条别混（对照常识 1.6）

| 别混 | 原话 | 出处 |
|---|---|---|
| **学历 ≠ 富贵** | 「学历仅是一个名而已，**不表财富能力、也不表权利、地位**」 | 面授 p98【题760】 |
| **官 ≠ 财** | 「**当财看了，就不作官贵看**」（互斥） | 第13章一·B③ |
| **大 ≠ 是你的** | 年柱的财大，但不一定是你的 | 【题390】 |
| **名气 ≠ 职务** | 「官杀虚透表示名气（**不表职务**）」；「不通根仅有虚名」 | 官运篇②；面授② |
| **有官职 ≠ 有实权** | 「官印通根可以表示实权」「虚透为虚职」 | v课 825 讲 |
| **同级不同权** | 「此人管的村没有上例的村庄大……**职务一样权力不一样**」 | 例题解 p16 |

## 三、速查表：盘上的样子 → 大概哪一档

| 盘上 | 钱 | 官 | 出处 |
|---|---|---|---|
| 做功效率不高、只是克制 | 工薪 | 无 | 财运篇 p12 |
| 比劫禄做功大 | 体力劳动 | — | 中级班 p32 |
| 财在时柱且到手 | 十万到百万 | 科级上限 | 宫位尺 |
| 一次功 | — | 科级 | 面授 p59 |
| 制财和财源、制财库 | 起步百万 | — | 面授 p64–65 |
| 二次功 | — | 处级 | 面授 p59 |
| 财在月柱且到手 | 千万苗子 | 厅级上限 | 宫位尺 |
| 三次功、制库 | — | 厅级 | 面授 p59；【题688】 |
| 食伤官杀两透、干不透财 | 大富 | — | v课 779 讲 |
| 年柱财、制尽、合回主位 | 上亿 | 省部级上限 | 宫位尺 |

⚠️ **资料未讲**：四次功、五次功是不是部级（见「官职」篇）；学历和职业怎么跟钱、官换算（资料只说「不要连」）。

## 四、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **在哪个城市、城里还是农村** | 1.5：尺子随地方变 | 县城的富说成一线城市的富 |
| **现在做什么、到什么位置** | 用反馈定原局读法 | 拿上限当实得 |
| **问的是钱、官、还是名** | 2.5：四把尺子分开量 | 把名气断成官职，把学历断成富贵 |
| **家里底子** | 祖业、父母给的 | 把家底算成本人的 |

⭐ 小任的话：「**八字即生活**：断出来跟生活不符就是错了」〔初中级第7课〕——断出「上亿」的人在出租屋里住，就回头查是不是**财没到手**、**看错了宫**。

## 五、读完这一篇，你能做什么

1. 知道**原局定层次**，层次的刻度是**做功**。
2. 会用**两把尺子**：宫位定上限（年＞月＞日＞时），做功定实得（几次功、制到哪层）。
3. 会看**清纯**、会用**象法**定层次。
4. **四把尺子分开量**：学历、官、钱、名气不互相推。

**资料未讲**：部级以上的判据；学历、职业与钱、官的换算。
