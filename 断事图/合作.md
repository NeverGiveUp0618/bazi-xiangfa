# 断事图 · 合作：找人合伙、谈生意、签合同、托人办事——成不成、对方靠不靠得住

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「这个合作能不能做」在现实里要分几层：**人靠不靠得住**、**条件谈不谈得拢**、**合同签不签得下**、**签了以后会不会扯皮**。不先知道合作一般怎么走、在哪一步出事，盘上看出「合」，你只能说「能成」，说不出会在哪一步翻脸。
>
> **这一篇和别篇的分工**：「兄弟朋友」讲合伙人是谁、比劫是一伙还是外人；「公司经营」讲合伙开公司；「官司」讲闹上法庭以后。这一篇讲**一次合作从谈到签到履行**，以六壬为主（六壬就是占「这一件事」的）。
>
> **这一篇分五部分**：
> **一、常识**：合作的几种、一般怎么走、常在哪一步出事（这部分是常识，不是命理规则）
> **二、六壬怎么看**（本篇主角，出自《大六壬通解》与毕法赋课例）
> **三、八字怎么对上**：这个人适不适合合伙、对方人品
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是常识；第二、三部分只用老师资料，逐条带出处；资料没讲的写明。

## 一、常识：合作是怎么回事

### 1.1 合作的几种

| 种类 | 样子 |
|---|---|
| **合伙** | 一起出钱出力、一起分利 |
| **买卖、交易** | 一次性的买和卖 |
| **供货、代理、加盟** | 长期供应关系 |
| **投资入股** | 出钱不出力 |
| **托人办事** | 求人帮忙、找关系 |
| **雇佣、外包** | 请人干活 |

### 1.2 一般怎么走

1. **接触**：认识、介绍
2. **谈判**：谈价格、分成、责任
3. **签合同**：白纸黑字
4. **履行**：交货、付款、干活
5. **结束**：结清，或续约，或散伙

### 1.3 常在哪一步出事

| 哪一步 | 常见问题 |
|---|---|
| 接触 | 对方身份是假的、夸大实力 |
| 谈判 | **谈崩**、反复变卦、互相压价 |
| 签合同 | 合同有坑、**口头约定没写进去**、手续办不下来 |
| 履行 | 不付款、不交货、偷工减料、**私吞**、账目不清 |
| 散伙 | 分钱分不清、**闹上法庭** |

⭐ **跟断命有关的一点**：六壬的「交车」一组格，正好把这几种结局分开了——**以财成交、各怀异心、笑里藏刀、顶牛反复、暗藏私弊、明争暗斗**（见 2.3）。

## 二、六壬怎么看（出自《大六壬通解》）

### 2.1 先分清谁是谁

> 「**占谋事求财，干为我，支为我所求之人**……故每一课演成，**先省察干支上神，心中便有把握，然后详观三传，则事之始终定矣**。」〔通解上 p131｜PDF p146〕

| 位置 | 代表 |
|---|---|
| **日干** | 我 |
| **日支** | 对方（我所求之人） |
| 三传 | 事情的始、中、终 |

### 2.2 两家关系：日辰生克

〔通解上 p131｜PDF p146〕

| 情形 | 断 |
|---|---|
| **日辰各受上神生** | **两家顺利有生意** |
| **日辰各受上神克** | **两家俱伤都不利** |
| 日上脱辰／辰上脱日 | 我脱他／他脱我；各受上神脱则**彼此防脱俱蹉跎** |
| **日辰互见刑害** | **宾主不投怀猜忌** |
| 辰临日上来生日 | **彼自上门来周济** |
| 日临辰上去克辰 | 事虽费力**得财** |
| 日辰乘墓坐墓 | 俱主昏迷云雾中 |
| 「干支如果互相加临而相生，则**彼此皆利**；如果**初传是支发用、末传归于干上，乃彼求我**，求谋大利」 | 通解上 p239-240 |

### 2.3 ⭐ 交车一组：合作的六种结局（对照常识 1.3）

| 课例 | 格 | 断 |
|---|---|---|
| ⭐ 例111 | 交车合财 | **以财成交**，买卖得利 |
| 例6 | 交车合财 | 双方各带一份财，宜合作求财；**中途手续与分账须落实** |
| ⭐ 例113 | 交车三合 | **处处相合**，买卖成交得助 |
| ⭐ 例112 | 交车脱 | **各怀异心**，貌合神离、各自算计，防吃暗亏 |
| 例105 | 交车害 | **表面合作、暗里互害**，不宜合作 |
| 例106 | 交车克 | **笑里藏刀**，合作必起争讼 |
| 例107 | 交车冲 | **你顶我、我顶你**，交易反复难安 |
| 例108 | 三交 | **暗藏私弊**，合作有奸私 |
| 例109 | 交车刑 | 和气里忽然较劲，明争暗斗 |

⭐ **一句话**：干支交互**合**＝成；交互**害、克、冲、刑、脱**＝各有各的坏法。

## 三、八字怎么对上

> 八字不占「这一次」，看的是**这个人适不适合合伙**、**对方人品**。

| 现实 | 盘上 | 出处 |
|---|---|---|
| ⭐ **测合伙对象人品** | 杀伏吟出尔反尔——「**与此命合作，一不会长久，二会为利益有争，还是别合作为好**」 | 例题解 p18-19【题70】 |
| **不能合伙** | 「年上癸卯是合伙者、**来破午财 ⇒ 不能合伙**」；「**亥巳冲 ⇒ 不可以合伙求财**」 | 【题671】【题694】 |
| 比劫连体时合伙 | 劫财合财＝**帮我合财**（团队分润），不能断成别人夺财 | 讲义 p229 |
| 比劫不连体 | 比劫多＝分夺；「主位临财外遇劫，防偷防骗」 | 小任 |
| 双方各有财 | 「交车合财」那类的八字版资料未讲 | — |
| ⭐ **手续、文书** | 「**印＝手续/文书**」，印空 ⇒ **手续没办下来**；「**空的用法是虚而未实，不一定是凶**」 | 【题51】 |
| **中介** | 伤官在时上主口才、寅戌拱火为财，「**但寅空，意为空买空卖之意**，故为中介」 | 【题56】 |
| 很会与领导搞关系 | 卯申暗合 | 【题633】 |
| 三人合伙 | 开砖厂 | 【题20】 |
| 合伙抢劫 | 比劫库、阴包阳 | 【题734】 |

⚠️ **资料未讲**：八字里「签合同」「谈判」的专门象；两个人的八字怎么合看（合婚以外）。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **什么样的合作**：合伙、买卖、托人？ | 1.1：类神不同（财、六合、贵人） | 托人办事当成买卖看 |
| **走到哪一步了** | 1.2：谈判、签约、履行，问的事不同 | 已经签了还断「谈不成」 |
| **对方是谁、有没有对方生辰** | 八字可测对方人品（【题70】） | — |
| **钱怎么分、谁管账** | 例6「中途手续与分账须落实」 | 漏掉最容易出事的环节 |

## 六、读完这一篇，你能断什么

1. 六壬**干为我、支为对方**；日辰各受生＝两家顺，各受克＝两家伤，互见刑害＝猜忌。
2. **交车一组**：合＝成交，脱＝异心，害＝暗害，克＝争讼，冲＝反复，三交＝私弊，刑＝明争暗斗。
3. 成不成看**六合**，谁主动看**干支相会**，文书看**朱雀**。
4. 托人办事：例165 所托之人可能骗你。
5. 八字：测对方人品、能不能合伙；**印空＝手续没办下来**。

**还断不了的**（资料未讲）：八字的签约、谈判专门象；两个人的八字怎么合看做生意。
