# 断事图 · 求人办事：见不见得到、事成不成、会不会被忽悠

> **为什么从常识讲起**：「求人办事」在现实里就是**托关系、见领导、投材料、等批复、拜访人**。成不成，多半看**对方有没有这个能力和意愿**、**材料和理由站不站得住**，不是看盘。六壬把这一类叫「**干谒**」「**谋望**」「**信息**」，原书里的案例都是**古人求官、谒贵、投呈、等文书**，换成现在就是找人办事、等审批、等回复。
>
> **这一篇分五部分**：
> **一、常识**：求人这件事的几种情况，怎样才算「求得成」
> **二、六壬怎么看**（本篇的主角）：我去见人还是他来找我 → 见不见得到 → 成不成 → 会不会被忽悠 → 什么时候有消息（全部出自《大六壬通解》，逐条带出处）
> **三、八字怎么对上**：不对应
> **四、案例**
> **五、开盘确认与先断后验**
>
> ⚠️ **读法**：第一部分是常识；第二、四部分只用老师资料，**资料没讲到的写明「资料未讲」**。案例出处统一写成〔案例库编号｜OCR页码〕，可在六壬神课站的「大六壬通解案例库」里按编号查原文。
>
> ⭐ 这一篇**只有六壬**：求人办事是一事一课，问的就是「这一次见不见得到、成不成」。

## 一、常识：求人这件事

### 1.1 求人的几种情形

| 情形 | 现实里 | 成不成多半看 |
|---|---|---|
| **见人**（约领导、约老师、约客户） | 对方不一定有空，常常要等 | 对方日程，你有没有引荐人 |
| **托人办事**（找关系办手续、进单位、找门路） | 最常见 | 中间人的分量，办事人愿不愿意 |
| **投材料、等批复**（申请、报批、投简历、等审批） | 看程序 | 材料是否合规，有没有人在里面说话 |
| **等消息**（等录取通知、等回复、等对方表态） | 最熬人 | 对方的时间表 |
| **挽回**（事情已经坏了，再托人补救） | 难 | 坏事的原因还在不在 |

### 1.2 现实里的两个提醒

1. **求人花钱要有数**：原书里不少课例都落在「钱花了，人也没办成」。这与盘无关，是常识：先问清**办什么事、谁能办、多少成本**，再决定要不要求。
2. **被忽悠的情况不少**：说能办、收了钱、没下文。原书有一条专讲这个（见 2.5）。

## 二、六壬怎么看（出自《大六壬通解》）

### 2.1 第一步：谁求谁——宾主

> 「在预测中要根据动静法则，注意区分主客，譬如**我去见人，以干为我，以支为他，他为主，我为宾**。如果**他来见我，他来找我，以干为他，以支为我**，此时，他为宾，我为主。」〔通解上 p132｜PDF p147〕

| 情况 | 日干代表 | 日支（辰）代表 |
|---|---|---|
| **我去见他**（求人） | 我（宾） | 他（主） |
| **他来找我** | 他（宾） | 我（主） |

⭐ **先定谁是我、谁是他**，后面的生克才不会反过来读。

### 2.2 第二步：尊卑与动静

> 「六壬中，**日尊辰卑**，干加支，就是以尊就卑。」〔通解上 p132｜PDF p147〕

| 盘上 | 断 |
|---|---|
| **干加支克支**（残下） | 我克者为财，有「**就地取财**」之义 |
| **干加支受支克**（乱首） | **自取其克** |
| 干支同类 | 互相帮比，好比培元固本 |
| 干受支生（日俯就） | 初历艰难，终受逸乐 |
| **支加干**（卑见尊） | 支来克干＝**上门乱首**，下犯上；支来生干＝**自在**，坐享其成 |
| 干去生支（求受） | 反竭我力而生他 |

**内外动静**〔通解上 p131–132｜PDF p146–147〕：

- 「干加支人归宅，支加干出难寻」。**干加支**：占人必至，访人必见，利静利人，利内事，不利动出；**支加干**：占人不来访，**访人不在**，利动利出外事，忌静。
- PDF p146 的日辰歌诀：「**日临辰上去受生**……」一组八句，断日辰相临谁生谁克，谁得财谁耗财；「**宾主不投怀猜忌，日辰互见害与刑**」；「**若见卯酉为阻隔，鬼罡蛇虎有伤折**」。

### 2.3 第三步：见不见得到、成不成

原书专有一章「**趋谒章**」，全是口诀，**原书没有逐句注解**，这里照录并只摘能对上案例的几句：

> 「**干谒之利三六合，彼我两仪欲相洽。六阳公事和谐看，六阴私谋素亲狎。舍益就损忌动用，根断源消防耗失。逼迫旺禄守旧宜，周遍循环所求得。初空未吉终有获，首上尾加干何益。度亥塞鬼二者推，有阻无阻此处绎。引从告谒往必唔，任信寻访必难谐。二贵合害分轻重，六亲生克吉凶排。日德阴神见长短，末传合处是成期。斫轮空亡须图改，昴星蛇虎安旧宜。**」〔通解上 p236｜PDF p251〕

| 摘句 | 意思（依案例对照） |
|---|---|
| **三六合** | 课里有三合、六合，有利于干谒 |
| **六阳公事和谐看，六阴私谋素亲狎** | 阳课宜公事，阴课宜私下 |
| **末传合处是成期** | 成事的日子看末传所合之处 |
| **度亥塞鬼二者推** | 有无阻碍看**河魁度亥**（魁度天门）和**鬼**塞不塞 |

⚠️ 其余句子**资料未讲，不解释**。

**可以对上案例的几条外加规则**：

| 盘上 | 断 | 案例 |
|---|---|---|
| **日辰上各见德神，再乘吉将** | 进发真，有成 | — |
| **发用空亡，传入贵人** | 有贵人来，事情被贵人的事打断 | 案例四（访僧） |
| **贵人空亡**，三传三合木局，夏令木休囚 | 求贵人办事**不成** | 案例六 |
| **本命行年逢空** | 前几次见不到，空过之后才见 | 案例八 |
| 鬼墓（暗鬼）：甲乙日丑，丙丁日辰，戊己日未，庚辛日戌，壬癸日辰 | **暗鬼**，要防 | 日辰歌诀脚注 |

### 2.4 第四步：什么时候有消息

**占文书信息，类神是朱雀**〔案例库 366｜OCR p208–209〕：

> 「**一般占时逢雀、丙、丁、巳、午，专主文书、信息、请乞类事，如发用或临命更验。**」「**巳午乘贵雀龙常，占文书必应。**」

| 盘上 | 断 |
|---|---|
| **朱雀** | 文书、信息的类神 |
| 朱雀临门 / 朱雀腾空 | 文字到 |
| **雀马合处、发用绝处** | 定文书之期：「**请问文书何日降，朱禽合日求马上，合起绝处用为真，不见逢空休请望**」 |
| **天罡作天后加支干** | **衣物送来**（特殊断法） |
| **昴星课，朱雀临门** | 文字**立至**；子卯相刑，来得快（案例库 370） |
| 求官望榜：**课传俱马，乘青龙作官星，天罡加支** | 榜至，且快（案例库 368） |
| **月建**主州府文字 | 公文看月建（案例库 369） |

### 2.5 第五步：会不会被忽悠

> 「凡占谋望最怕遇到坏人、诳语，古人曰：『**阴空蛇虎魁罡立，五者相逢必诳人**』。」〔案例库 380 书中讲解〕

五个字：**太阴、天空、螣蛇、白虎、魁罡**，五者同时出现，主有人说假话。

**谋望总诀**〔案例库 377 书中讲解〕：

> 「**谋望先须看类神，合神有气必成功。切忌刑冲并破害，成神不入枉劳功。**」

| 盘上 | 断 |
|---|---|
| 类神出现，合神**有气** | 成 |
| 合神**无气**、被刑冲破害、成神不入传 | 不成，白费功夫 |

## 三、八字怎么对上

**不对应。** 八字是一辈子的格局，哪一次托人能不能成，要看这一课。八字里关于贵人、官杀印的说法，是另一回事（见「官职」「职业」篇），**资料没有讲到「某次托人成不成」**，这里不写。

## 四、案例

> 出处：《大六壬通解》下册 · 第六章 · 「信息、谋为」。

### 案例一：访人，对方不出来见（案例库 371｜OCR p210）

十月庚辰日寅将午时，李秀才占往元真观访紫衣张道士。三传 **丙子（螣蛇）→申（青龙）→庚辰（玄武）**。

> 邵彦和曰：「此课占访人，其人在本处**水火之傍**，造墨或为生计事。因事未毕，**必然不出见也**。盖子发用，虽与日辰三合，奈**辰课不足**，必主事务未毕也。且今日庚金，子水发用，**庚落空亡**，不能生子，子反畏日上天罡，所以主不出见。」

结果：「李果访之不见，后询之，果因造墨未毕也。」

| 盘上 | 断 |
|---|---|
| 子发用，与日辰三合 | 表面能合 |
| **辰课不足** | 对方有事没完 |
| 庚落空亡，天罡在日上 | 不出见 |
| 罡加孟，为在内 | 人在家 |

### 案例二：往见县尹，课里不正，钱花了没用（案例库 373｜OCR p211）

己酉年十月甲午日寅将戌时，管学正，四十九岁，往宜兴谒县尹。三传 **壬寅（白虎）→甲午（天后）→戊戌（六合）**，寅午戌炎上课。

> 邵彦和曰：「寅午戌相习而为狂党，天后六合**不正之神**，又为失友……甲日火局，是十二分**盗气**，支又来耗我，故大有所费。吾兄纵有所得，**左手得钱，右手便送娼家**，被官知觉，亦轻视不肯惠矣。」

结果：杨尹大喜，所赠甚厚，管全送入娼家，杨察知之，「遂不相预，仅与盘缠而归」。

原书又说：「炎上课，甲日自是不利，又午来蚀甲，天后六合皆不正之神，主酒色蛊惑，**四课不足，虽厚本亦主消折**，况赤手空拳乎。」

📝 **存疑**：原书注：断语中「吾兄若欲行正道，则不必见之。若行邪道，见之不妨」一段，编者标注「**此四句当有讹错**」，本篇不据此立论。

⭐ **这一课教什么**：**见到了不等于成**。盘上看的不只是见不见得到，还有**拿到了留不留得住**。

### 案例三：访僧，撞上贵人来访，没赶上宴席（案例库 374｜OCR p212）

三月乙酉日酉将辰时，史某占访僧见否。三传 **未（青龙）→子（贵人）→丑（白虎）**。

> 邵彦和曰：「和尚出门撞见，要回寺。又有一贵人来访，僧设宴款待。吾兄不得豫也。」

结果：「史果至寺门相见，待欲留茶，俄有侍御来见，僧便设席，史不豫宴。」

| 盘上 | 断 |
|---|---|
| **发用空亡**，传入贵人 | 有贵人来 |
| 酉来合乙得六合 | 寺门相见 |
| 未为酒食，龙为宴，又作空亡 | 虽有酒，不宴我 |

### 案例四：出外谒贵，求远得近（案例库 375｜OCR p212–213）

己酉年八月丁亥日辰将未时，傅清钦，三十五岁，占出外谒贵（《一针见血》）。三传 **癸巳（天空）→庚寅（六合）→丁亥（贵人）**。

> 邵彦和曰：「天罡作青龙，真斩关卦，**必至出行，但求远在近，求久在迩**，突然千里之外，只在目睫之处间。」

结果：傅往道州见太守（姑丈），姑丈却给一封信，荐在本州汪通判处就馆，**得二百贯钱**。

⭐ **这一课教什么**：原本要找的人没起作用，**帮忙的人在身边**。

### 案例五：投呈屡遁不收，何日收进（案例库 376｜OCR p213）

乾隆丁巳年三月戊戌日，东阳寺僧祥明，欲投阁宪呈词，屡遁不收，占何日能收进（《残编》）。

> 断曰：「占投呈，看**文书、朱雀**为主，今中传午为文书，旬遁甲木为官星，乘神是白虎，午与白虎皆道路之神也……**意者，此月十五癸卯日阁宪大人必出拈大士香**，登海会寺阙迎路而求之，可蒙收进也。」

结果：「至十五日果一一如断。」另有一说：十五日应期，是取末传戌为应期，地盘戌上见卯。

### 案例六：求贵人办事，贵人空亡，不成（案例库 377｜OCR p213–214）

雍正乙卯年五月丁卯日未将卯时，阮帝臣占求孔公司委买之事允否（《残编》）。

> 黄断曰：「**求贵不宜贵空，空则无力**，且夏令得木局，乃休气。休气者，废也，不成之象。」结果：「果于七月**另委他人**矣。」

原书解：「求贵人办事，贵人入传，那么其象倍现，**贵人空亡，因此不成**，而且三传三合木局，干支三合丛杂，表示事体多端，并且夏天木气休囚，因此事情不成功。此课三传不离四课，因此整个事情虽然不成功，但是要走一个过程，此为**回环课**的含义。」

### 案例七：督院文书批下来怎么样（案例库 378｜OCR p214）

乾隆乙亥年八月丁卯日辰将子时，占督院文书批发何如（《牧夫占验》）。

> 王牧夫曰：「省中文字不能如意，盐窝当大退。**丙丁之日批，戊己之日到**。果于丁日批，己日到。批语与生意甚无益也。」

| 盘上 | 断 |
|---|---|
| 占大官，**岁破**为用，岁破之上生酉，正冲木局 | 不能如意 |
| 正时与朱雀六害，与卯相刑 | 无望 |
| 朱雀为批辞，遁辛克支，支受墓受克 | 批语不好 |
| 未即丁，辛与丙合 | 丙丁日批 |
| 马带巳又合戊 | 戊己日到 |

### 案例八：谒贵见否（案例库 379｜OCR p214–215）

乾隆己卯年十月壬午日寅将戌时，占谒贵见否（《牧夫占验》）。

> 王牧夫曰：「**明日必见，见必有言语，不致动气**，此后水乳也。」结果：「其人到辕，三次禀见，俱未见，次日往禀，果传见。见有责备言语。却未曾动气，验甚！」

| 盘上 | 断 |
|---|---|
| **本命行年逢空** | 前几次见不到 |
| 干支上卯与戌合，年之阴见贵 | 来日传见 |
| 未为朱雀 | 有言语 |
| 未中藏丁，与干壬水作合 | 不动气 |

### 案例九：托人挽回，不能挽回（案例库 380｜OCR p215）

乾隆己卯年九月壬戌日卯时寅将，占事坏，今欲托人能挽回否（《牧夫占验》）。

> 王牧夫曰：「此事不能挽回，无希望矣。盖亥乃壬身投支受克，乃身为他人之财，传归子丑空位，又入夜乡，前路黑暗，安能复见，而丑为太常，作鬼临身，**此乃亲故中人来坏汝事耳**，子亥乃干支罗网，岂能让汝出头乎，故曰无望也，果验。」

原书解：占谋望最怕坏人、诳语，**发用天空立于河魁**，正应「阴空蛇虎魁罡立」一句。

## 五、开盘确认与先断后验

**开口前只确认下面几件**（盘上看不出来）：

| 先确认 | 为什么 | 不确认会错在哪 |
|---|---|---|
| **我去找他，还是他来找我** | 2.1：干支代表的人反过来 | 把我和他读反，断出来恰好相反 |
| **求的是见面、办事、还是等消息** | 2.3、2.4：看的东西不同 | 问见面却看朱雀 |

**其余的不要先问，先看盘、先开口，再用对方的反应验证**：

| 盘上先看 | 先怎么说（一句话） | 为什么 |
|---|---|---|
| 干支相临、生克 | “这事要求人，是你主动找的。” | 2.1 先定宾主 |
| 贵人落点、空不空 | “能帮上忙的人有，但（有没有力气）。” | 案例六：贵人空则无力 |
| 太阴天空螣蛇白虎魁罡 | “有人说得好听，要留个心眼。” | 2.5：五者相逢必诳人 |
| 末传所合之处 | “大概在某日有结果。” | 趋谒章：末传合处是成期 |

⚠️ 断出「被忽悠」「有亲近的人在里面坏事」时，**不要点名**——只说关系远近、特征，让当事人自己核实（同「失物」篇）。

## 六、读完这一篇，你能断什么

1. **谁求谁**：我去见他＝干是我、支是他；他来找我反过来。
2. **见不见得到**：干加支人必至；支加干访人不在；卯酉为阻隔；发用空亡传入贵人，会有别的贵人插进来。
3. **成不成**：类神出现、合神有气成；贵人空亡无力；本命行年逢空，先几次见不到。
4. **留不留得住**：炎上课、天后六合不正之神，钱到手也会散。
5. **会不会被忽悠**：阴、空、蛇、虎、魁罡五者相逢，必诳人。
6. **文书什么时候到**：朱雀为类神，雀马合处、发用绝处定期，丙丁日批、戊己日到。

**还断不了的**（资料未讲）：**趋谒章**其余口诀的逐句解释；八字如何看一次托人办事；**网络办事、线上审批**这类现代形式的专门象。
