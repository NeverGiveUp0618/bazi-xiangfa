# 断事图 · 财运：一个人能挣多少、怎么挣、存不存得住

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「财运好」在现实里可以是工资高、做生意赚、炒股赢、拆迁分到钱、继承家产，也可以是**挣得多但存不住**、**看着有钱其实负债**。不先知道钱有几种来路、几种去路，盘上看出「财旺」，你只能说「有钱」，说不出是哪种有钱，也说不出那钱会从哪里漏掉。
>
> **这一篇和「公司经营」的分工**：「公司经营」讲**开公司、做老板**的人；这一篇讲**每个人都会问的钱**——收入、外快、存钱、投资、赌、借钱欠债、破财。两篇讲同一套「什么当财」，这里不重复的细节去那一篇查。
>
> **这一篇分五部分**：
> **一、常识**：钱从哪来、往哪去、几个量级、投资与赌、借贷与负债（这部分是常识，不是命理规则）
> **二、八字怎么对上**：什么当财 → 是不是你的 → 怎么挣 → 多大 → 存不存得住 → 投资还是赌 → 借贷欠债 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**：一次求财、借钱、讨债（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。

## 一、常识：钱是怎么回事

### 1.1 钱从哪里来（收入的几种）

| 来路 | 样子 | 特点 |
|---|---|---|
| **工资薪金** | 每月固定发；奖金、绩效、年终奖 | 稳、有上限 |
| **经营所得** | 开店、做生意、个体户 | 有起伏、有风险 |
| **劳务、技能** | 接活、设计、咨询、讲课、手艺 | 靠本事，干一份拿一份 |
| **投资收益** | 存款利息、理财、股票、基金、房租 | 钱生钱，可亏 |
| **偶然所得** | 中奖、彩票、拆迁补偿、赔偿 | 一次性 |
| **家里给的** | 继承、父母资助、嫁妆彩礼 | 不靠自己挣 |
| **不正当所得** | 赌、贪污、受贿、诈骗、偷 | 有法律风险 |

⭐ **跟断命有关的一点**：命理里分「**正财**」（工资、经营这种按部就班来的）和「**偏财**」（外快、意外之财）。资料里断语常落在这一层：「**领工资度日**」「**有外财**」「**无工资外收入**」——先分清是哪一种。

### 1.2 钱往哪里去

| 去路 | 样子 |
|---|---|
| **日常开销** | 吃穿住行 |
| **大额支出** | 买房、买车、装修、婚嫁、教育、看病 |
| **人情往来** | 送礼、份子钱、请客、借给亲友 |
| **还债** | 房贷、车贷、信用卡、借款 |
| **亏损** | 生意亏、投资亏、被骗、被偷、赌输 |
| **罚没** | 罚款、赔偿、官司 |

⭐ **跟断命有关的一点**：资料里的「破财」很少只说破财，常常带着**为什么破**——「**看病住院先破财**」「**为当官破财（花钱送礼）**」「**为丈夫病而破财**」「**破财免灾**」。断破财要连去路一起断。

### 1.3 钱的几个量级（大致）

| 量级 | 现实里大致是 |
|---|---|
| **贫困** | 温饱困难、靠救济 |
| **工薪** | 月收入几千到一两万，够过日子 |
| **小康、小富** | 有房有车有存款，几十万到几百万资产 |
| **富** | 几百万到几千万，有产业 |
| **大富、巨富** | 亿级以上 |

⚠️ 各地物价不同：县城的「富」和一线城市的「富」差一个量级。资料里的断语也是按当地讲的（「**在当地属于富命**」〔【题21】〕）。

### 1.4 存不存得住

| 情况 | 样子 |
|---|---|
| **会挣会存** | 收入稳，有积蓄 |
| **挣得多存不住** | 花钱大手、爱面子、好赌、爱借人 |
| **账面有钱实际负债** | 生意人常见：资产多，但贷款更多 |
| **钱被别人花了** | 家人花、合伙人卷、被骗 |

### 1.5 投资、投机和赌

| 类别 | 例子 | 风险 |
|---|---|---|
| **储蓄、理财** | 存款、国债、银行理财 | 低 |
| **投资** | 股票、基金、房产、入股 | 中到高 |
| **投机** | 短线炒股、期货、币圈 | 高 |
| **赌博** | 赌场、六合彩、网络赌博 | **违法**，长期必输 |

⭐ **投资和赌的分界**：投资是拿本金买会长的东西；赌是拿本金买运气。资料里正好有一条同样的分法——比劫库制财库，「**制得住是投资、制不住就是赌**」（见 2.6）。

### 1.6 借贷和负债

| 类别 | 样子 |
|---|---|
| **正规贷款** | 房贷、车贷、经营贷、信用卡 |
| **民间借贷** | 向亲友、向私人借，利息不一 |
| **借出去** | 借给亲友，**要不回来很常见** |
| **高利贷、网贷** | 利滚利，容易越陷越深 |
| **担保** | 替别人担保，别人不还自己还 |

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 什么当财

> 「①**以财看财**（生活费用，最小的财）②**以食伤看财**（财的源头，大财）③**以官杀看财**……④**以禄看财**（前三项都没有的，好的禄就是白领，差点的就是领工资的）⑤**看库**……」〔v课 · 第 767 讲〕

| 现实（1.1） | 盘上当财的字 | 出处 |
|---|---|---|
| 生活费、小钱 | **财星本身**——「命中的财星为小财，如制尽再当大财看」 | 2012高级面授 p64 |
| 大钱的源头（本事、产品） | **食伤** | v课 767 讲 |
| 大钱（无财时、财官相生时） | **官杀当财** | 同上；面授 p64–65 |
| ⭐ **工资** | **禄**——好的禄是白领，差的是领工资；⭐「**辰中之财表工资**」 | v课 767 讲；财运篇 p12【题278】 |
| 积蓄、家底 | **库**（财库、食伤库、官杀库） | v课 767 讲 |

⭐ **先问两句**：「**看财运先问两句：①什么当财 ②宫位内外一分**」〔v课 776 讲〕。

### 2.2 是不是你的

| 盘上 | 断 | 出处 |
|---|---|---|
| **合得回来**的财 | 才是自己的；合不回来是打工的 | 面授⑥ ＋ v课 |
| 「**生出去的财要拿住或控制住**」 | 拿不住就不是你的 | 2012高级面授 p64–65 |
| 财**到不了日时主位** | 不是你的，换一个字当财看 | v课 777 讲【题477】 |
| ⭐ 同样的字、**卯在日支** vs **卯在月令** | 一个千万富翁、一个负债度日——「**月令表示众人之地**……自己的财被众人花费」 | 实战技巧 p5-6【题21】 |

### 2.3 怎么挣（对照常识 1.1）

> 「发财命要**定出他如何取财**，这样才对人生有更准确的指导意义。」〔财运篇 p6〕

| 现实 | 盘上 | 出处 |
|---|---|---|
| **工资** | 工薪取财——多以食伤／印／官杀／财做功，**效率普遍不高**；⭐「**技能被单位重用**」：食神（技能）被印（单位）那一方制着 | 财运篇 p6-12；【题279】 |
| **经营** | 伤官、食神或财星做功 | 财运篇 p6 |
| **开店** | 财星落于时上或年上做功；**财星配印**适合开门店（印表房屋） | 同上 |
| **靠本事** | 食伤做功且食伤占主位 | 同上 |
| **体力** | 比肩、劫财、禄神做功；「**比劫禄作用大的，多是体力劳动者**」 | 同上；中级班 p32【题587】 |
| **炒股、金融** | 「**申金为金融、股票等**」 | 初级班 p30【题119】 |
| **到处跑着挣** | 日坐马星：出租车、小客车、炒股、外卖 | 【题810】 |
| **不劳而获、非法** | 财合劫财＝不劳而获、非法得财 | 第5章；【题77】提示 |

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬占的是**这一次**：这笔钱求不求得到、借不借、讨不讨得回。

### 3.1 主线

> 「占求财，一定要**重视妻财与青龙**，因为**青龙为财帛之神**，喜龙居**旺相之地无刑克**，并**生日辰**则求财大利。」〔通解上 p239｜PDF p254〕

| 盘上 | 断 | 出处 |
|---|---|---|
| 干上、支上、命上**三处见财**又旺相 | 求财大获；只有支上一处未必是你的 | 通解上 p239 |
| 传财太旺、日干衰弱 | **求之不得**（担不动） | 通解上 p239-240 |
| ⭐ 财旺生起日干之鬼 | **因财致祸** | 同上 |
| 兄弟爻过旺 | 最忌，分夺 | 同上 |
| 三传顺克 | 求财大获 | 同上 |
| 末传生初传之财 | 有人暗中帮助 | 同上 |
| 初中空亡、末传见财禄长生 | 「进步艰难喜末吉」 | 通解上 p239 |
| 传中财都空陷，日下坐财 | 「避难之财坐身下」 | 同上 |
| 应期 | 以末传为主，看末传所合之支 | 通解上 p241 |

### 3.2 借钱、还债、讨债

| 课例 | 断 | 出处 |
|---|---|---|
| 例5 | **不宜借贷求财**，须防拆借还债、账目不明 | 借钱还债格 |
| 例10 | 尽力生财却像**替人还债** | 取还魂债格 |
| 例2 | 财多反而担不起，强取反费己财 | 三传财太过格 |
| 例20 | 财到宜速取，缓则反祸 | 求财急取格 |
| 例21 | 危中取财，能取到但有惊险 | 危中取财格 |
| ⭐ 例22 | **三传和日上夹着的字就是要讨的钱**；末传归禄逢合，终究讨得回 | 通解下 p289 |
| ⭐ 例24 | 对方不是故意赖账，是**好赌好酒败了家**，要**卖房子才还得上**，还不满全数 | 通解下 p293 |
| 例135 | 为点钱把鬼喂大了，**因财致祸、被人诬告** | 末助初鬼格 |
| 例168 | **求财招祸** | 谒求祸出格 |

⚠️ **资料未讲**：六壬占炒股、买彩票的专门断法。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **做什么工作、拿工资还是自己做** | 2.3：工薪和经营盘上不同 | 给打工的人断「发大财」 |
| **在哪个城市** | 1.3：量级随地方变 | 县城的富说成一线城市的富 |
| **家里有没有底子** | 祖业、家里给的 | 把家里的钱当本人挣的 |
| **有没有负债、炒股、借钱给人** | 2.6、2.7 | 只看收入，漏了漏洞 |
| **问的是长期还是这一笔** | 长期看八字，这一笔用六壬 | 用八字断一笔交易 |

⚠️ 断出「好赌」「赖账」「非法得财」时**别当面扣帽子**，可以说「这几年钱上有风险，别碰高风险的东西」。

## 六、读完这一篇，你能断什么

1. **什么当财**：财星小财，食伤是源，官杀当财大财，禄是工资，库是家底。
2. **是不是你的**：合得回来、到得了主位才是自己的。
3. **怎么挣**：工薪、经营、开店、靠本事、体力、炒股、到处跑。
4. **存不存得住**：财库养贼、主位穿财、库不开、太贪。
5. **投资还是赌**：比劫制财库，合回来是赢，合不回来倾家荡产。
6. **借贷与破财**：借出要不回、骗贷、因病因官因官司破财。
7. 六壬：这笔钱求不求得到、讨不讨得回。

**还断不了的**（资料未讲）：房贷车贷这类正常贷款的专门象；彩票中奖的专门象；六壬占炒股的专门断法。
