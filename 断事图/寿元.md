# 断事图 · 寿元：活多久、怎么走、哪几年是坎

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。看寿元最容易出两种错：一是**把正常衰老断成凶**（八十岁老人身体差是常事），二是**把一个坎断成死**（多数坎是能过的）。不先知道人一般活多久、各年龄常见死因、一个人走之前一般是什么样子，盘上看出「禄被伤」，你说不清是大病一场还是寿到。
>
> **这一篇和别篇的分工**：「疾病」讲**哪里病、急还是慢**，末尾有一小节寿元；「意外」讲**横死**；这一篇把**寿元的整套方法**单独拿出来：寿元星怎么定、哪些结构短寿、小孩的关、六亲的寿、应期、化解。
>
> **这一篇分五部分**：
> **一、常识**：人一般活多久、各年龄常见死因、病死和横死、临终与丧事（这部分是常识，不是命理规则）
> **二、八字怎么对上**：寿元星 → 短寿的结构 → 怎么走（病死还是横死） → 小孩的关 → 六亲的寿 → 什么时候 → 化解（全部出自资料，逐条带出处）
> **三、六壬怎么看**：这一场病过不过得去（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。
>
> ⚠️⚠️ **讲义三条规矩**〔小任讲义 p44〕：① 拿到八字**第一件事先判寿元**，免得把只到 40 岁的命断成「50 岁后大器晚成」② **60 岁前不主动告知寿数**；见小儿关煞这类明显风险要委婉提醒 ③ 不可拿已故者八字考命理师（学术讨论除外）。

## 一、常识：人的寿命

### 1.1 一般活多久

| 项 | 大致数 |
|---|---|
| 中国人均预期寿命 | **近 79 岁**（近年公布的数） |
| 男女差 | **女性一般比男性长寿五六年** |
| 「长寿」 | 一般说 80 岁以上；90 岁以上算高寿 |
| 「早逝」 | 一般说 60 岁以前 |
| 「夭折」 | 未成年就去世 |

⭐ **跟断命有关的一点**：资料里「**人不过六十不论寿命**」〔寿元门歌诀〕——**六十岁以后去世算正常**，不当凶看；要断的是**六十岁以前**有没有坎。

### 1.2 各年龄的常见死因

| 年龄 | 常见死因 |
|---|---|
| **婴幼儿** | 先天病、早产、意外（溺水、窒息、跌落） |
| **少年、青年** | **意外**（交通、溺水）、自杀、白血病等 |
| **中年** | **心脑血管**（心梗、脑出血）、**癌症**、意外 |
| **老年** | 心脑血管、癌症、呼吸系统病、老人跌倒 |

### 1.3 病死、横死、自然老死

| 类别 | 样子 |
|---|---|
| **病死** | 慢慢病重，或急病突发（心梗、脑出血） |
| **横死** | 车祸、被害、溺水、火烧、中毒、自杀 |
| **老死（寿终正寝）** | 年纪大了器官衰竭，没有明显大病 |
| **猝死** | 看着好好的突然走了，多是心脏 |

⭐ **跟断命有关的一点**：资料里正好分这两类——「**枭印夺食一般是病死；阳刃出凶都是横死**」〔教材第15章 4.3·B〕。

### 1.4 一个人走之前一般什么样

- **慢病**：反复住院 → 越来越重 → 卧床 → 器官衰竭
- **急病**：突然发作 → 抢救 → 救回来（留后遗症）或没救回
- **危重的几个信号**：进重症监护室、医院下病危通知、不吃不喝、意识不清

⭐ **跟断命有关的一点**：「救回来」和「没救回」差在一线——资料里专门有「**手术能救过来**」「**危而复生**」的判法（见 2.6、三）。

### 1.5 丧事

| 项 | 常识 |
|---|---|
| **孝服** | 家里有人去世，晚辈戴孝 |
| **内孝、外孝** | 本家（父母、配偶）为内；外家（岳父母、舅家）为外 |
| **守孝期** | 旧俗三年，今多从简 |

⭐ 六壬里有「**内孝服、外孝服**」的专门断法（见三·3.3）。

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 寿元星：先定，再看坏没坏

> 「看寿命要定寿元星，**寿元星分两类①生禄为体②禄生为用**，单个寿元星的话，出问题，这个人就会死掉，这种情况较少，多数情况是有多个寿元星，那就都要看，**都出问题才会死掉**。**多个寿元星之间如果倒象，这种命就容易早夭。**」〔v课 · 第 798 讲〕

```
   寿元星 ＝ 生我的（印，「生禄为体」）＋ 我生的（食伤，「禄生为用」）
             ＋ 调候之字 ＋ 日主的根、天地门的「门」字
   判法：① 列出全部寿元星  ② 逐个看有没有坏  ③ 全坏才死；互相倒象＝早夭之象
```
〔教材第15章 4.3·B〕

| 要点 | 原话 | 出处 |
|---|---|---|
| 单元星 | 「**独官遭破入黄泉**」「**财轻逢劫死，刃重见财亡**」 | 小任讲义 p44 |

| ⭐ 「门」字 | **天地门那个「门」字坏了就全坏** | 【题496】 |

| 先问 | 为什么 | 不问会错在哪 |

| **问自己还是问家人** | 六亲看宾位 | 把六亲的寿断到自己身上 |

## 六、读完这一篇，你能断什么

1. **寿元星**：生我的、我生的、调候、根、门字；全坏才走，互相倒象早夭。
2. **短寿结构**：根被制、禄被伤、印被穿、流绝、四大空亡。
3. **怎么走**：枭印夺食病死，阳刃出凶横死。
4. **小孩的关**：将军箭开弓、童箭、真元辰。
5. **六亲的寿**：宾位衣食跑到运上，墓绝同现。
6. **救不救得回**：替身代器官、忌神有制、阴阳还在。
7. 六壬：虎鬼、龙生、久病逢空死、暴病逢空吉。

**还断不了的**（资料未讲）：长寿的专门判法；正常老死与病死怎么分。
