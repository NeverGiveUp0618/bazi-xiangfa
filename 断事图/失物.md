# 断事图 · 失物：丢了没有、在哪、找不找得回、贼是谁

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「东西不见了」在现实里多数是**放错了地方**，少数是**被偷**，还有**被骗走**、**借出去没还**、**被家里人拿了**。六壬原书作者自己丢书那一课，第一句就是「**书还在我的范围内**」——后来在家里包里找到了。不先想清楚有哪几种可能，盘上看出来也说不准是哪一种。
>
> **这一篇分五部分**：
> **一、常识**：东西不见的几种情况、被偷被骗怎么办、人走失怎么办（这部分是常识，不是命理规则）
> **二、六壬怎么看**（本篇的主角）：丢没丢 → 在哪 → 贼是谁 → 找不找得回 → 什么时候 → 跑掉的人（全部出自《大六壬通解》，逐条带出处）
> **三、八字怎么对上**：哪些人一辈子容易失盗破财
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。
>
> ⭐ 这一篇和前面几篇不一样：**占失物主要靠六壬**（一事一课，问的就是「这一次」），八字只看一辈子容不容易丢钱丢东西。

## 一、常识：东西不见了

### 1.1 东西不见的几种情况

| 情况 | 常见程度 | 样子 |
|---|---|---|
| **放错地方、忘了** | **最常见** | 就在家里、车里、包里、办公室 |
| **落在外面** | 常见 | 商场、出租车、饭店，常能找回 |
| **被家里人、熟人拿了** | 时有 | 家人收起来、孩子拿走、熟人顺手 |
| **被偷** | 少一些 | 入室盗窃、扒窃、单位财物被盗 |
| **被骗走** | 越来越多 | 电信诈骗、网络诈骗、熟人借钱不还 |
| **借出去没还** | 常见 | 借给朋友、亲戚 |

⭐ **跟断命有关的一点**：六壬里专门先判**是不是真丢了**——「**鬼空则不能克我，必定非遗失**」（见 2.1）。现实里多数「丢了」其实是没丢，这一步最要紧。

### 1.2 被偷、被骗以后

| 事 | 要点 |
|---|---|
| **报警** | 被盗被骗都应报警；数额到一定程度（各地标准不同，一般一两千元以上）公安会立案 |
| **调监控、查记录** | 现在多数案子靠监控、转账记录破 |
| **追赃** | 抓到人后追回赃物、赃款，常常只能追回一部分 |
| **常见诈骗** | 冒充客服退款、冒充公检法、刷单返利、网恋投资、冒充熟人借钱 |
| **防范** | 不轻信陌生来电、不转账到「安全账户」、贵重物品分开放 |

### 1.3 人不见了

| 情况 | 样子 |
|---|---|
| 孩子离家出走、老人走失 | 多在附近 |
| 成年人失联 | 躲债、躲人、外出没告诉家里 |
| 私奔、卷款跑了 | 有预谋 |
| **报警不用等 24 小时** | 人员走失、失联可以立即报警 |

## 二、六壬怎么看（出自《大六壬通解》）

### 2.1 第一步：丢没丢

> 原书作者的失物实占（丢了一本六壬书，怀疑丢在超市或别人家）〔通解上 p29｜PDF p44〕：
> 「首先，此课为**元首课，我为主，书为客，我克彼，表示书还在我的范围内**」
> 「而**三传明暗木鬼均空亡，不能克日，因此必定非遗失**」
> ——结果：「正东方是一个黑耐克包，笔者打开包，**一下就找到了书**」。

| 盘上 | 断 | 对照常识 1.1 |
|---|---|---|
| **课体「我克彼」**（元首课等） | 东西还在**我的范围内** | 放错地方 |
| **鬼空亡** | 鬼不能克我 ⇒ **必定非遗失** | 没丢 |
| ⚠️ 空的若是**类神** | 结论反过来——东西真没了 | 真丢了 |

> ⭐ 「**空亡是好消息还是坏消息，看它空的是什么**。这一课空的是鬼……若空的是类神，结论就反过来了。」〔第 17 课〕

**报信是不是真的**：「报信全是虚的、别空欢喜（无中生有）」〔课例 120〕；**天空**是虚诈之神。

### 2.2 第二步：在哪

> 「**发用上克下，表示书在室内较低的位置**」「发用天将为朱雀，朱雀就是书的类神，**临日阴，表示书在身边室内**」「**卯加日墓表示书在室内的容器内**」「三传连茹，**初传卯为正东方**……**卯为六数**，正好东方摆了六个包与箱子」〔通解上 p29〕

| 看什么 | 断什么 |
|---|---|
| **类神**（丢的是什么，就找它的类神） | 东西本身；类神临哪宫就在哪 |
| 发用上克下／下贼上 | 位置高低（上克下＝在低处） |
| 临日阴等（内） / 临外 | **室内还是室外** |
| 加墓 | **在容器里**（包、箱子、柜子） |
| 类神的地支 | **方位**（卯＝正东） |
| 类神的数 | **件数**（卯为六） |

**失物的类神**〔第 12 课〕：

| 丢的是 | 类神 |
|---|---|
| 一般失物、亡失 | **亥**（主取索、亡失）、**戌**（主失钱物） |
| 钱财 | **妻财**（日干所克） |
| 文书、书 | **朱雀** |
| 动物、具体物件 | 按支神类象取：**申为猴、酉为玉**、午为马、酉为鸡…… |

> 课例：「申为猴、酉为玉，**丢的是什么盘上直接写着**」〔课例 126〕；「**鸡就在邻居家，还压在瓦盆底下**」〔课例 129〕。

### 2.3 第三步：贼是谁、在哪

> 「**占贼行藏须视鬼，玄神生克看加临。卜赃失得凭财断，子孙休旺定追寻。**」〔通解上 p244｜PDF p259〕

| 看什么 | 断什么 |
|---|---|
| **官鬼** | 贼的行藏 |
| **玄武** | 贼的**方位与状态**（所乘所临） |
| **妻财** | 失物、赃物 |
| **子孙** | **能不能追回**——旺则获，休囚则难 |

> 「**玄武、螣蛇、天空、鬼贼、脱盗、兄弟等皆为偷窃之神**，断课时须要根据课传具体而论。」〔通解上 p244〕

**对照常识 1.1**：「兄弟」也是偷窃之神——正好对上「**熟人、家里人拿了**」那一种。

> 课例：「**贼有五人、住在东北五十里、丙丁日败露**」〔课例 124〕；「**丢的是人参，还说得出两个来客穿什么颜色**」〔课例 125〕；「**被人连哄带骗地脱走**」〔课例 116〕。

### 2.4 第四步：找不找得回、抓不抓得到

| 盘上 | 断 | 出处 |
|---|---|---|
| **鬼逢刑冲克害** | **可以抓获**，否则难捕 | 通解上 p244 |
| **子孙旺** | 能抓获、能找回；**子孙休囚**则难 | 同上 |
| **玄武临克地** | 「**捕贼以玄武为类神，若玄武临克地，自然得捉也**」 | 通解上 p176 |
| **自生入墓**（寅加戌、巳加丑、申加辰、亥加未） | 「如人堕井中，呼天不应……**占贼难获**」 | 通解上 p67 |
| 类神根本不在课传里 | **找不回** | 课例 128 |
| 玄武乘空 | — | 课例 121 |
| 脱了又落空、竹篮打水 | — | 课例 119 |
| 钱像流水接连耗、抓不住 | — | 课例 118 |
| 天黑了、贼照不出来 | 太阳（月将）照不到玄武 | 课例 114 |

**对照常识 1.2**：「子孙旺能追回」——现实里是**监控清楚、有人帮、追赃顺利**；「自生入墓」——**石沉大海**。

### 2.5 什么时候

| 规则 | 出处 / 课例 |
|---|---|
| 贼**丙丁日败露** | 课例 124（类神、应期） |
| 应期一般看末传、类神所合之神 | 第 16、21 课 |

⚠️ **资料未讲**：失物应期的专门口诀——课例里都是随课而断。

### 2.6 跑掉的人（对照常识 1.3）

> 「**追寻达士详日德，捕捉逃奴看支刑。德克刑神必易获，刑克日德定难寻**……**伏吟主近无依遐**。」〔通解上 p244｜PDF p259〕

| 盘上 | 断 |
|---|---|
| 日德克支刑 | **容易找到** |
| 支刑克日德 | **难找** |
| **伏吟** | **人没走远** |
| **八专**（干支一体） | 人没走远，**就藏在家里**（课例 152） |
| 连茹退行 | 人走不远，**马上就回来**（课例 150） |
| 关隔 | 门被关死、人访不着（课例 145） |

> 课例：「**婢女卷财逃走，钱藏在水里**」〔课例 149〕；「**她说要去投河，先看『河覆不覆井』**」〔课例 151〕。

## 三、八字怎么对上（一辈子容不容易丢钱丢东西）

| 现实 | 盘上 | 出处 |
|---|---|---|
| ⭐ **容易被偷被骗** | 「**主位临财外遇劫，防偷防骗防盗窃**」 | 小任 |
| **某一年被盗** | 禄作财看时最怕见劫财：「逢庚辰年，辰土劫财泄禄为凶」⇒ **此年被盗破财**；好在大运吉，**破案后追回部分财物** | 财运篇 p2 ·【题260】 |
| **单位财务被盗**（工作失误） | 丁丑运「要注意破大财、命犯小人，特别是今年要有盗贼出现」⇒ 会计下班忘了取钥匙，单位被盗 | 【题166】 |
| **一见某字就破财** | 卯合闭财库：「一见卯就要破财，制了卯才能发财」 | 【题102】 |
| **被熟人骗** | 被表兄弟骗过两次；当经理风光，后被骗丢职 | 【题261】【题266】 |
| **钱被人拿走** | 运里水多入比劫库 | 【题475】 |
| **借钱要不回来** | — | 【题487】 |

**对照常识**：「主位临财外遇劫」＝自己的钱身边站着外人——现实里就是**财物看管不严、身边人复杂**。

⚠️ **另一面**：盘上有偷盗之象的，也可能是**偷的人**（见「官司」篇 2.2：丑时至阴去拿人家钱、食伤入墓且全阴性、两个亥夹寅的技术小偷）。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **丢的是什么** | 2.2：类神不同 | 丢的是钱，你去找朱雀 |
| **什么时候发现的、最后一次见在哪** | 起课时间与范围 | — |
| **家里、车里、办公室都找过没有** | 1.1：多数是放错了；六壬第一步就是判丢没丢 | 人家没找就断「被偷」 |
| **身边有没有可能拿的人** | 「兄弟」也是偷窃之神 | 漏掉熟人这一种 |
| **报警了没有** | 1.2：断「找不找得回」时有用 | — |
| **问的是物还是人** | 2.6：跑掉的人另有一套 | 用失物的法子找人 |

⚠️ 断出「被偷」「熟人拿了」时，**不要点名**——只说方位、特征、关系远近，让当事人自己去核实。

## 六、读完这一篇，你能断什么

1. **丢没丢**：我克彼＝还在我范围内；鬼空＝非遗失；空的是类神才是真丢。
2. **在哪**：类神定物；临内外定室内室外；加墓在容器里；地支定方位、数定件数。
3. **贼是谁**：鬼看行藏，玄武看方位状态；兄弟也是偷窃之神。
4. **找不找得回**：鬼逢刑冲克害可获；子孙旺能追回；自生入墓难获。
5. **跑掉的人**：伏吟、八专人没走远；连茹退行马上回。
6. 八字看**一辈子**：主位临财外遇劫防偷防骗；禄见劫财那年被盗。

**还断不了的**（资料未讲）：失物应期的专门口诀；**网络诈骗**这类新情况的专门象；八字里「丢东西」和「破财」怎么分。
