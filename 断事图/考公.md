# 断事图 · 考公考编：考不考得上、进的是什么单位、上岸以后

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「考公」「考编」「考上岸」现在是来问最多的事之一，但现实里这几样差别很大：**公务员**和**事业编**不是一回事，**国考**和**省考**不是一回事，**笔试过了**和**录用了**也不是一回事。不先知道考试怎么走、卡在哪一步，盘上看出「官印相生」，你只能说「有工作」，说不出是考上了、还是面试被刷、还是进了编外。
>
> **这一篇和别篇的分工**：「学业」讲读书、学历；「官职」讲当上官以后几级；「职业」讲体制内还是外面。这一篇讲**中间那一步：考进体制、内部竞聘**。
>
> **这一篇分五部分**：
> **一、常识**：体制内有哪几种身份、考试怎么走、卡在哪一步、内部竞聘（这部分是常识，不是命理规则）
> **二、八字怎么对上**：有没有体制内的命 → 是不是「官」 → 进什么单位 → 什么时候
> **三、六壬怎么看**：这一场考不考得上（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是常识，具体政策每年、每地都会调，**以当年公告为准**；第二、三部分只用老师资料，逐条带出处，资料没讲的写明。

## 一、常识：考进体制是怎么回事

### 1.1 体制内的几种身份

| 身份 | 是什么 | 怎么进 |
|---|---|---|
| **公务员** | 机关在编人员（政府、法院、检察院、党委等） | **国考**（中央机关及直属机构）、**省考**（地方） |
| **参公** | 参照公务员管理的事业单位 | 一般随公务员考试 |
| **事业编** | 学校、医院、科研院所等 | 事业单位招考（各地分批）；**教师编**、**医疗编**单独招 |
| **选调生** | 定向培养的年轻干部 | 面向应届优秀毕业生 |
| **军队文职** | 部队里的非军人 | 单独考试 |
| **国企** | 不是编制，但稳定 | 校招、社招 |
| **编外、合同工、临聘** | 在机关事业单位干活但**没有编制** | 招聘 |

⭐ **跟断命有关的一点**：老师说「**公务员不叫官，起码副科级开始才算**」〔v课【题518】〕——**考上公务员 ≠ 当官**，只是有了工作。

### 1.2 考试一般怎么走

1. **报名**（看岗位要求：学历、专业、年龄、户籍、工作经历）
2. **资格审查**
3. **笔试**：公务员考**行测＋申论**；事业编考**公基**或职业能力测试；教师、医疗考专业
4. **面试**：结构化面试、无领导小组讨论等
5. **体检**
6. **考察、政审**
7. **公示、录用**
8. **试用期**（一般一年）

### 1.3 常卡在哪一步

| 卡点 | 样子 |
|---|---|
| **报不上名** | 专业、学历、年龄不符；年龄一般 35 岁以下（具体看公告） |
| **笔试没过** | 分数不够，进不了面试 |
| **进了面试被刷** | 「**差一点**」——排名第二第三 |
| **体检、政审没过** | 少见，但有 |
| **考了好几年** | 「多年考公」很常见 |
| **上岸了不满意** | 岗位偏远、工资低、想辞职 |

### 1.4 内部竞聘、遴选

| 类别 | 样子 |
|---|---|
| **竞聘上岗** | 单位内部竞争中层岗位 |
| **遴选** | 从下级机关考到上级机关 |
| **公开选拔** | 面向社会选领导干部 |
| **提拔** | 组织考察任命，不考试 |

## 二、八字怎么对上（出自资料）

### 2.1 有没有体制内的命

| 现实 | 盘上 | 出处 |
|---|---|---|
| **公职、国企** | **官印相生** | 十八道法门 p11 |
| ⭐ **在单位做事** vs 在企业 | 「**食伤在年表在单位做事，在日时表企业**」 | 【题758】 |
| **有工作但不当官** | ⭐ 「**禄合官不为官，只表示有工作**」 | 中级班 p22【题569】 |
| 有工作的命 | 禄带印；乙庚合官 | 【题557】【题587】 |
| 上班族（单位里的财） | 癸卯带象又在月上＝单位里的财 | 【题703】 |
| **自主创业，不进体制** | 食伤生财 | 十八道法门 p11 |
| 不想打工、自己当老板 | — | 【题209】 |

### 2.2 考上了是不是「官」（对照常识 1.1）

| 规则 | 出处 |
|---|---|
| ⭐ 「**公务员不叫官，起码副科级开始才算**」 | v课【题518】 |
| 「**省市一级的科员之类**；国考能上司法局」——「**格局不大也不算小**」 | 【题392】 |
| 国考通过，在统计局上班，**有权力** | 【题378】 |
| 「**官印通根可以表示实权**」；「**虚透为虚职**」 | v课 825 讲 |

⭐ **对照常识**：【题378】【题392】都是**国考进机关**——一个「有权力」（统计局、亥食伤生财、乙庚合），一个「科员之类」（丙辛合、食伤配印）。**同样考上，层次在盘上就分开了**。

### 2.3 进什么单位（对照常识 1.1）

| 现实 | 盘上 | 出处 |
|---|---|---|
| 法院、检察、司法 | 「组合中如出现**申、酉两字做功**，一般是与**法律**有关的官职」；「申、酉、寅丑有关的组合做功，一般与**公安**有关」 | 官运篇原则 |
| 军队、执法 | 「**羊刃与七杀组合**，一般表执法部门、实权派或军队部门」 | 同上 |
| 纪检 | 「**伤官与官杀组合**，一般为实权或纪检部门」 | 同上 |
| 财政、银行 | 申为金融；食神制杀又有财源库 ⇒ 银行行长 | 【题262】【题689】 |
| 学校、医院 | 印＝文化；印的人物还有**医生、护士** | 小任 · 初中级第05课 |

更多部门取象见「官职」2.5、「职业」2.4。

### 2.4 学历够不够（对照常识 1.2 报名门槛）

| 规则 | 出处 |
|---|---|
| 「**具体学历高低，就是命主对学历星用的度的把握**」 | v课 761 讲 |
| ⭐ 「**学历仅是一个名而已，不表财富能力、也不表权利、地位**」 | 面授 p98【题760】 |
| 56 岁的本科生：「穿两次就算正式了」 | 【题440】 |

详见「学业」篇。

### 2.5 什么时候考上

| 规则 | 出处 |
|---|---|
| 「**命中没有的事，大运来了也不算！**」 | 2012面授 p55 |
| 官杀、印到运到年、做功的字被引动 | 第12章 |
| 空亡＝「**还没实**」：「**杀＝工作，空 → 工作还没落实；印＝手续/文书，空 → 手续没办下来**」 | 【题51】 |

⭐ **对照常识 1.3**：【题51】正好对上「**人已经上班了，但手续还没办下来**」——试用期、编制还没批的那一段。

⚠️ **资料未讲**：笔试和面试分开看的八字判法；「考了好几年才上岸」的专门象；内部竞聘、遴选的专门判法。

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一场考试**、**这一次竞聘**。

### 3.1 干为考生，支为考场

> 「**占考试，干为举子，支为场屋**；**占求官，干为求官之人，支为所历之任**。」〔通解上 p131〕

| | 考试 | 竞聘、求职 |
|---|---|---|
| 日干 | 考生本人 | 求职的人 |
| 日支 | 考场、考试本身 | 那个岗位 |

### 3.2 考得上考不上

> 「**登科者禄马扶会**」——禄神驿马临于干支之上，主前程远大。
> 「**不第者刑害俱骈**」——三刑六害并临干支之上，**刑主有缺，害主阻隔难成**。〔通解上 p176｜PDF p191〕

| 见到 | 断 | 对照常识 1.3 |
|---|---|---|
| 禄、驿马临干支 | **考得上** | 上岸 |
| 三刑六害并临干支 | **考不上** | 刑＝有缺（差几分），害＝阻隔（被卡） |
| 「**欲问前程有与无，日辰虚实定荣枯**」；日干支临日禄、帝旺 | 前景良好 | 通解上 p237 |
| 日干支**落空乘空** | 最忌 | 同上 |

### 3.3 ⭐ 一件事分几段，就分几套字看（对照常识 1.2）

> 例46：「**省试能中，殿试却不第——两场要分开看**」；「⭐ **一件事分几段，就分几套字来看**」〔通解下 p97〕

⭐ **对照现实**：**笔试、面试、政审**是几段，可以分开占、分开看——笔试能过不等于面试能过。

### 3.4 有人举荐、升迁

| 课例 | 断 |
|---|---|
| ⭐ 例36 递生格 | **三传递生日干＝有人层层举荐**；中间一环空亡＝举荐落空 |
| ⭐ 例41 | 三传递生像是有人举荐，**为什么升不了**——「**三传是大概之象，年命方切于己**」 |
| 引从格 | 「**前后引从升迁吉**」——初传居干前为引，末传居干后为从，**必升迁** |
| 两贵引从 | 必得**上司提拔或两处贵人引荐** |
| 文职看**青龙**，武职看**太常** | 「旺相相生必吉，上下克战则凶」 |
| 求名看**朱雀** | 「求名文书朱雀中」 |

### 3.5 分到哪里、要不要花钱

| 课例 | 断 |
|---|---|
| ⭐ 例45 | **会被派到哪个县**：盘上拱出一个地名（蓬莱） |
| 例44 | 求这个官要「**先费自己的钱**」，走的不是正途 |

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **考什么**：公务员、事业编、教师、国企？ | 1.1：身份不同 | 把事业编断成「当官」 |
| **到哪一步了**：报名、笔试、面试、政审？ | 3.3：分段看 | 笔试过了就断「上岸」 |
| **考了几年、多大年纪** | 1.3：年龄门槛 | 给超龄的人断「明年能考上」 |
| **学历、专业** | 2.4：报名门槛 | — |
| **考哪个单位、哪个地方** | 2.3、3.5 | — |

## 六、读完这一篇，你能断什么

1. **有没有体制内的命**：官印相生、食伤在年表单位、禄合官只表有工作。
2. **考上了是不是官**：公务员不叫官，副科级起才算。
3. **进什么单位**：申酉法律、刃杀执法军队、伤官官杀纪检。
4. **手续没下来**：印空＝还没实。
5. 六壬：**干为考生、支为考场**；禄马扶会考得上，刑害俱骈考不上；**笔试面试分开看**；递生＝举荐。

**还断不了的**（资料未讲）：八字里笔试与面试怎么分；多年才上岸的专门象；内部竞聘、遴选。
