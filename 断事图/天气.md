# 断事图 · 天气：下不下雨、什么时候转晴、风大不大

> **为什么从常识讲起**：天气今天有**气象预报**，比任何盘都准。六壬占天时是古人没有预报时的办法，书里留下的案例也只是「**这一课断对了**」的记录，**不是**说盘比预报强。所以这一篇的用法是：**拿它练盘、练类象**，因为天气是**当天就能验证**的事，最适合新手检验自己断得准不准。
>
> **这一篇分五部分**：
> **一、常识**：天气是怎么回事，以及这一篇该怎么用
> **二、六壬怎么看**（本篇的主角）：先看总势 → 风雨雷雪各看什么 → 大小 → 什么时候 → 转晴 → 类神表（全部出自《大六壬通解》，逐条带出处）
> **三、八字怎么对上**：不对应
> **四、案例**
> **五、开盘确认与先断后验**
>
> ⚠️ **读法**：第一部分是常识；第二部分只用老师资料，**资料没讲到的写明「资料未讲」**；古书里**两说并存**的地方一律两说都列，不替它选。
>
> ⭐ 这一篇**只有六壬**：占天气是一事一课（问的就是「这一次」），八字是一辈子的格局，两者不挂钩。

## 一、常识：天气这件事

### 1.1 天气能占多久

| 范围 | 现实里 | 六壬书里 |
|---|---|---|
| **当天、明后天** | 气象预报最准 | 书里的案例**绝大多数**是这一档 |
| **几天内** | 预报还可以 | 有「**雨期**」「**转晴日**」的口诀（见 2.4、2.5） |
| **一整年的晴雨** | 谁也说不准 | 古人有特殊起法（大年初一起课等），见 2.7；**案例资料没给**，不要当真 |

### 1.2 这一篇怎么用

1. **先看预报，再起课对照**：预报说下雨，盘上也有雨象，才算「看懂了」；盘断「大雨」预报说晴，要回头查是不是**类神取错、空亡漏看**。
2. **断完当天验证**。原书作者自己就是这样练的：断完告诉家人「巳时云层变化，午时小雨，申酉时风云雨至」，**当天对照**（见案例一）。
3. 天气是练**五行旺衰＋类象**最干净的题：没有人情，没有隐瞒，对错当天见分晓。

## 二、六壬怎么看（出自《大六壬通解》）

### 2.1 第一步：看总势，辰和贵人

> 「**天象先占太角星，指阴主雨指阳晴。贵登绛明时雨沛，预卜阴晴此法精。**」〔通解上 p204｜PDF p219〕

| 看什么 | 断什么 |
|---|---|
| **天罡（辰）** 加在哪 | 辰加**六阴位**主雨，加**六阳位**主晴——这只是**总的趋势**，不能只靠它定 |
| **天乙贵人**加在亥、子等水位 | 有行雨的**主体趋势** |

> 原书注：「**十二神重天罡，十二将重天乙贵人**」——抓住十二神和十二将的首领，作为断天气总势的**入口**，再结合课体、神将、五行细看。〔通解上 p204｜PDF p219〕

⚠️ **根本原则**：「**阳将火神多主晴，阴将水神多主雨**」；「**具体判断要以五行为主，神煞为辅**」。〔通解上 p205｜PDF p220〕

### 2.2 第二步：风雨雷雪各看什么

> 「**龙入庙晴，升天雨，虎出山林有烈风。水运乎天叹霖泽，火离于地仰晴空。**」〔通解上 p205｜PDF p220〕

| 要断的 | 看什么 | 怎么断 |
|---|---|---|
| **雨** | **青龙** | 青龙临**辰、巳、午、未**＝青龙升天，降雨之象；青龙在十二天将里司雨 |
| **风** | **白虎** | 白虎临**寅、卯**有大风（原书另说：临寅卯辰巳＝跨山出林风势大；临午未申丑戌＝小风） |
| **雷电** | **螣蛇、朱雀**（火神） | 螣蛇、朱雀临**卯**，又见**丁神**＝雷电霹雳；朱雀、螣蛇临巳午＝热极生风 |
| **连绵雨** | 玄武 | 玄武临**亥子**＝连绵雨水 |
| **晴朗多云** | 天空 | 天空临**四季土（辰戌丑未）**＝晴朗多云 |
| **风雨交加** | 白虎 | 白虎临**亥子**＝风雨之象 |
| **蛇化蛟龙** | 螣蛇 | 螣蛇临**亥子**＝主雨 |

**两说并存（原书照录，不替它选）**：

- 青龙临谁算「升天」：一说**巳午未申**（还有一说加酉）；青龙临**亥子丑**是「游乐江湖」，**反而无雨**；龙临**寅**是「入庙」，无雨。〔通解上 p205｜PDF p220〕
- 白虎临**未**则风烈：未为风伯，原书评「这一说很有道理，读者在实践中多比较参考」。

⭐ **雷的看法**（《壬窍》）：「**占风看巳午未寅卯、雀、虎，占雷看甲、卯、乙及六合。**」〔通解上 p206｜PDF p221〕

### 2.3 第三步：大小

> 「**衰旺空刑须细辨，克日有气滂沱见。无气空亡微雨来，如回应声真可羡。**」〔通解上 p206｜PDF p221〕

| 盘上 | 断 |
|---|---|
| 水**旺**且**克日** | **大雨**，持续久 |
| 水**空亡**而生日干 | **雨小** |
| 水、火等五行**空亡无气** | 晴雨都**不久** |
| 水神加**巳** | 水绝，雨少；加**午**是胎，雨小；加**未**受克，有也弱 |

> 原书注：「旺则大而久，衰则小而短。」「一切依月令、日辰旺衰结合上下神详细而论。」

**风雷煞动、云雨神加**（神煞辅助）：

- 风有**风煞、风伯**；雷有**雷煞**；**飞符、飞廉**是迅速之神，主来得快。
- 口诀：「风雷煞动大风起，云雨神加骤雨来。猛烈唯足畏下真，迅速飞符疾雨雷。」
- ⚠️ 风煞、风伯、雷煞、飞符、飞廉各按月（或按日干）起，具体排法见原书同页脚注：风煞正月寅、二月丑、三月子逆行；风伯正月申、二月未、三月午逆行；飞符甲日巳、乙日辰、丙日卯、丁日寅……〔通解上 p206｜PDF p221〕

### 2.4 第四步：什么时候下

> 「**风雨之主看龙虎，风雨之期寻羊鼠。**」（羊＝未，主风；鼠＝子，主水）

| 盘上 | 断应期 |
|---|---|
| 未加寅（六乙日） | **甲乙日**有风 |
| 子加申（六丙日） | **庚辛日**有雨 |
| **水神（壬癸亥子）**临寅卯 | 甲乙日下雨 |
| 水神加**辰戌丑未** | **戊己日**下雨 |
| 水神加**巳午** | **丙丁日**下雨 |
| 课传**不见亥子**，或亥子**空亡** | 看**青龙**所临地支的**地盘合处**：如青龙临子、子空，子丑合，则看地盘**丑**上的神来定雨期，并要看那个神有没有雨气之象 |

〔通解上 p205–206｜PDF p220–221〕

### 2.5 第五步：什么时候转晴

> 「**罡加四季天无云，去日几位是其候。月将加时再一看，丙丁之下晴光透。**」〔通解上 p207｜PDF p222〕

| 盘上 | 断 |
|---|---|
| **天罡加四季**（辰戌丑未） | 天气**将要转晴** |
| **去日几位** | 例：六乙日辰加午，去日两位，次日晴；辰加未，去日三位，第三日晴 |
| **丙丁**所在的位置 | 「丙丁之下晴光透」：看课中丙丁落在哪，就是哪日晴。例：庚午日返吟课，寅遁丙加申、卯遁丁加酉，则**申酉日**晴 |
| **久雨占晴** | 古人说：「**占晴，看雨神空绝日**」——雨神空亡、绝的那天 |

**勾陈制玄武**：「占晴雨最宜勾陈入传临日辰，制玄武，决主天晴。」〔通解上 p105｜PDF p120〕

### 2.6 第六步：五行本象与课体

> 「**金为水母巽风从，震为雷兮兑为泽。**」〔通解上 p207｜PDF p222〕

| 看什么 | 断什么 |
|---|---|
| **申金**（水之长生，金为水母） | 不雨则阴。庚申辛酉、巳酉丑金局、乙庚化金、纳音金都可论水母 |
| ⚠️ **有母无子则不应** | 课中**没有水**，不能只凭金就断雨 |
| 辰、巳、乙 | 有风象 |
| 乙、卯 | 雷；辛、酉：雨泽 |

> 「**阳备晴兮阴备雨，曲直生风炎上旱。从革主晦润下阴，稼穑是主晴可断。**」〔通解上 p207｜PDF p222〕

| 课体 | 天气 |
|---|---|
| **阴不备**（四课阳全） | 主晴 |
| **阳不备**（四课阴全） | 主雨 |
| 三合**木**局（曲直） | 风 |
| 三合**火**局（炎上） | 干旱 |
| 三合**金**局（从革） | 阴晦 |
| 三合**水**局（润下） | 阴雨 |
| 课传皆**土**（稼穑） | 见日月星辰，晴 |

**变化**：火盛逢水＝电光霹雳；水局见土则润、见木则泄、见火则战；土局见水火＝熏蒸为云雾；见金木＝克泄为风凉；土空＝土崩金现，非水涸则主洪灾。〔通解上 p207｜PDF p222〕

### 2.7 冬天占雪

> 「**占雪之法以何云，太阴寅卯值用神。青龙暂时天后久，戊未白虎六合真。**」〔通解上 p207｜PDF p222〕

| 看什么 | 断什么 |
|---|---|
| **太阴**乘寅卯克日 | 主雪（太阴是霜雪之神） |
| **青龙** | 雨雪短暂 |
| **天后** | 雨雪**大而久** |
| 戊、未、**白虎** | 三白，主白雪 |
| **六合** | 花，类似雪花 |
| **巳、螣蛇** | 巳在巽，有风雪象；螣蛇对应也主雪 |
| 冬至后子加巳午 | 主雪、大雨 |

> 「**太乙翼蛇头有雪，天干遁起丙辛加。雨水入传无克战，玄后龙阴布六花。**」——课传出现天干**丙辛**合化水，也主雨水；冬季课传有雨水之象，天将又见玄武、天后、太阴、青龙，主雨雪。

### 2.9 一年的晴雨（古法，资料只给起法）

通解中 p635 列了几种特殊起课法：

- **大吉（丑）加元旦**（大年初一），看神后、太冲、天罡下，定雨月。
- **大吉加月朔**，视神后下为大雨日，太冲下为小雨日，申酉下为雨日，遇空亡则否。
- **月符加月建**：壬癸下为雨日，丙丁下为晴日（月符：春辰、夏未、秋戌、冬丑）。
- 岁朔所得月将加岁干、月将加月干，分别立课定一年、一月、一日。

原书评其中两种：「**值得我们去实践证之**」。⚠️ 本篇不展开，也没有案例。

## 三、八字怎么对上

**不对应。** 八字是一辈子的格局，看不出哪一天下不下雨；资料里也没有讲八字与天气的关系，**不写**。

## 四、案例

> 〔出处：《大六壬通解》中册 · 第六章第二节「壬课分类汇总 · 一 天时」〕

### 案例一：原书作者当天自占（庚寅年七月十九日，庚午日）

四柱：庚寅 癸未 庚午 庚辰；六月未将，甲子旬戌亥空。三传：**癸酉（勾陈）→甲子（螣蛇）→丁卯（太阴）**。〔通解中 p635–636｜PDF p271–272〕

> 断：「**天罡临玄武，且为正时，辰为水库，天罡指阴，酉金毕宿发用，正所谓：箕宿好风，毕星好雨，因此必然主雨**。……三传酉子卯，中末两传子卯相刑，主大雨，初传癸酉与末传丁卯冲克，庚日丁鬼临卯主雷电，因此今日必然有雷雨大风天气。」

| 盘上 | 断 |
|---|---|
| 天罡临玄武，辰为水库 | 阴，主雨 |
| 酉发用（毕宿） | 毕星好雨 |
| 子卯相刑，酉卯冲克，丁鬼临卯 | 大雨、雷电、大风 |
| 青龙临巳（上天） | **巳时**云层变化 |
| 癸酉临午，勾陈，被火克 | **午时**云层小雨，不久太阳出 |
| 亥临申（长生） | **申时**下雨 |
| 酉传出子 | **酉时**大雨 |

> **事实**：「出门时候多云，巳时末云彩顿集，午时下了几分钟云彩雨后，太阳出现，热到下午4点40分后，乌云起，雷声低沉成片，一会风势大起，雨起，**酉时变为大雨**。**此课极验**。」〔通解中 p636｜PDF p272〕

⭐ **这一课教什么**：断天气不只断「下不下」，要**拆到时辰**——每一个时辰的地支对应着盘上的哪个字，各自怎么动。

### 案例二：宋仁宗求雨（明道二年，甲寅日）

京城自三月不雨到六月，仁宗召苗公占之。甲寅日未将辰时。三传 **庚申（青龙）→癸亥（朱雀）→甲寅（天后）**。〔通解中 p636–637｜PDF p272–273〕

> 苗公达奏：「今日申时风云大作，雷声迸发，酉时收敛，甘泽不至。至**庚申日午时**，风雷后作甘泽浥尘，其势虽急，不至滂沱。直至**甲子日**，雷电风暴及一昼夜，大雨滂沱。」

| 盘上 | 断 |
|---|---|
| 发用**青龙**跨虎 | 有风云微雨 |
| 中传**朱雀**临亥（水火交战） | 发雷声 |
| 日上巳火乘太常土 | **不降雨**（当日） |
| 登明（水神）加申 | **庚申日**雨应 |
| 中传亥乘朱雀（火） | 雨来得急但**不滂沱** |
| 末传寅加亥，乘**天后**（云神） | 云起西北 |
| 甲子日卯加子，云雷相加，上得太阴金神 | **雷电风暴，大雨一昼夜** |

📝 **存疑**：原书编者注：此年六月十九壬子日大暑，若真有此课，月将当为午火胜光（与题目「未将」不合）。**案例是否真实有疑，只学其断法。**

### 案例三：冬季润下课（十二月庚申日）

庚申日甲申时，子将。三传 **甲辰（玄武）→戊申（青龙）→壬子（螣蛇）**，三传四课一片水，润下之局。〔通解中 p637｜PDF p273〕

> 邵彦和曰：「润下课，玄临子作用，中传龙又乘申，末又是夜青龙。若春占主水涨，**今冬占必有大雪**。果辛亥日雨，丙辰日大雪，戊午日晴而起风。」

| 盘上 | 断 |
|---|---|
| 润下局 | 阴雨雪 |
| 初传辰土水库 + 玄武 | 主雨雪 |
| 青龙临申（申为水母） | 下雨，**不以克制论** |
| 冬天占 | 雨变为**雪** |

⭐ **这一课教什么**：同一个课体，**春占是水涨，冬占是大雪**——要结合季节。

### 案例四：庚辰年浙江大旱（八月癸丑日，伏吟课）

八月癸丑日辰将辰时，占雨泽。伏吟课，三传 **癸丑（勾陈）→庚戌（白虎）→丁未（太阴）**。〔通解中 p637–638｜PDF p273–274〕

> 邵彦和曰：「**伏吟课，定是今日未时有云，一霎时起大风，又下小雨，明日甲寅，一日大风，下微雨，至乙卯日风止，大雨一日，水暴涨也。**」

| 盘上 | 断 |
|---|---|

### 其余可参考的例子

- **例十八**（辛巳年十二月壬子日寅时丑将，雪后天阴，问还会下雪吗）：三传庚戌（白虎）→己酉（天空）→戊申（青龙）。刘赤江断「**明后日必有大风雪**」：天罡加巳，巳主雪；白虎临河魁加亥发用克日；中传酉乃太阴本家，且乘雨师、风伯、飞廉三煞。原书解：课连茹（戊酉申返驾）为肃杀之气，阴凝为雪；冬天巳为花象，为雪花。「后果如占。」〔通解中 p647–648｜PDF p283–284〕

## 五、开盘确认与先断后验

**开口前只确认下面几件**（盘上看不出来）：

| 先确认 | 为什么 | 不确认会错在哪 |
|---|---|---|
| **问的是哪一天、哪个时段** | 2.4：应期和转晴日都按日算 | 问「周末」却起了今天的课 |
| **在哪个地方** | 天气跟地域有关 | 北方的课用在南方 |
| **现在是什么季节** | 案例三：同一课春秋冬断法不同 | 冬天的润下课当水涨断 |

**其余的不要先问，先看盘、先开口，再用对方的反应或当天实际验证**：

|---|---|---|

## 六、读完这一篇，你能断什么

1. **总势**：天罡指阴主雨、指阳主晴；阳将火神主晴，阴将水神主雨。
2. **风雨雷雪**：龙管雨、虎管风、蛇雀管雷电、太阴天后管雪。
3. **大小**：水旺克日大雨；水空亡生日干雨小。
4. **应期**：看水神和羊（未）鼠（子）所临；无水神看青龙地盘合处。
5. **转晴**：罡加四季＝将晴，去日几位是几日；丙丁下晴；久雨看雨神空绝日。
6. **课体看大势**：阴备晴、阳备雨；木局风、火局旱、金局阴晦、土局晴。

**还断不了的**（资料未讲）：**一年的晴雨**（古法有起法，无案例）；**降雨量具体多少**；**地域**怎么落进盘里；八字里「命主与天气」的对应。
