# 断事图 · 来意：客人坐下来，他到底想问什么

> **为什么要这一篇**：老师说过，**算不了认知以外的命**。来问的人嘴上说的，常常不是他真想问的：说「看看财运」，其实是生意上有一场纠纷；说「看看孩子」，其实是孩子早恋了；说「随便看看」，其实家里有人病了。资料里最见功夫的几题，都是**不等人开口，先把来意说出来**——「**把断语提前到问题之前**」〔【题192】〕。
>
> **这一篇是前面所有分类的入口**：先判来意，再翻到对应的那一篇。
>
> **这一篇分五部分**：
> **一、常识**：人一般为什么来、嘴上问的和真想问的、谁替谁来（这部分是常识，不是命理规则）
> **二、六壬怎么看来意**（本篇主角，出自《大六壬通解》）
> **三、八字怎么看来意**
> **四、案例**
> **五、开口之前的顺序**
>
> ⚠️ **读法**：第一部分是常识；第二、三部分只用老师资料，逐条带出处；资料没讲的写明。

---

## 一、常识：人为什么来

### 1.1 最常问的事（大致按多少排）

| 事 | 去哪一篇 |
|---|---|
| 钱、生意 | 财运、公司经营 |
| 感情、婚姻 | 感情、婚姻 |
| 工作、升迁 | 职业、官职 |
| 孩子（学业、婚姻、身体） | 子女、学业 |
| 身体 | 疾病、寿元 |
| 官司、纠纷 | 官司、小人是非 |
| 房子、搬家 | 房产 |
| 出门、出国 | 出行 |
| 丢东西、人走了 | 失物 |
| 家里老人 | 父母、寿元 |

### 1.2 嘴上问的和真想问的

| 嘴上说 | 常常其实是 |
|---|---|
| 「看看财运」 | 有一笔钱要不回来、生意要不要做、被骗了 |
| 「看看婚姻」 | 对方外面有人、要不要离 |
| 「看看孩子」 | 孩子早恋、不上学、要高考 |
| 「随便看看」「看看今年」 | 心里有件具体的事不好意思说 |
| 「我能不能发财」 | 想辞职创业 |
| 「看看身体」 | 刚查出什么病 |

### 1.3 谁替谁来

| 情况 | 样子 |
|---|---|
| 本人来 | 最常见 |
| **父母替孩子来** | 孩子学业、婚姻 |
| **妻子替丈夫来** | 丈夫事业、外遇、身体 |
| 子女替老人来 | 老人身体 |
| 一家人一个八字看全家 | 乡下叫「**全家卦**」 |

⭐ **跟断命有关的一点**：替人来问的，**盘是被问的那个人的**，但**来意是来问的那个人的**。资料里很多题背景就写着「母亲来测儿子」「妻子来测丈夫」「爷爷带孙子来测」。

## 二、六壬怎么看来意（出自《大六壬通解》）

### 2.1 先锋门：占时

> 「**正时是课传的第一引发点**。因此在预测来意与事情的发展主线上，有重大的引导作用。**古法多以之占断来意**。」〔通解上 p137｜PDF p152〕

先锋门＝正时（占时），「**课体未出，吉凶已露**」。

| 正时的情形 | 断 |
|---|---|
| 时乘空亡 | 多为**虚诈** |
| 时为驿马 | 多主**改动迁移** |
| 时日同辰 | 多主**迟疑偃蹇** |
| 冲辰冲日 | **颠沛流离** |

〔通解上 p137〕

### 2.2 课体已定诀来意

> 「**课体已定诀来意，日辰年命三传记。来克日干无差异，参合天官为真议。**」〔通解 p110-111 · 李九万六壬百章歌〕

| 看哪里 | 读什么 |
|---|---|
| **发用（初传）** | 「**初传发用是事物发端、来意切口和最先显现的动机**」〔象法速查〕 |
| 日、辰、年命、三传 | 一起记 |
| 来克日干的 | 就是那件事 |
| 天将 | 参合定性质 |

### 2.3 几个现成的格：一看就知为什么来

| 格 | 盘上 | 来意 | 出处 |
|---|---|---|---|
| ⭐ **鬼脱乘元格** | 日鬼或脱气乘玄武，发用尤准 | **来意占失脱**（丢东西、被偷被骗） | 毕法赋；例115 |
| **腹胎格** | 腹（丑）加胎神 | **来意妻必有孕** | 毕法赋 |
| **末助初作财格** | 末传助初传作日干之财 | 暗中有人以财相助；**来意占婚尤的** | 毕法赋 |
| 飞禽无翼 | 朱雀临巳、卯、辰并勾虎 | **求谋无成乃来意** | 金锁玉匙 · 通解下 p1076 |

### 2.4 来意不明怎么办

> 例22：「**有所为而占**（占者没说来意）」——「⭐ **来意不明时，看三传夹拱出什么**」；「**没露面的常是正主**」⇒ 断出是一笔旧年欠款〔通解下 p289〕

### 2.5 盘比问题大

> 例75：问的是开店求财，「**不是财利问题，是命上有大凶**」——「**日墓、日鬼、白虎压在本命上，就压过所问之事**」；「**盘会把最要紧的事顶到前面，别被问题牵着走**」〔通解下 p53〕

⭐ **对照常识 1.2**：嘴上问的是一件，盘上顶在前面的可能是另一件——**更要紧的那件先说**。

### 2.6 来意也约束取象

> 「来问者身份、问题场景，会约束同一符号的落点。**老农来占，酉可偏麦产、田财；商人来占，酉可偏财货、交易；病人来占，酉又可落口窍、血精、肺金**。」〔象法速查 · 讲义中册·来意占例〕
> 「**非占现类勿言**：不是所问事的类神，即使显于课传，也不宜牵强断入……问财不因白虎就断病，问病不因青龙就断财；**始终围绕来意**。」〔毕法象义〕

⚠️ 这两条和 2.5 看着相反，其实是一回事：**一般围绕来意取象；只有压在本命上的大凶，才越过来意先说**。

## 三、八字怎么看来意

### 3.1 先定问什么事

> 第0步：「**定住所问之事**：问财就切财，问身体就**八个字全当身体看**，别一边断婚姻一边断事业」；「**分析要专一**」〔第16章第0步〕
> 「⭐ **看身体全盘都是身体，看财运就切换成财运，要分析专一**」〔v课 754 讲【题436】〕

### 3.2 盘上能不能看出他为什么来

资料里有两题做到了「不等人问先说」：

| 题 | 怎么看出来的 | 出处 |
|---|---|---|
| ⭐ 【题192】 | 「命中子星临空亡，假子假女来继香」＋「**子星值年你去抱养**」——癸巳年巳（子星）值年 ⇒ 「**就是今年 → 所以她今年来问抱养的事**」 | 神煞 p13 |
| 【题58】 | 断「去年到今年要**犯点口舌官司，应该和房产或门面有关**」——反馈：门面地皮纠纷，「**来测就是想问此事**」 | 实战技巧 p26-27 |

背后的规则：

> 「●**应期：原局有什么样的字，就会应什么样的事。大运流年到位是应期。**」〔【题597】〕

⭐ **推演**（资料没有专门讲「八字看来意」）：既然**今年到位的字就是今年要应的事**，那么**来测那一年到位的字，多半就是他来问的事**——【题192】正是这么用的。**只有这一题是明说的，别当成通法**。

### 3.3 替人来问

| 背景 | 题 |
|---|---|
| 妻子来测丈夫，**代测全家**（全家卦） | 【题544】 |
| 一个八字断祖孙三代 | 【题460】 |
| 母亲来测儿子能不能结婚 | 资料多题 |
| 母女同来，半年后女儿单独来 | 【题168】 |

⭐ 全家卦要换**太极点**：「默认以日主为太极点；断祖上、断对象、断母亲的相好，才换太极点」〔第16章第0步〕。

## 五、开口之前的顺序

```
   ① 谁来的？替谁问？（常识 1.3）——盘是谁的、来意是谁的
        ↓
   ② 六壬：看占时（先锋门）、看发用，有没有现成的来意格（2.1–2.3）
      八字：看来测这一年到位的是哪个字（3.2，推演）
        ↓
   ③ 先说一句来意试探：「您是为 X 来的吧？」
        ↓   对 → 翻到对应那一篇
        ↓   不对 → 别硬撑，直接问
   ④ 盘上有没有压过来意的大凶？（2.5）有就先说
        ↓
   ⑤ 定住所问之事，分析专一（3.1）
```

⭐ 每一篇末尾的「**断之前先问清**」是**来意定了以后**要问的细节。

## 六、读完这一篇，你能做什么

1. 知道嘴上问的和真想问的常常不一样，**替人来问**要分清盘是谁的。
2. 六壬：先锋门（占时）、发用、鬼脱乘元等格；来意不明看夹拱；本命大凶压过来意。
3. 八字：定住所问之事；**来测之年到位的字**（【题192】，推演为通法要慎用）。
4. 取象**围绕来意**：同一个酉，农人是麦、商人是货、病人是肺。

**资料未讲**：八字看来意的通用方法（只有【题192】一例明说）。
