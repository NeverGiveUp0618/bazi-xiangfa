# 断事图 · 相貌：长什么样、胖瘦高矮、眼睛耳朵、穿着打扮

> **为什么要这一篇**：老师说过，**算不了认知以外的命**。相貌是断命里**最容易当场验证**的一样——资料里好几题都是「**开口第一句**」先说长相：「他的双眼特别小，细细就像两条缝」（同来的人都感到惊叹）〔【题27】〕。一句说中，后面的话对方就都听得进去。六壬书里也说：「断人断物，最容易当场被验证的就是颜色」〔第8课〕。
>
> **这一篇分四部分**：
> **一、常识**：描述一个人外貌的几个维度（这部分是常识，不是命理规则）
> **二、八字怎么看**：天干外形、肤色、眼睛耳朵、漂不漂亮、打扮、配偶的长相（出自资料，逐条带出处）
> **三、六壬怎么看**：来人、对方穿什么、什么颜色（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是常识；第二、三部分只用老师资料，逐条带出处。**相貌的资料不多，而且多是象法**——一个盘一个讲法，**别当公式套**。

## 一、常识：怎么描述一个人的长相

| 维度 | 常用的说法 |
|---|---|
| **身高** | 高、中等、矮 |
| **体型** | 胖、匀称、瘦；壮、单薄 |
| **肤色** | 白、黄、黑、红润 |
| **脸型** | 圆脸、方脸、长脸、瓜子脸 |
| **五官** | 眼睛大小、双眼皮、近视；耳朵；鼻子；嘴 |
| **气质** | 秀气、硬朗、文静、精神、憔悴 |
| **特征** | 疤、痣、残疾、毁容、秃顶 |
| **打扮** | 时髦、朴素、爱打扮、不修边幅 |

⭐ **跟断命有关的一点**：说相貌**只挑一两个最突出的说**（「眼睛特别小」「一只耳朵大一只小」），比面面俱到更准、更能当场验证。资料里的例子全是这样。

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬断的是**来人、对方、贼、走失的人**长什么样、穿什么。

### 3.1 颜色

> 「断人断物，最容易当场被验证的就是颜色……原书给的是**十干一套、十二支一套**」〔第8课四·B〕

十干：**阳干正色、阴干间色**——甲青、乙碧、丙赤、丁紫、戊黄、己绛、庚白、辛栗、壬黑、癸绿〔第8课〕。
⭐ 「**子午卯酉（四仲）是纯，寅巳申亥（四孟）是杂**」——四孟颜色不纯〔第8课〕。

### 3.2 课例

| 课例 | 断 |
|---|---|
| 例125 | 丢的是人参，**还说得出两个来客穿什么颜色** |
| ⭐ 例176 | 八年没消息的儿子，**几时回、穿什么、骑什么马** |
| 例180 | 侄子跟谁走的？盘上答：**一个姓杨的** |
| 例92 | 生男生女、**伤在哪只眼** |

⚠️ 「这些类象**只能参考取用，绝对不可照搬照用**」〔通解上 · 第8课〕。

## 五、断之前先问清

| 先问 | 为什么 |
|---|---|
| **时辰准不准，尤其子时** | 【题619】早子夜子相貌两样；也可以反过来用相貌定时辰 |
| **说的是本人还是对象** | 对象看配偶星、运带来的那一柱 |
| **先挑一处最突出的说** | 说中一处，比面面俱到更有用 |

## 六、读完这一篇，你能断什么

1. 天干外形：**己女身材好、辛女脸蛋好**、己喜乙辛相貌秀气。
2. 肤色：**甲乙庚辛白、丙丁红、戊己黄、壬癸黑**。
3. 眼睛：**左右对称两字＝一对眼**，看大小强弱、远近、伤没伤。
4. **财虚＝穿戴时髦**；早子夜子相貌两样，可反定时辰。
5. 六壬：**阳干正色、阴干间色**；能断来人穿什么颜色。

**还断不了的**（资料未讲）：身高、胖瘦、脸型的通用判法。
