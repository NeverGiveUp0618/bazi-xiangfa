# 断事图 · 时辰：报来的时间准不准、不准怎么定——排盘之前的那一关

> **为什么要这一篇**：断事图前面所有篇，都建立在**盘排对了**这个前提上。可现实里，客人报来的时间常常不准：**父母记的是农历、记的是「大概晚上」**；**用的是北京时间**；**正好卡在交节、子时**；**是剖腹产选的时辰**。小任把它列为排盘避坑清单第 1 条：「**未勾选真太阳时：导致时柱错误，十神全盘皆偏**」〔初中级课时笔记6 p6〕。时柱一错，子女、晚年、相貌全错；日柱一错，「我」就错了。
>
> **这一篇分五部分**：
> **一、常识**：出生时间是怎么来的、常见的错法（这部分是常识，不是命理规则）
> **二、排盘的规矩**：真太阳时 → 早晚子时 → 交节 → 断事时的年份（出自资料，逐条带出处）
> **三、时辰不准怎么定**：列候选、拿事实反推、几个现成的判别点（出自资料）
> **四、剖腹产、选时辰**
> **五、问诊清单**
>
> ⚠️ **读法**：第一部分是常识；第二到四部分只用老师资料，逐条带出处；**资料里有三处口径不一，照录不替老师定**。
> 📎 详细原文见命理精讲笔记〔八字07-排八字用北京时还是地方时〕，这一篇是它的断事图版。

## 一、常识：出生时间是怎么来的

### 1.1 时间的来源

| 来源 | 可靠程度 |
|---|---|
| **出生医学证明** | 一般精确到分钟，较可靠 |
| **医院病历** | 可靠 |
| **父母记忆** | 常只记得「早上」「半夜」「天快亮」 |
| **老人口述** | 多是农历、按「鸡叫」「吃早饭」这类说法 |
| **身份证** | 只有日期，没有时辰，且常有登记错的 |

### 1.2 常见的错法

| 错在哪 | 样子 |
|---|---|
| **农历公历混** | 报了农历当公历排 |
| **北京时间没换算** | 西部出生的人最容易差一个时辰 |
| **夏令时** | 中国 1986–1991 年夏季实行过夏令时（钟表拨快 1 小时）——**这几年夏天出生的要减 1 小时** |
| **「晚上」「凌晨」说不清** | 「18 号晚上」可能指 18 号凌晨 |
| **记错日子** | 身份证生日、上户口的生日与实际不一 |
| **出生地记错** | 出生在外地医院 |

⚠️ **夏令时这一条是常识，资料里没讲**（大任资料检索「夏令时」0 处命中〔笔记07〕）。

### 1.3 古人怎么说时辰

> 「**半夜子时 → 鸡鸣丑时 → 天蒙蒙亮寅时 → 日出卯时 → 早餐辰时 → 日高巳时 → 正晌午时 → 日斜未时 → 后晌申时 → 日落酉时 → 掌灯戌时 → 入睡亥时**」〔小任 · 初中级课时笔记21 p2〕

⭐ 老人说「鸡叫的时候生的」，就按这个对。这口诀本身就是**当地太阳**说了算——跟北京时间无关。

## 二、排盘的规矩（出自资料）

### 2.1 ⭐ 真太阳时

> 「**排八字应以当地时间为准**，即出生时的地域时间。**真太阳时与北京时间有所不同，应以真太阳时为准**。」〔小任 · 26排八字大运 p1〕
> 「**北京时间仅为行政政策，八字接的是当地天地之气。**」〔小任 · 初中级课时笔记16 p5〕

| 项 | 内容 |
|---|---|
| 基准经线 | **东经 120°**（北京时间的实际基准） |
| 换算 | **每 1 经度 ＝ 4 分钟；偏西减、偏东加** |
| 量级 | 中国东西跨约 60° → 最大差约 4 小时；**新疆与中原差 2–3 小时** |
| 工具 | 「必须**手动输入出生地、勾选真太阳时**，核对排盘结果」 |

〔小任 · 初中级课时笔记 5、6、21〕

⭐ **例**：「乌鲁木齐北京时间 12:00 实为巳时；1990-01-01 01:05（北京时间）实为 1989-12-31 22:52，**差一天、两个八字**」〔小任 · 初中级第2课〕

### 2.2 ⭐ 早晚子时（换算完必须重判）

> 「**真太阳时换算后必须重新判定**」〔小任 · 初中级课时笔记6 p6〕——一换算就可能跨过 23:00。

| 时段 | 小任课堂原话的排法 | 时干 |
|---|---|---|
| **23:00–24:00**（前子时、夜子时） | **日柱换为次日** | 按当日日干五鼠遁，**再顺推一位** |
| **00:00–01:00**（后子时、早子时） | 次日 | 按次日日干正常起 |

| 日干 | 后子时 | 前子时 |
|---|---|---|
| 甲・己 | 甲子 | 丙子 |
| 乙・庚 | 丙子 | 戊子 |
| 丙・辛 | 戊子 | 庚子 |
| 丁・壬 | 庚子 | 壬子 |
| 戊・癸 | 壬子 | 甲子 |

〔小任 · 高级课时10〕

⚠️ **三说并存**（照录，不替老师定）：

| 口径 | 23–24 点的日柱 |
|---|---|
| 小任笔记5、整合精修 | 前一日 |
| 小任笔记6、⭐ 高级课时10 老师原话 | **换次日** |
| ⭐ 大任 2012 面授 p11 | **仍算当天**，但**按次日日干起时柱** |

⭐ **实战上两盘都排，拿反馈反推**（【题547】、【题495】的做法）。

### 2.3 交节卡点

> 「**交节当日出生者**，需结合出生地**南北**（**北方偏晚、南方偏早**）或**列双八字校对**。务必通过**已发生大事反推验证**月柱。」〔小任 · 初中级课时笔记21 p2〕
> 「遇到这种换气时节，又是在换气时辰的，**最好排两个八字看哪一个符合实际**」〔v课 800 讲【题495】〕

⭐ 真太阳时修**经度**（东西），交节卡点修**纬度**（南北）——两件事，别混。
例：惊蛰前后月柱在戊寅与己卯之间，「**北方交节偏晚，不能盲信软件**」〔公开课课时笔记3 p6〕。

### 2.4 断事时客人报的年份

> 母说：是**去年腊月二十**办的婚事……我说：**哪其实已是今年（丁亥）了，因已过了立春前，我们看命是按交节看的**〔大任 · 04断命例题解 p46〕

客人报的任何时间（结婚、出事、买房），**落在腊月或正月**的，必查当年立春时刻。见「流年」篇 1.2。

### 2.5 起运、交运

| 规则 | 出处 |
|---|---|
| 起运天数**含出生当日**（「**生人当天就算一天，一舍二进**」） | 大任 · 2012面授 p11 |
| 交大运时间以**年柱纳音**定（木大寒当日寅时、火清明前三天午时……） | 同上 |
| 换运精确到月：「土命芒种后九天未时交运」 | v课 804 讲【题498】 |

## 三、时辰不准怎么定（出自资料）

### 3.1 总方法

> 「**定时辰是综合功力的体现**。通过对比疑似时辰在**婚姻、财运、六亲、伤病灾**等方面的**断语差异**，以『**符合历史事实**』者为真时辰。」
> 「**实操步骤**：列出可能时辰 → 分别推演关键人生节点 → 对照命主反馈 → 锁定唯一时辰。」〔小任 · 初中级课时笔记21 p2〕
> 「**定时辰没有单独的绝招**，若说有秘诀就是『**因地制宜**』：拿前三柱的特征分别配上可能的时辰，推各自会发生什么事，再用实情反推」〔小任 · 公开课第1课〕

### 3.2 现成的判别点

| 用什么判 | 例子 | 出处 |
|---|---|---|
| ⭐ **兄弟姐妹的血缘** | 寅卯之间定时：卯时则卯辰相穿 ⇒ **同父异母的弟弟**；反馈属实，定卯时 | 小任 · 公开课第1课 |
| ⭐ **相貌** | 「**如果是早子时人不漂亮，夜子时人漂亮，可以对号入座**」 | 面授【题619】 |
| **皮肤、性格、经历** | 「先点两件事定时辰：**庚子时则皮肤白、俊、爱运动、桃花旺但不换婚**；36 岁前公家单位、36 岁后离乡做实体合伙」⇒ 反馈 37 岁去佛山合伙开厂，定庚子时 | 小任 · 初中级第21课 |
| **一件大事** | 「辛卯年喝一瓶啤酒睡一晚死掉」⇒ 判定立秋后那盘 | 【题495】 |
| 离婚、流产、得子 | 两盘并排拿事实套 | 【题547】 |

⭐ **读法**：挑**两盘差别最大**的那一处去问——相貌、兄弟姐妹、哪一年出过大事。问一两件就能定。

### 3.3 问诊技巧

> 「他只要一说是 23 点多或 0 点多……**我们要加上一句：『天亮是啥时候？』**」〔小任 · 高级课时10〕

## 四、剖腹产、选时辰

| 规则 / 案例 | 出处 |
|---|---|
| ⚠️ 台湾大师 3 万元选的时辰，说「富贵双显」——实际**午火被晦，心脏病，先天性的**；「⭐ **看身体、六亲一定要参考空亡**」 | 面授【题712】 |
| 剖腹产选的时辰：**庚金喜午临空亡，双卯破午，灭了阳** ⇒ 心肺病，到目前仍然不行 | 面授【题714】 |
| ⭐⭐ 「**选时辰要必须兼看六亲，钱可赚钱，但要负责，不然就要遭报应的**」 | 大任 · 面授 p76 |
| 寿元篇：「拿到八字**第一件事先判寿元**」 | 小任讲义 p44 |

⭐ **对照常识**：剖腹产选时辰现在很常见。资料的两例都是**只看富贵、没看身体和六亲**出的事——选时辰要先过**寿元、身体、六亲**这几关。

⚠️ **资料未讲**：剖腹产的人八字算不算数（有人说人为选的不准）——资料里的两例**照样按选出来的时辰断，而且断中了**。

## 五、问诊清单

```
① 出生地（省市，最好到县）——「在什么地方出生都要写」
② 公历还是农历？精确到几点几分？来源（出生证明、父母记忆）？
③ 1986–1991 年夏天出生的 → 问有没有按夏令时记（常识）
④ 23 点多或 0 点多 → 问「天亮是啥时候？」
⑤ 换算真太阳时 → 重判是否跨 23:00
⑥ 生日靠近交节 → 查精确交节时刻，必要时列双八字
⑦ 时辰记不清 → 列候选时辰，挑差别最大处问一两件事反推
⑧ 是不是剖腹产选的时辰
```

## 六、读完这一篇，你能做什么

1. 排盘先过**真太阳时**（东经 120°，每度 4 分钟，西减东加）。
2. 换算后**重判 23:00**；早晚子时三说并存，**两盘都排拿反馈反推**。
3. 交节卡点**南北修正、列双八字**；客人报的腊月正月**按立春换年**。
4. 时辰不准：**列候选、推差异、问事实**——兄弟血缘、相貌、大事。
5. 选时辰要**兼看六亲、身体、空亡**。

**资料未讲**：夏令时；剖腹产时辰算不算数（资料是照样断）。
