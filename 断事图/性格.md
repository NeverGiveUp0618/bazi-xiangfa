# 断事图 · 性格：这个人是什么样的人

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。性格是最容易「说什么都像」的一项——说人「外刚内柔」「有时开朗有时安静」，谁听了都觉得准。要断得有用，得知道性格有哪几个维度、哪些是天生的哪些会变、什么样的说法才算具体。资料里的断语都很具体：「**要面子、重名气**」「**禄上带财人很小气，但一穿花钱就大方**」「**比劫多，处理问题易糊涂**」——这才是能验证的性格判断。
>
> **这一篇分五部分**：
> **一、常识**：心理学怎么描述性格、性格和行为的关系（这部分是常识，不是命理规则）
> **二、八字怎么对上**：看哪里 → 日干本性 → 十神心性 → 虚实与面子 → 几组具体的性格判断 → 神煞与气势（全部出自资料，逐条带出处）
> **三、六壬怎么看**
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的心理学常识写的；第二部分只用老师资料。**常识和资料的对照是我配的，原话为准**。
>
> ⭐ 小任的一句话：「每个人的**天性由天命决定**——命是先天，性格是后天慢慢往那个方向发展；跑动的命，闲不住就是他的天性。」〔小任 · 高级第 9 课〕

## 一、常识：性格是怎么回事

### 1.1 心理学常用的五个维度

心理学里用得最多的是「**大五人格**」，把性格分成五个维度，每个维度都是一条连续的线，不是非此即彼：

| 维度 | 高的一端 | 低的一端 |
|---|---|---|
| **外向性** | 爱热闹、话多、精力足、喜欢人群 | 喜静、话少、独处充电 |
| **宜人性** | 随和、体贴、信任人、乐于帮忙 | 挑剔、多疑、好争、只顾自己 |
| **尽责性** | 守规矩、有计划、可靠、自律 | 随性、拖延、不守规则 |
| **开放性** | 好奇、有想象力、爱新东西、反常规 | 务实、保守、喜欢熟悉的东西 |
| **情绪稳定性** | 沉得住气、不易焦虑 | 易焦虑、易怒、情绪起伏大 |

⭐ **一个人通常是几个维度的组合**，比如「外向但多疑」「守规矩但焦虑」。

### 1.2 几个常识

| 常识 | 说明 |
|---|---|
| **性格既有天生的一面，也受成长环境影响** | 家庭、经历、职业都会改变一个人 |
| **人前人后不一样** | 外人看到的样子和家里的样子常有差别 |
| **性格没有绝对好坏** | 多疑的人做审计合适，随和的人做谈判吃亏 |
| **同一个特点两面看** | 「固执」也是「有主见」，「冲动」也是「果断」 |
| **具体的才能验证** | 「小气」「要面子」「爱打扮」能对上；「复杂」「矛盾」说了等于没说 |

⭐ **跟断命有关的一点**：资料里的十神心性表正好**每个都分「正」「负」两面**（见 2.3），和「同一个特点两面看」是一个意思；资料也区分「**天干表象、地支内在**」（见 2.1），对应「人前人后不一样」。

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 看哪里

> 「⭐ **看性格只看日元近身的字**：**日支（内心世界）为主，其次月干、时干（外在表现）**，年干最远；**离日元远、或落空亡的十神，多主外部人事环境，不轻易断成本人性格**。」〔小任 · 中级班讲义 p188、p194、p199〕
> 「四柱八字中，**天干代表人的表象**，如外表特征、性格表象、容易被外人看出来的显著特点；而**地支代表人的内在**，如内心世界、与家人的关系等。」〔教材第 4 章〕

| 位置 | 管什么 | 对照常识 1.2 |
|---|---|---|
| **日干** | 我的能力、性格、想法 | 本人 |
| **日支** | **内心世界**（为主） | 家里的样子、真实的自己 |
| 月干、时干 | **外在表现** | 人前的样子 |
| 年干、空亡的字 | 多主外部环境，**不轻易断成性格** | — |

⭐ **坐下十神看本性**：「坐七杀多霸道，坐正印多稳重，坐财星重感情（但不能孤立地看）；**藏干看更深一层**——壬辰日辰藏戊乙癸，内心兼有七杀、伤官、劫财三种特质」〔小任 · 公开课第 3 课〕。

### 2.3 十神心性：正面与负面

〔小任 · 中级班讲义 p186–217〕

| 十神 | 心性 · 正 | 心性 · 负 |
|---|---|---|
| **正官** | 正直守法、责任心、理性、自省 | 墨守成规、不会变通、从众、压力敏感 |
| **七杀** | 野心、魄力、闯劲、讲义气、嫉恶如仇 | 冲动暴烈、多疑记恨、独断霸道 |
| **正印** | 仁慈包容、勤恳奉献、忍耐、重情 | 依赖、懒惰、思想固化、逃避压力 |
| **偏印** | 推理破译强、创新、洞察、玄学天赋 | 缺共情、多疑、孤独封闭、外冷内热、焦虑 |
| **正财** | 务实保守、求稳、专一、勤俭持家 | 吝啬、目光短浅、患得患失、控制欲强 |
| **偏财** | 敏锐抓商机、敢冒险、慷慨、重义轻财 | 缺持久、情感外放、消费冲动 |
| **比肩** | 自尊、重情义、执行力强、求公平 | 固执、刚愎、排斥干涉、自私 |
| **劫财** | 果敢、魄力、讲义气、应变快 | 冲动鲁莽、嫉妒攀比、不守规矩 |
| **食神** | 知足、温和、善解人意、有雅兴 | 迁就内耗、优柔、逃避现实、沉迷享乐 |
| **伤官** | 极聪明、才华横溢、反权威、创新 | 争强好胜、嫉妒、情绪化、好大喜功 |

**对照常识 1.1**（⚠️ 配对是我做的，供参考）：

| 大五维度 | 十神里接近的 |
|---|---|
| 尽责性高 | 正官、正财 |
| 开放性高 | 伤官、偏印 |
| 宜人性高 | 食神、正印 |
| 情绪稳定性低 | 七杀、劫财、伤官的负面 |
| 外向性高 | 丙、偏财 |

**一条横贯十神的分法**：「**印表示保守，枭表示开发**……**食伤、官杀，正的都是保守，偏的都表示开发**。」〔2012 面授 p20〕——**正＝保守，偏＝开发**。

## 三、六壬怎么看

六壬是**一事一课**，不专门断人的性格。断课里要知道**对方是什么样的人**时，看对方类神所乘的**天将**：

| 天将 | 性情（第 9 课、象法速查·天将类象白话） |
|---|---|
| 贵人 | 统摄、官贵、裁决 |
| 螣蛇 | 缠绕、虚惊、反复 |
| 朱雀 | 表达、传播、口舌 |
| 六合 | 连接、和合、媒介 |
| 勾陈 | 勾连、迟滞、争讼 |
| 青龙 | 生发、财喜 |
| 天空 | 虚无、不实 |
| 白虎 | 裁伤、刚猛 |
| 太常 | 承礼、酒食 |
| 玄武 | 隐秘、欺诈 |
| 太阴 | 隐匿、精细 |
| 天后 | 滋养、阴柔 |

旧版资料的说法：「**地支 = 物理实体（名词），天将 = 属性标签（形容词）**，两者拼接输出具体画面」〔附篇 80 · 旧版入门与原理〕——支神定是什么人，天将定这人的状态与性情。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁的性格**：本人、配偶、孩子、合作对象？ | 太极点不同 | 把孩子的盘断成父母的脾气 |
| **问性格是为了什么**：择偶、用人、教育孩子、自我了解？ | 同一个特点，放在不同的事里好坏不同 | 「多疑」在审计是优点，在婚姻是问题 |
| **先说一两条让对方确认** | 老师：先点两件事校准 | 一上来说一长串，没法验证 |
| **人前人后有没有差别**？ | 2.1：天干表象、地支内在 | 只说外表，说不中内心 |

⚠️ **说话的分寸**：性格的负面（自私、说谎、人品不好）要换成提示式说法；而且性格会随经历变化，**说倾向，不下定论**。

## 六、读完这一篇，你能断什么

1. **看哪里**：日支内心为主，月干时干外在；年干、空亡多是环境。
2. **日干本性**：十天干人性表。
3. **十神心性**：每个十神分正负两面；正＝保守、偏＝开发。
4. **面子与虚荣**：官虚透要面子；财虚男追潮流、女爱打扮。
5. **具体判断**：任性、小气、大方、吃苦、聪明、不专一、研究型、自私、暴躁……
6. **矛盾在哪**：破落哪一柱，就跟那一柱的人有矛盾。
7. **神煞**：华盖、孤辰寡宿喜静。
8. 六壬：看对方类神所乘天将的性情。

**还断不了的**（资料未讲）：性格怎么随大运变化；内向外向有没有专门的判据（只能借丙、驿马、孤寡华盖）；心理问题（抑郁焦虑）与性格的分界（另见「疾病」篇的资料未讲）。
