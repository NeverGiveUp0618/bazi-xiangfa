# 断事图 · 婚姻：有没有、好不好、几次、什么时候

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。现在的婚姻样子很多——恋爱多年不结婚、同居、异地、分居不离、离了又复婚、再婚带孩子、丧偶。盘上看出「宫两现」，你得知道它可能是**两次婚**，也可能是**一次婚加一段同居**，还可能是**两套房子两个家**——这些在现实里是完全不同的事，说错一个就对不上。
>
> **这一篇分五部分**：
> **一、常识**：婚姻在法律上和生活里是怎么回事（这部分是常识，不是命理规则）
> **二、八字怎么对上**：宫与星 → 有没有 → 好不好 → 坏到什么程度 → 几次 → 对方什么情况 → 桃花 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**：占这一门婚事成不成（出自《大六壬通解》）
> **四、案例**：题库里的命例按情况排好
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的法律规定和社会常识写的；第二、三部分只用老师资料，**资料没讲到的格子写明「资料未讲」**，不自己编规则。并排放的「对应」是我把常识和资料原话摆到一起方便对照——**原话为准**。

## 一、常识：婚姻是怎么回事

### 1.1 法律上的婚姻

| 事项 | 规定（民法典婚姻家庭编） |
|---|---|
| **法定婚龄** | 男不早于 22 周岁，女不早于 20 周岁 |
| **怎么才算结婚** | 到婚姻登记机关**登记**，领结婚证。办了婚礼没登记，法律上不算夫妻 |
| **同居** | 没登记就一起生活，法律上不是婚姻；分手时只按一般财产、子女关系处理 |
| **重婚** | 有配偶又和别人登记结婚，或以夫妻名义同居，是犯罪 |
| **夫妻共同财产** | 婚后所得一般归夫妻共有（个人婚前财产、明确约定的除外） |
| **离婚的两条路** | ① **协议离婚**：双方到登记机关申请，有 **30 天离婚冷静期**，期满再一起去领离婚证；② **诉讼离婚**：一方不同意，到法院起诉 |
| **彩礼** | 没办结婚登记、或登记了但确实没有共同生活、或婚前给付导致**给付的一方**生活困难的，可以要求返还 |
| **复婚** | 离了以后再登记结婚 |

### 1.2 婚姻的几个阶段

```
  认识 → 恋爱 → （订婚、谈彩礼）→ 登记 → 办婚礼 → 婚后磨合 → 生育 → 长期相处
                                   ↘ 中途可能：分手、退彩礼、悔婚
```

- **初婚年龄**：近些年中国人平均初婚年龄在 **28 岁上下**（2020 年人口普查），城市更晚。「早婚」「晚婚」要放在这个背景里说。
- **登记和办酒是两件事**：有人先办酒后登记，有人只登记不办酒。

### 1.3 婚姻的各种实际状态

现实里的「婚姻」远不只「结了」「离了」两种：

| 状态 | 是什么 |
|---|---|
| **正常婚姻** | 登记、同住、关系稳定 |
| **名存实亡** | 没离婚，但感情没了，各过各的 |
| **分居** | 没离婚，分开住（感情原因或工作原因） |
| **异地** | 夫妻在两个城市 |
| **同居不婚** | 一起生活多年不登记 |
| **婚外情** | 有配偶还和别人有感情、性关系 |
| **离婚** | 法律上解除 |
| **丧偶** | 配偶去世 |
| **再婚** | 离婚或丧偶后再结 |
| **再婚家庭** | 一方或双方带着前一段婚姻的孩子 |
| **不婚、单身** | 一直没结，或离了以后不再结 |

⭐ **跟断命有关的一点**：资料里专门区分了这些——「**有位置没名分**（情人、同居、多个家）」「**分居多年却没离**」「**离婚不离家**」「**同居九年未婚**」「**嫁了个离过婚带小孩的男人**」。断「两次婚」之前，先想清楚是哪一种。

### 1.4 婚姻出问题的常见原因

| 原因 | 现实里的样子 |
|---|---|
| **性格、三观不合** | 吵架、冷战 |
| **第三者** | 一方或双方出轨 |
| **经济** | 一方没收入、欠债、为钱吵 |
| **家庭** | 婆媳、娘家婆家插手 |
| **距离** | 长期异地 |
| **生育** | 不孕不育、对要不要孩子意见不同 |
| **健康** | 一方重病、残疾 |
| **家暴、恶习** | 赌、酗酒、打人 |

⭐ **跟断命有关的一点**：资料里有「**坏的是财星，那就是经济问题**」（【题430】）、「**老婆被人合走**」（【题669】）、「**申亥穿＝距离拉远**」（【题659】）、「**丈夫是个花心人**」——同样是「婚姻不好」，原因不同，盘上的样子也不同。

### 2.2 恋爱对象还是结婚对象

**对照常识 1.2**：谈过的人不一定成为配偶。

> 「凡与**日干或配偶宫有关系**的星方可当配偶星看，**如无关系，只表示婚前朋友**。」〔婚姻篇 p2〕
> 关系＝「**刑、冲、克、害、合、生，都叫关联**」〔十八道法门 p52〕

⭐ **年上桃花是正常恋爱，不是婚外情**〔v课第 705、687 讲〕——年柱对应少年时期，那时候的感情就是谈恋爱。

### 2.3 好婚姻长什么样

> 1. **宫位要安静**——不能被刑、冲、破、穿坏或六合，暗合他星也不宜杂透多现
> 2. **宫制星者为好婚姻**——男命比劫能制财，女命用伤官能制官。⚠️「**如果宫制星反制不住，反为坏婚姻**」
> 3. 原局官为所忌之神，被星制之吉者，婚姻好
>
> 〔婚姻篇 p2〕

**对照常识**：「宫制星」＝**家里说了算的一方管得住另一方**——【题211】「她管丈夫，丈夫也喜欢她管」。

⚠️ **宫被制不一定坏**：先看那个宫本身是好东西还是坏东西——午宫是坏东西，制了反而是好婚姻〔面授 ·【题600】〕。

### 2.4 坏到什么程度：离婚、一辈子不好、还是丧偶

这一步最要紧，**对照常识 1.3 的各种状态**。

> 「**宫也坏、星也坏 ＝ 克丈夫，要死人了**；**宫坏了 ＝ 一辈子婚姻不好**；**星坏了 ＝ 离婚了、换人了而已**（离婚不离家）。」
> 「宫是家，星是人：**家坏了换个人都不行；家没坏，星坏了换个人就行**。」〔v课第 705 讲〕

| 现实 | 盘上 | 出处 / 案例 |
|---|---|---|
| **离婚、换人** | 只坏**星** | v课 705 讲 |
| **一辈子婚姻不好**（换几个都不好） | 坏了**宫** | 【题403】「宫坏了，来谁都坏婚」 |
| **丧偶、克配偶** | **宫星同坏** | 十八道法门 p38「宫星同坏六亲遭殃」 |
| 婚姻宫里**正星**被坏 | **容易死亡** | v课第 736 讲 ·【题428】 |
| 婚姻宫里**偏星**被坏 | **顶多离婚** | 同上 |
| **婚姻不坏，是经济问题** | 宫没坏、坏的是财星 | 【题430】 |

**判断「坏了没有」的几道筛子**：

| 筛子 | 内容 | 出处 |
|---|---|---|
| ① **单一作用不断坏婚** | 要两个以上条件叠加 | 教材第 14 章三 |
| ② **穿的力度** | 克穿（子未、丑午、酉戌、卯辰）**重**；生穿（申亥、寅巳）**轻** | 同上 |
| ③ **扛不扛得住** | 「**金木为形怕伤，水火为气不怕**」 | v课第 728 讲 ·【题418】【题419】【题421】 |
| ④ **旁边有没有帮手** | 同气之字来救，降一档：离婚而非丧偶 | 【题401】↔【题403】 |
| ⑤ **日主坐库** | 「凡日主坐库没有刑冲者婚姻都不吉，**四库必须坏**——除**甲辰、丁未、乙未、丙戌**不可以坏以外」 | 中级班 p27 |
| ⑥ **女命坐养地** | 辛丑、庚辰、甲戌、乙未四柱，婚姻不好的概率大 | v课第 719 讲 ·【题410】 |

### 2.5 有没有婚姻、会不会单身

**对照常识 1.3 的「不婚、单身」「同居不婚」**：

> 无婚姻的三种情况：**① 一生独身　② 有短暂婚史但基本独自生活　③ 有情人、有性交往，无婚**〔教材第 14 章七〕

**独身十一型归成三个机制**（十八道法门 p52–53）：

| 机制 | 包括 | 现实里多应 |
|---|---|---|
| **宫进不去**（门被占、被制、被埋） | 夫妻宫被比劫印占住；宫制星制不住反被坏；宫是星的墓；财煞聚合；劫坐三刑 | **一生独身** |
| **星不对版** | 宫里坐正星却透出偏星（「水中捞月无婚姻」）；三食神（只谈恋爱不结婚） | 恋爱不断、成不了 |
| **合而不成** | 女命关了财门；日月双合（一直努力求婚／一直在等最后放弃）；月柱正印坐寡宿 | **有情人无婚** |

**面授补充**：

| 情况 | 盘上 | 出处 |
|---|---|---|
| 根本没有婚姻 | **星和宫相伤**（丑午穿） | 【题657】 |
| 但只要星在别处有分身落在我家，婚姻就成立 | 同盘月干换成丁 ⇒ 丈夫在自己的家中 | 【题658】 |
| 无婚之命靠「自己主动」救回来 | 「如果没有乙庚合，就是无婚之命」 | 【题655】 |
| 身体有问题、不结婚、自我封闭 | **禄入墓** | 面授 例69 |
| 无婚但不缺异性 | 坐库不开，年月的财都入坐下墓库 | 【题256】 |

### 2.6 女命：无财不养官

> 「**女命看官杀和财，重点看财**——没财生官，就是**养不住丈夫**；坏了财就叫「**关财命**」，坏婚。」〔v课第 705 讲〕
> 「女命**财是情缘线，财是感情**；合财、坐财的人重感情。」〔v课第 696 讲〕
> 「**财星一断财门关**」〔v课第 745 讲〕

**对照常识**：财在女命里，可以理解成**感情和供养丈夫的那条线**（这是我的概括，不是原话）——财断了，感情没了来源，婚姻就养不住。

⚠️ **断命纪律**：「**不能又闭库又开库**」——断这件事用了「闭」，就不能再拿「后面开了」来抵消〔v课第 719 讲〕。

### 2.7 几次婚姻

> ⭐ **宫回答「有几个位置」，星回答「有几个人」。**〔教材第 14 章一，据 21 个命例归纳〕

| 现实 | 盘上 | 案例 |
|---|---|---|
| **真的多次婚** | 宫两现 **＋** 星也两现；或两个宫互相冲刑 | 【题228】「宫星两现，必定离婚」；【题225】；【题114】 |
| **多个家、少次婚**（一次婚＋情人、同居、分居） | 宫多**而星只有一个** | ⭐【题224】分居多年却没离；【题11】九个家七次婚 |
| **仍是一次好婚姻** | 两个宫相合或互不干扰，星也安静 | 【题211】【题215】 |
| **一次也不成** | 宫虽两现，星把宫坏了 | 【题257】 |

⚠️ **看到日干伏吟就断二婚，会连错三题**（【题211】【题215】【题257】）。

### 2.11 别忘了另一本账

> ⚠️ **事业账与六亲账要分开记**：同一个字，**做功时是好事，当六亲看时就是伤**；**做功层次越高，往往六亲身体越吃亏**——「没有十全十美的事」。〔教材第 14 章七·C ⑤〕

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一门婚事**成不成、这个人靠不靠谱、这段感情能不能长久。

### 3.1 主线：财为妻、官鬼为夫

> 「**夫卜妻姻成不成，财居旬后总无情。女推夫婿将何断，鬼坐天中同此评。**」
> 注：「**财为妻，官鬼为夫**……**财官无气空亡，则婚姻失败**。」〔通解上 p217｜PDF p232〕

| 谁占 | 看什么 | 忌 |
|---|---|---|
| 男占妻 | 妻财；天将看**青龙** | 财空亡、无气 |

### 3.2 成与不成：两法对

> 「**传将生合百年配，干支刑克朝夕背。男女年命孰相加，欲其事遂两法对。**」〔通解上 p217｜PDF p232〕

⭐ **两法对**＝**干支之间**看一遍生合刑克，**男女年命上神之间**再看一遍，**两处都吉才是真吉**。

| 例 | 情形 | 断 |
|---|---|---|
| 甲申日 | 干上巳为支之长生，支上亥为干之长生 | 吉 |
| 癸酉日 | 干上辰与支六合，支上子与干六合 | 吉 |
| 丙寅伏吟 | 干上巳为支所刑，支上寅又刑其干神 | 凶 |
| 丁丑日 | 干上午与支六害，支上子与干六害 | 凶 |

**对照常识**：干＝我、支＝对方（或对方那个家），干支生合＝两个人合得来；年命再合＝两家人也合得来。

### 3.3 一条凶象

> 「凡**天后在三传日辰，而其阴神作虎者，即日克妻或大凶厄**……若占妻病必死。」〔通解上 p220｜PDF p235〕

⚠️ **资料未讲**：六壬怎么断**婚后**过得好不好、几次婚——第 22 课只讲了占婚事成不成。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁**：本人、子女、父母？ | 太极点不同，看的宫星不同 | 把女儿的婚姻断到母亲身上 |

## 六、读完这一篇，你能断什么

1. **有没有婚姻**：宫进不去、星不对版、合而不成三种单身。
2. **好不好**：宫要安静、宫制星；宫被制先看宫是好是坏。
3. **坏到什么程度**：星坏＝离婚换人；宫坏＝一辈子不好；宫星同坏＝丧偶。
4. **几次**：宫数位置、星数人；分出真多婚、多个家、仍是一次好婚。
5. **对方的情况**：有没有家庭、离过婚带孩子、死过对象、被人合走。
6. **桃花**：不看子午卯酉，看禄合财官、食伤合财官。
7. **什么时候**：合逢冲、冲逢合；大运定性、流年定年。
8. 六壬看**这一门婚事**：财官空亡则败，干支、年命两处都合才真吉。

**还断不了的**（资料未讲，下次听课可以问）：
- **复婚**有没有专门的象？
- **异地**和**分居**怎么分？资料有「申亥穿＝距离拉远」，但没讲是工作原因分开还是感情原因分开。
- **合婚**（两人八字对照）资料里有零散用例，没有成套方法。
- 六壬怎么断婚后好坏、几次婚。
