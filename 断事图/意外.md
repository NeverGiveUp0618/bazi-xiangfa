# 断事图 · 意外灾险：车祸、摔伤、被打、水火、中毒、自伤

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「有血光之灾」在现实里可以是车祸、从高处摔下、被人打伤、开刀、溺水、煤气中毒、被狗咬，也可以只是**磕破点皮**。不先知道意外有哪几类、哪个年龄段容易出哪一类、怎么分轻重，盘上看出「冲穿」，你只能说「小心」，说不出该防什么。
>
> **这一篇和别篇的分工**：「疾病」讲**病**（含手术、车祸外伤一小节）；「官司」讲**牢狱**；这一篇专讲**突然来的外伤和凶险**，把车祸、摔伤、被打、水火、中毒、自伤、小儿关放在一起。
>
> **这一篇分五部分**：
> **一、常识**：意外的几类、各年龄段风险、轻重怎么分、出了事怎么走（这部分是常识，不是命理规则）

> **四、案例**
> **五、断之前先问清**
>

## 一、常识：意外是怎么回事

### 1.1 意外伤害的几类

| 类别 | 例子 |
|---|---|
| **交通事故** | 开车撞人、被车撞、翻车、电动车摔倒 |
| **跌落、摔伤** | 从高处摔下、楼梯摔倒、老人跌倒骨折 |
| **被人伤害** | 打架、被打、被抢、被袭击、被杀 |
| **溺水** | 游泳、落水、掉冰窟窿 |
| **火灾、烧烫伤** | 失火、烫伤、爆炸 |
| **中毒** | 煤气中毒、食物中毒、误服药物、喝农药 |
| **机械、工伤** | 工地事故、机器绞伤、触电 |
| **动物伤** | 被狗咬、被蛇咬 |
| **自伤** | 自杀、自残 |
| **自然灾害** | 地震、洪水、雷击 |

### 1.2 各年龄段容易出的事

| 年龄 | 容易出的 |
|---|---|
| **幼儿（0–6 岁）** | 跌落、溺水、烫伤、误食、窒息 |
| **少年（7–17 岁）** | 溺水、交通事故、打架 |
| **青壮年（18–45 岁）** | **交通事故**、工伤、打架斗殴、自杀 |
| **中年（45–65 岁）** | 交通事故、工伤 |
| **老年（65 岁以上）** | **跌倒骨折**、中毒、火灾 |

⭐ **跟断命有关的一点**：意外和年龄对得上才准——给五岁小孩断「开车撞人」不对，给八十岁老人断「打架」也不对。资料里的「**小儿关**」「**将军箭**」专门管小孩（见 2.7）。

### 1.3 轻重怎么分

| 程度 | 样子 |
|---|---|
| **轻伤** | 擦伤、扭伤、缝几针，不住院 |
| **重伤** | 骨折、内脏伤、要住院、要手术 |
| **残疾** | 截肢、瘫痪、毁容、失明 |
| **死亡** | 当场死亡、抢救无效 |
| **伤人** | 自己没事，伤了别人（要赔、要坐牢） |

⭐ **跟断命有关的一点**：资料里专门分轻重——「**死里逃生**」「**无大伤**」「**多处重伤**」「**撞死人**」「**身体无妨**」；还分**伤自己还是伤别人**。

### 1.4 出了事以后

1. **急救**：120、现场处理
2. **治疗**：急诊、手术、住院
3. **责任**：报警、交警定责、保险理赔
4. **赔偿**：医药费、误工费、伤残赔偿、死亡赔偿
5. **后果**：康复、后遗症、残疾；伤人的可能要承担刑事责任

## 六、读完这一篇，你能断什么

1. **总象**：既制又用、制不住的杀、阳刃无制、卯午破、寅酉绝。
2. **车祸**：车象（寅申巳亥辰丑子酉、印、马）＋冲穿；年时主外；伤哪看部位。
3. **摔伤、被打**：空亡、金克木；阳刃、恶人之象。
4. **水火中毒、自伤**：水无源、童箭、自缢煞、个性刚强。
5. **小孩的关**：将军箭开弓引箭、童箭。
6. **出不出人命**：阴阳缺一不可；禄在、替身在就能救。
7. 六壬：白虎、螣蛇、玄武；凶将不克日干灾不作。

**还断不了的**（资料未讲）：火灾、触电、工伤的通用判据（只有个别命例）；地震洪水；六壬专门占车祸的方法。
