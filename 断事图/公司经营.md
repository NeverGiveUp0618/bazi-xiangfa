# 断事图 · 公司经营：这个人能不能做老板、做多大、会不会倒

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**，还专门举过例子：断公司会不会破产，你得知道公司的流程和里面的各种情况才能断准。盘上看出「财库不开」「穿财」，你要能说出是**钱压在货里、应收账款收不回**，还是**合伙人卷走**、**被骗贷**——这些都是现实里公司倒掉的不同路子。
>
> **这一篇分五部分**：
> **一、常识**：企业有哪几种、谁是老板、钱怎么流、公司怎么做大、怎么倒（这部分是常识，不是命理规则）
> **二、八字怎么对上**：什么当财 → 是不是你的 → 怎么挣 → 多大 → 合伙 → 会不会倒、会不会出事 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**：占求财、占这一笔生意（出自《大六壬通解》）
> **四、案例**：题库里的命例按情况排好
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的商业常识写的；第二、三部分只用老师资料，**资料没讲到的格子写明「资料未讲」**，不自己编规则。并排放的「对应」是我把常识和资料原话摆到一起方便对照——**原话为准**。

## 一、常识：公司是怎么回事

### 1.1 企业有哪几种

| 形式 | 是什么 | 老板担多大责任 |
|---|---|---|
| **个体工商户** | 小店、小摊、小作坊，一个人或一家人经营 | **无限责任**：欠的债要拿个人和家庭财产还 |
| **个人独资企业** | 一个人出钱开的企业 | **无限责任** |
| **合伙企业** | 几个人一起出钱、一起经营 | 普通合伙人**无限连带责任**：一个人欠债，其他人也要还 |
| **有限责任公司** | 最常见的公司形式，股东 1–50 人 | **以出资额为限**：公司倒了，股东一般只赔掉投进去的钱 |
| **股份有限公司** | 股本分成等额股份，可以上市 | 以认购的股份为限 |
| **上市公司** | 股票在交易所公开买卖的股份公司 | 同上，但要公开信息、受监管 |
| **国有企业** | 国家出资 | 管理者是**经营者**，不是**所有者** |

⭐ **跟断命有关的一点**：资料里分得很清——【题268】「**不是他本人的企业，是管理者**」，【题94】「**一生在别人手下挣钱的小老板**」。现实里老板、股东、经理、打工的是四种人，盘上也不一样。

### 1.2 公司里的几种人

| 角色 | 是什么 | 钱是不是他的 |
|---|---|---|
| **股东**（所有者） | 出钱、占股份，按股份分利润 | 是（按比例） |
| **法定代表人** | 公司对外签字、担法律责任的人 | 不一定，常是老板，也可能是挂名的 |
| **总经理**（经营者） | 管日常经营 | 拿工资和奖金，公司的钱不是他的 |
| **财务、会计** | 管账、管钱进出 | 经手但不归他 |
| **员工** | 拿工资干活 | 不是 |
| **合伙人** | 一起出钱一起干 | 按约定分 |

⭐ **所有权和经营权分开**是现代公司的常态：大股东可以不管事，总经理可以一分股份没有。断「他有钱」之前，先分清他是**拥有**这笔钱，还是**经手**这笔钱。

### 1.3 钱是怎么流的

一家公司的钱，大致这样走：

```
  投进来的本钱（股东出资、借款、贷款）
        ↓
  买原料、付房租、发工资（成本）
        ↓
  做出产品/服务 → 卖出去（收入）
        ↓
  收回来的钱（有的当场收，有的先赊账＝应收账款）
        ↓
  收入 − 成本 ＝ 利润 → 再投入 or 分红
```

几个要分清的词：

| 词 | 意思 | 为什么要紧 |
|---|---|---|
| **收入**（营业额） | 卖了多少 | 收入大不等于赚钱 |
| **利润** | 收入减去所有成本 | 真正赚的 |
| ⭐ **现金流** | 手上实际进出的钱 | **公司大多不是亏死的，是没钱周转「憋死」的** |
| **应收账款** | 卖出去了、钱还没收回来 | 收不回来就是坏账 |
| **负债** | 欠别人的（银行贷款、货款、民间借款） | 到期还不上就出事 |
| **担保** | 替别人的借款作保 | 别人还不上，你来还 |
| **库存** | 进了货还没卖掉 | 钱压在货上 |

### 1.4 钱从哪里来（融资）

| 来源 | 特点 |
|---|---|
| 自有资金 | 最稳，但量有限 |
| 银行贷款 | 要抵押或担保，到期要还 |
| 股权融资 | 别人出钱占股份，老板的股份被稀释 |
| 民间借贷 | 利息高、来得快，出事也快 |
| ⚠️ **非法集资** | 向不特定公众吸收资金、许诺高回报，是犯罪 |

### 1.5 公司怎么做大

- **规模的大致量级**：个体小店（年营业额几万到几十万）→ 小微企业（几百万）→ 中型企业（几千万到几亿）→ 大型企业、集团（几十亿以上）。
- **做大的常见路子**：开分店、开分公司、多行业经营、兼并收购、上市。
- **集团**：一家母公司控制好几家子公司。

⭐ **跟断命有关的一点**：资料里有「**一个卯一个公司**」「**有两个以上的企业**」「**至少要办三个以上**」这类数企业的断法（见二·4）。

### 1.6 公司怎么倒

| 倒法 | 是怎么回事 |
|---|---|
| ⭐ **资金链断裂** | 账上有利润、手上没现金，到期的债还不上，一环扣一环 |
| **应收账款收不回** | 货发出去了钱收不回，三角债 |
| **盲目扩张、投资失误** | 借钱扩张、投了新项目，回不来 |
| **合伙人纠纷** | 分钱不均、意见不合、一方卷款 |
| **被骗** | 合同诈骗、被人骗贷、被担保拖累 |
| **违法经营** | 偷税漏税、非法集资、做假账，最后被查 |
| **行业衰退** | 整个行当不行了 |

**收尾的几种结局**：**注销**（正常关门）、**破产清算**（资不抵债，资产拍卖还债）、**破产重整**（法院主持下重组、继续经营）、老板**跑路**、被列为**失信被执行人**（俗称「老赖」）。

⭐ **跟断命有关的一点**：资料里倒公司的案例，原因各不一样——**被骗贷、骗贷款**（【题485】）、**投资失误**（【题593】）、**外地企业倒闭赔光老本**（【题631】）、**非法集资被捕**（【题109】）。断「会倒」还要断「**怎么倒**」，这就要用到这张表。

## 二、八字怎么对上（出自资料，逐条带出处）

> 教材第 13 章把三套资料——**大任财运篇**、**v课财运九纲**、**2012 面授财运七条**——合成了一张表，**三套不冲突，是同一件事的三种切法**。下面按「什么当财 → 是不是你的 → 怎么挣 → 多大 → 合伙 → 会不会倒 → 什么时候」排。

### 2.1 什么当财

> 「我们讲看财富，**并不仅仅只看财星**，八字中**其它的神在特定情况下也可以当财论**。」〔大任 · 财运篇 p2〕

| 谁当财 | 条件 | 出处 |
|---|---|---|
| **财星** | 「**以财看财**（生活费用，最小的财）」 | v课九纲 ① |
| **食伤** | 「**以食伤看财**（财的源头，大财）」；八字无财有食伤，以食伤当财 | v课九纲 ②；财运篇 p4 |
| **官杀** | 「**官统财或财统官**，官杀当财富看」；「官杀**有制但制服不太好**，官杀可当财富看」；⚠️「官杀当财富看时，其**财富级别会很高**」 | 财运篇 p5 |
| **禄** | 「前三项都没有的，**好的禄就是白领，差点的就是领工资的**」 | v课九纲 ④；面授 ⑦ |
| **官带财帽** | 「官带庚财帽子，所以官当财看」 | 中级班 p9 |

⭐ **先问两句**：「①**什么当财** ②**宫位内外一分**」〔v课第 776 讲〕

### 2.2 是不是你的

这是断老板还是打工的关键一步，**对照常识 1.2「拥有」和「经手」**。

| 现实 | 盘上看什么 | 出处 |
|---|---|---|
| **钱是自己的**（股东、老板） | **合得回来**才是自己的；「⭐ **生出去的财要拿住或控制住**」 | 面授 ⑥；v课 |
| **打工的** | 「**财合不回来＝打工的**」；「财没进到自己这里，是给别人打工的」 | v课；【题390】 |
| **管理者，不是所有者**（总经理、国企领导） | 「**食神带官的象：不是他本人的企业，是管理者**」 | 【题268】 |
| **在别人手下的小老板** | 「一生在别人手下挣钱的小老板」 | 【题94】 |
| **经手公家的钱**（财务、会计） | 官当财看在月柱＝**公家的钱**；「三个单位的会计」 | 【题487】【题649】 |
| 财到不了主位 | 「**财到不了主位就不是你的财**，换一个字当财看」 | v课第 777 讲 ·【题477】 |
| 年柱的大财够不够得着 | 「**年干是皮，支为肉**」——日干合到年干只拿到皮，合到年支才拿到肉 | 十八道法门 p49 墓库门 |
| 被别人合走 | 「收玉米的小老板——**被别人合走财**」 | 【题800】 |

⚠️ **陷阱**：「**见财就断富**」——必须先过归属关；「**主位临财外遇劫，防偷防骗防盗窃**」〔小任〕。

### 2.3 怎么挣：六种取财方式

> 「看命首先要确定一个人的**职业**。发财命要**定出他如何取财**。」〔财运篇 p6〕

| 现实 | 取财方式 | 盘上看什么 | 出处 |
|---|---|---|---|
| 经营企业 | **经营取财** | 伤官、食神做功或财星做功 | 财运篇 p6–12 |
| 开店、门面生意 | **做生意／开店** | 财星落于**时上或年上**做功（年时表门户）；**财星配印**适合开门店（印表房屋） | 同上 |
| 多行业、规模经营 | **多种／规模性经营** | 伤食与官杀做功 | 同上 |
| 技术型、知识型（自己的脑子） | **智力取财** | 伤官食神做功，且**占了主位** | 同上 |
| 体力活、苦干 | **体力取财** | 比肩、劫财、禄神做功；「比劫禄作用大的，多是体力劳动者」 | 同上；中级班 p32 |
| 拿工资 | **工薪取财** | 做功**效率普遍不高** | 同上 |

**另外几种方式**（面授、v课命例）：

| 现实 | 盘上看什么 | 出处 |
|---|---|---|
| 敢闯、风险大 | **比劫求财＝有风险胆子大** | 教材第 13 章一·B·B |
| 亲自下场、辛苦 | **禄做功＝身体亲自下场**；「禄冲财＝用身体求财」 | 面授命例 ·【题695】 |
| 靠管理、靠控制 | **合住控制＝靠管理生财** | 同上 |
| 借势、自己不出力 | 「借势为自己，不出力，**老板命**」 | 【题623】 |
| 冲财、合财、穿财 | **冲财＝跑着去拿钱；合财＝把钱拉过来；穿财＝想拿却拿不到，拿到也不正当** | v课第 701 讲 |

### 2.4 做多大

**对照常识 1.5 的量级**：

| 资料原话 | 大致量级 | 出处 |
|---|---|---|
| 「**命中的财星为小财**，如制尽再当大财看」 | 小财 → 大财的分界 | 面授 ① |
| 「命局**制财的原神做功**者，为大富，一般**起步百万级**。如做功能量大者可达**千万到亿级**」 | 百万起，千万到亿 | 财运篇 p3 |
| 「**制财库为大财**」；财库、食伤库、官杀库「有就为大财」 | 大 | 面授 ③；v课九纲 ⑤ |
| 「**财生了官杀，官杀当财看时为大财**」 | 大 | 面授 ④ |
| 「**官统财 → 提升了财富的级别**」；「**谁少谁统治谁**……**制住少的，就发大财**」 | 大 | 财运篇 p8；v课九纲 ⑦ |
| 「食伤官杀两透格，**干不透财为大富**」——「我不仅拿住了财，把财的源头也拿住了」 | 大富 | v课第 779 讲 |
| 做功走不通时，**象法可以单独定层次** | 上市公司董事长「掌管数十亿」 | 财运篇 p6 ·【题267】 |

**企业有几家**：

| 资料原话 | 出处 |

| 「**卯为财为企业 ⇒ 一个卯一个公司**」 | 【题699】 |

### 2.5 合伙

**对照常识 1.1**：合伙企业的普通合伙人要承担连带责任，合伙出事比自己干出事更麻烦。

| 现实 | 盘上看什么 | 出处 |
|---|---|---|
| 合伙对象是谁 | 比劫；「年上癸卯是**合伙者**」 | 【题671】 |
| ⚠️ **不能合伙** | 「年上癸卯是合伙者、**来破午财 ⇒ 不能合伙**」；「**亥巳冲 ⇒ 不可以合伙求财**」 | 【题671】【题694】 |
| 测合伙人的人品 | 「小人命：测合伙对象的人品」 | 【题70】 |
| 比劫连体时的合伙 | 比劫与日主**连成一体**时，**劫财合财＝帮我合财**（合作得财、团队分润），不能断成别人夺财 | 教材第 9 章 ·讲义 p229 |
| 比劫不连体 | 「比劫多＝分夺」；「**主位临财外遇劫**，防偷防骗防盗窃」 | 小任；六壬「最忌兄弟爻过旺」 |
| 三人合伙 | 【题20】三人合伙开砖厂 | 案例 |

### 2.6 会不会倒、会不会出事

**对照常识 1.6 的倒法**：

| 现实里怎么倒 | 盘上看什么 | 出处 |
|---|---|---|
| **与钱无缘、一生不富** | 「**主位与财星穿**，就是表示自己与财没有缘份——不仅无财，反一生不能富」 | 中级班 p10 ·【题46】【题367】 |
| **钱压着拿不出来**（库存、被套） | 「**财库不开＝拿不出来**」：「财入辰墓，而墓不开，表示墓中之物不能被自己所用」 | 初级班 p14；例题解 p40 |
| **担不动、扩张过度** | **身弱合财**，日主无力拿这么重的财 ⇒ 穷；六壬「**传财太旺，日干衰弱，反而求之不得**」 | 中级班 p10 ·【题369】；通解上 p239 |
| **被骗、借钱收不回** | 「借钱要不回来」；「被表兄弟骗过两次」；「当经理风光，后被骗丢职」 | 【题487】【题261】【题266】 |
| **投资失误** | 「甲申年甲虚透被己合绊＋寅申冲根 ⇒ **投资失误损财严重**」 | 【题593】 |
| **外地企业倒闭** | 「子未穿 ⇒ 外地企业倒闭赔光老本」 | 【题631】 |
| **公司垮、员工走、关分公司** | 「戊运＝巳跑到天干上不管事了」 | 【题459】 |
| **骗贷、有外债、公司会倒** | 「未穿子（**穿有手段不正**）＋官印会包装」 | 【题485】 |
| **先发后败** | 「先好后坏（发财→破产）」 | 【题13】 |
| **一见某字就破财** | 「卯合闭财库：一见卯就破财」 | 【题102】 |
| **违法经营、坐牢** | 「打着合法招牌做违法生意」；「资产四个亿，后因**非法集资**被捕」；「把公家的钱转到合伙公司再据为己有」 | 【题179】【题109】【题488】 |
| **因财致祸** | 六壬：「**财旺生起日干之鬼，则为因财致祸**」；八字：**官杀倒象＝工作没了还犯官非** | 通解上 p239；v课第 855 讲 ·【题510】 |
| **财产官司** | 「乙亥运乙庚合＝比劫合官夺财 ⇒ **财产官司**」 | 【题594】 |
| 做假账被查 | 「**卯午破表做账**；**丙辛合上级指出做假账**」（「子卯破表做账」本身只是做账，【题745】是替别人做账） | 【题624】 |

⭐ **化解**：「**破财免灾的原理**：财生官 ⇒ 官非来了让财去生它（花钱）⇒ 它就不克你」〔v课第 855 讲 ·【题510】〕。

### 2.7 什么时候发、什么时候倒

| 规则 | 出处 |
|---|---|
| 「**命中到运**（一种是破财，一种是来财，具体分析）」 | v课九纲 ⑧ |
| 「**应期**（财官食伤谁先来先说谁）」 | v课九纲 ⑨ |

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一笔生意**能不能做、这次能不能收回钱、什么时候到账，不是一辈子做多大。

### 3.1 主线：妻财与青龙

> 「占求财，一定要**重视妻财与青龙**，因为**青龙为财帛之神**，喜龙居**旺相之地无刑克**，并**生日辰**则求财大利。」〔通解上 p239｜PDF p254〕

| 青龙乘 | 断 |
|---|---|
| 未（入墓） | 不利 |
| 巳、午（丧身） | 不利 |
| 亥（入水） | **大利** |
| 子（沐浴／出水） | 虽得而少 |

### 3.2 财在谁那里：干财、支财、命财

> 「在求财课中**财分三类，即干财、支财与命财**……此为**三财**，春天木火旺相，**求财大获**。」〔通解上 p239｜PDF p254〕

| 财在哪 | 是谁的财 | 对照常识 |
|---|---|---|
| **干上** | 我的财 | 自己口袋 |
| **支上** | 宅／对方那头的财 | 对方的钱、应收账款 |
| **命上** | 这个人本身带的财 | 本身的家底 |

### 3.3 四条反例

| 原文 | 对照常识 1.6 |
|---|---|
| 「**传财太旺，日干衰弱，反而求之不得**」 | 盲目扩张、担不动 |
| 「课传见财，**天将又生，则大利**」 | 有人帮衬 |
| ⭐ 「**财旺生起日干之鬼，则为因财致祸**」 | 违法经营、为钱惹官司 |
| 「占求财**最忌讳兄弟爻过旺**」 | 合伙分夺、被抢生意 |

〔通解上 p239–240｜PDF p254–255〕

### 3.4 三传怎么读

| 三传关系 | 断 | 对照常识 |
|---|---|---|
| 顺克（干克初、初克中、中克末） | **求财大获** | 一路都拿得住 |
| 末传生初传之财 | 有人**暗中帮助** | 有贵人、有门路 |
| 干支互加而相生 | 彼此皆利 | 双赢的买卖 |
| **支发用、末传归干** | **彼求我**，求谋大利 | 对方找上门来 |

〔通解上 p239–240｜PDF p254–255〕

### 3.5 困境里怎么看

> 「**进步艰难喜末吉**」——三传前面不好，看末传有没有财禄长生；「**避难之财坐身下**」——看日干底下有没有坐着财。「**贵坐生合求财吉，财逢空墓最为难**。」〔通解上 p239｜PDF p254〕

**对照常识**：前期亏、后期回本（进步艰难喜末吉）；外面的钱收不回，好在自己手上还有底（避难之财坐身下）。

### 3.6 应期

> 「应期以**末传**为主，得财时间看**末传所合**的支神而论，但是这一点必须结合财爻所临之神。」〔通解上 p241｜PDF p256〕

## 六、读完这一篇，你能断什么

1. **什么当财**，**是不是你的**（老板、管理者、打工、经手）。
2. **怎么挣**：开店、经营、规模、智力、体力、工薪。
3. **做多大**：小财、百万、千万、亿；有几家企业。
4. **能不能合伙**，合伙人靠不靠谱。
5. **会不会倒、怎么倒**：被骗、投资失误、扩张过度、违法、官司。
6. 六壬看**这一笔**：财在谁手里、有没有人帮、会不会因财致祸、什么时候到账。

**还断不了的**（资料未讲）：资金链断裂和财库不开的对应；股份大小；上市的象；行业衰退；担保连带。
