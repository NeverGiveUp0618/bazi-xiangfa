# 断事图 · 小人是非：口舌、被坑、被抢功、跟领导不对付

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。来问「犯小人」的人，实际遇到的可能是：同事抢功、领导打压、被人背后说坏话、被举报、被骗、被合伙人坑，也可能只是**自己脾气冲、跟谁都吵**。不先分清是别人坑你、还是你自己招来的，盘上看出「比劫」「七杀」，你只能说「有小人」，说不出该防谁、该改什么。
>
> **这一篇和别篇的分工**：被骗钱见「财运」，被偷见「失物」，打官司见「官司」，合伙人见「兄弟朋友」；这一篇讲**人和人之间的摩擦**：口舌、是非、小人、跟领导的关系、名声。
>
> **这一篇分五部分**：
> **一、常识**：是非的几类、小人从哪来、自己招的还是别人来的、怎么应对（这部分是常识，不是命理规则）
> **二、八字怎么对上**：谁是小人 → 口舌吵架 → 被抢功、被坑 → 跟领导 → 名声 → 自己就是小人 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**：这件事有没有口舌、谁在背后（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。

## 一、常识：是非是怎么回事

### 1.1 是非的几类

| 类别 | 样子 |
|---|---|
| **口舌争吵** | 吵架、骂人、冷战 |
| **背后说坏话** | 传闲话、造谣、挑拨 |
| **抢功、排挤** | 功劳被别人拿走、被孤立、穿小鞋 |
| **被举报、被告** | 匿名举报、被投诉、被起诉 |
| **被坑、被骗** | 合作被坑、借钱不还、被出卖 |
| **名声受损** | 丑闻、网上被骂、被误会 |
| **家里不和** | 婆媳、妯娌、兄弟争家产 |

### 1.2 小人从哪来

| 来源 | 样子 |
|---|---|
| **同事、同行** | 竞争同一个位置、同一笔生意 |
| **领导** | 打压、不重用、穿小鞋 |
| **下属** | 不服管、背后告状 |
| **朋友、合伙人** | 熟人最容易坑熟人 |
| **亲戚** | 争家产、借钱、看不起 |
| **陌生人** | 诈骗、网上骂人 |

### 1.3 别人来的，还是自己招的

| 情况 | 样子 |
|---|---|
| **别人来的** | 自己没做什么，被嫉妒、被算计 |
| **自己招的** | 说话太直、脾气冲、爱管闲事、不服管、爱出风头 |
| **两边都有** | 多数情况 |

⭐ **跟断命有关的一点**：资料里也分这两种——「**食神克官**——只有克、没制住，**常得罪领导、招惹小人、犯口舌官司**」〔小任 · 公开课第4课〕，这是**自己招的**；「**荣誉与财被同事拿走**」〔【题620】〕，这是**别人来的**。

### 1.4 怎么应对（常识）

- 口舌：少说、不争一时
- 抢功：重要的事留痕迹、当面汇报
- 被造谣：澄清、必要时走法律
- 小人在身边：保持距离，不深交、不借钱

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **是什么事** | 口舌、抢功、被坑、被告，盘上看的字不同 | 一律断「有小人」 |
| **跟谁** | 同事、领导、亲戚、合伙人 | 宾位的字对不上人 |
| **自己怎么做的** | 1.3：自己招的还是别人来的 | 把自己的毛病说成别人坑 |
| **问自己还是测别人** | 【题70】可以测对方人品 | — |

⚠️ 断出「你自己脾气冲、得罪领导」，要说得**能让人听进去**——这正是最有用的一句。

## 六、读完这一篇，你能断什么

1. **谁是小人**：比劫是别人（帮还是劫看体用宾主）；七杀无制在宾位；坏的官杀。
2. **口舌**：破、刑、天干虚冲、冲；午酉破会动手。
3. **被抢功、被坑**：比劫印枭多，荣誉与财被同事拿走。
4. **跟领导**：食神制官得贵、克官得罪领导、犯官违法。
5. **自己就是小人**：杀伏吟出尔反尔、食伤透而虚好说谎。
6. 六壬：朱雀口舌、蛇雀并临是谣言、两面刀。

**还断不了的**（资料未讲）：网暴；「贵人」的专门判法；办公室政治里谁会升谁会走（见「官职」篇）。
