# 断事图 · 进退去留：辞职、跳槽、调动、这件事还要不要接着做

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「该不该辞职」「要不要换工作」「这事还做不做」——问的人心里多半已经很纠结。现实里，**走**有几种走法（裸辞、跳槽、调动、被裁、退休、出来创业），**留**也有几种留法（硬撑、等机会、内部调岗）。不先知道这些，盘上看出「冲」，你只能说「要动」，说不出是主动走还是被动走、走了是好是坏。
>
> **这一篇和别篇的分工**：「职业」讲做什么行当；「考公」讲进体制；「流年」讲哪一年动。这一篇讲**一个决定：进还是退、去还是留**。六壬占「这一次该不该」，八字看「这个人是不是常换、换了好不好」。
>
> **这一篇分五部分**：
> **一、常识**：走和留的几种、常见的原因、换了以后（这部分是常识，不是命理规则）
> **二、六壬怎么看**：这一步该进该退（本篇主角，出自《大六壬通解》与毕法赋课例）
> **三、八字怎么对上**：常不常换、主动还是被动、换了好不好、什么时候
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是常识；第二、三部分只用老师资料，逐条带出处；资料没讲的写明。

## 一、常识：走还是留

### 1.1 走的几种

| 走法 | 样子 |
|---|---|
| **主动辞职** | 有下家再走，或裸辞 |
| **跳槽** | 换到同行别家 |
| **内部调动** | 换岗位、换地方，单位不变 |
| **被裁、被辞退** | 公司裁员、犯错 |
| **出来创业** | 不打工了，自己干 |
| **退休** | 到年龄 |
| **停职、下台** | 出了问题 |

### 1.2 常见的原因

| 想走的原因 | 样子 |
|---|---|
| 钱少 | 嫌工资低 |
| 不受重用 | 跟领导不合、升不上去 |
| 太累 | 加班、跑动多 |
| 人际 | 同事、小人 |
| 有更好的机会 | 别家开出更好的条件 |
| 想自己干 | 不想打工 |

### 1.3 换了以后

| 结果 | 样子 |
|---|---|
| 越换越好 | 每次都往上走 |
| 越换越差 | 换来换去没积累 |
| 换不成 | 想走走不了，被拴住 |
| 走了后悔 | 新地方不如旧的 |

⭐ **跟断命有关的一点**：资料里正好分这几种——「**每次工作调动，都起好作用**」〔【题604】〕、「**工作不稳定，经常变动**」〔【题394】〕、「**不安心工作，嫌工资低**」〔【题656】〕、「**不想干这份工作，会自己出来干事当老板**」〔【题209】〕。

## 二、六壬怎么看（出自《大六壬通解》与毕法赋课例）

### 2.1 进还是退：连茹

| 课例 | 盘上 | 断 |
|---|---|---|
| ⭐ 例169 进茹空亡 | 三传**顺数**（进茹）却逢空 | **前路踏空宜退**——前进踏空撞鬼，宜退不宜进；退回就干支上相合之神反有得 |
| ⭐ 例170 退茹空亡 | 三传**倒数**（退茹）的步子逢空又是鬼 | **退路踏空宜进**——退无可退，向前一步逢生我之神 |
| 例150 | 连茹退行 | 人走不远，马上就回来 |

〔通解上 p237-238〕：「**三传退间蛇倒拔**（逆间传）……**事业倒退，阻隔重重**」；「**三传引进龙飞天**」（进连茹、进间连茹）。

⭐ **对照常识**：连茹本身说方向（进茹宜进、退茹宜退），**逢空就反过来**。

### 2.2 守还是走

| 课例 | 盘上 | 断 |
|---|---|---|
| ⭐ 例29 旺禄临身 | 禄临干且旺 | **切不可舍此别谋、守禄为上**——三传空墓脱＝不可就 |
| ⭐ 例158 舍损就益 | 干支上破碎羊刃六害（坏）＋三传生我带财（好） | **舍掉身边的坏、投向三传的好**，自微至显 |
| ⭐ 例183 | 干旺支衰 | 「**哪边旺就往哪边走**」——**宜出外、不利家居** |
| 例101 / 例102 | 人旺宅狭 / 屋广人稀 | 不可迁大屋 / 宜弃此别迁 |

⭐ **对照常识 1.1**：「守禄为上」＝**眼下这份工作就是你的饭碗，别走**；「舍损就益」＝**身边坏、外面好，该走**。

### 2.3 这件事接着做，结果如何

> 「谋事看**初传（开头）、末传（结局）**」〔例153 回顾〕；「**别只看开头、要看末传能不能翻盘**」〔例160 回顾〕

| 课例 | 断 |
|---|---|
| 例153 有始无终 | **开头满堂彩、到头一场空**——初长生、末墓 |
| 例154 难变易 | **开头难、后来通**——初墓、末长生；坚持终有成 |
| ⭐ 例160 苦去甘来 | **先苦后甜**——末传制掉凶神又带生机 |
| ⭐ 例161 恩多怨深 | **恩反成仇**——开头处处有人帮，末传反克日干 |
| ⭐ 例162 一喜一悲 | 喜忧参半，勿喜过早、勿忧过重 |
| 例159 周而复始 | 占事必成 |
| 例171 空上天空 | 空话一场莫追 |

### 2.4 我求人还是人求我（谈新工作、谈条件）

| 课例 | 盘上 | 断 |
|---|---|---|
| ⭐ 例166 干传支 | 三传从干流向支 | **我求人**——主动权在对方，宜低心下意 |
| ⭐ 例167 支传干 | 三传从支流向干 | **人求我**——主动在我，求取得 |
| 「初传是支发用、末传归于干上，乃彼求我，求谋大利」 | — | 通解上 p239-240 |

⭐ **对照常识 1.2「有更好的机会」**：别家来挖你（支传干）比你去求别家（干传支）顺。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **想走，还是已经被要求走** | 1.1：主动、被动盘上不同 | 被裁的人你劝他「守禄为上」 |
| **为什么想走** | 1.2：钱、领导、累、机会 | 抓不住真正的原因 |
| **有没有下家、什么条件** | 2.4：谁求谁 | — |
| **以前换过几次** | 3.1：常换的命 | 把天生常换的命当成这一次的特殊情况 |
| **年纪、家里负担** | 「人生年龄」篇 | 给快退休的人断「出去闯」 |

## 六、读完这一篇，你能断什么

1. 六壬：**进茹宜进、退茹宜退，逢空反过来**；**旺禄临身守为上**；**舍损就益**；哪边旺往哪边走。
2. 谋事看**初传与末传**：先明后暗、先暗后明、先苦后甜、恩反成仇。
3. **我求人（干传支）**还是**人求我（支传干）**。
4. 八字：**伏吟、相换、穿、禄被冲**＝常换；**寅巳穿嫌工资低**；**印生身每次调动都好**；**冲者主动**。

**还断不了的**（资料未讲）：裸辞还是有下家；被裁与主动辞职怎么分；退休。
