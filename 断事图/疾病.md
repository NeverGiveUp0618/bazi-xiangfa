# 断事图 · 疾病：这个人哪里有病、急还是慢、救不救得回

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。断病，先得知道人身上有哪些系统、哪些病是慢慢熬的、哪些是突然发作的、生了病一般怎么走——否则盘上看出「卯被穿」，你只能说「肝不好」，说不出是急性发作还是要开刀，也说不出该劝人查什么。六壬《通解》讲占病时也专门说：断病源「**还要结合中西医常识**」。
>
> **这一篇分五部分**：
> **一、常识**：人体系统、中医脏腑五行、病的性质、生病以后一般怎么走；⭐ **加厚**：中医的脏≠西医器官、病因（风寒湿燥、七情）、八纲（虚实寒热）、病怎么传、五脏取象表、西医检查与指标、男女老少常见病、精神心理（这部分是常识，不是命理规则）
> **二、八字怎么对上**：哪个字受伤 → 身体哪里 → 急还是慢 → 会不会开刀 → 何时发 → 寿元（全部出自资料，逐条带出处）
> **三、六壬怎么看**：占病的主线（出自《大六壬通解》）
> **四、案例**：题库里的命例按身体部位排好
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的医学常识写的；第二、三部分只用老师资料，**资料没讲到的格子写明「资料未讲」**，不自己编规则。并排放的「对应」是我把常识和资料原话摆到一起方便对照——**原话为准**。
>
> ⚠️⚠️ **断病只是提示，不是诊断**。断出问题，劝人去医院查；不要替人下病名，更不要劝人停药。老师也说过：「**60 岁前不主动告知寿数**」〔小任讲义 p44〕。

## 一、常识：人身上的病

### 1.1 两套看人体的方法

现代医学按**系统**分，中医按**脏腑**分。命理资料里两套说法都在用（「肝」「肺」是中医的叫法，「心脑血管」「肿瘤」「卵巢手术」是西医的叫法），所以两套都要懂。

**西医：九大系统**

| 系统 | 包括 | 常见病 |
|---|---|---|
| **循环** | 心脏、血管、血液 | 高血压、冠心病、心梗、心律失常 |
| **神经** | 大脑、脊髓、神经 | 中风（脑梗、脑出血）、癫痫、头痛、神经衰弱 |
| **呼吸** | 鼻、咽喉、气管、肺 | 哮喘、慢性支气管炎、肺炎、肺癌 |
| **消化** | 口、食道、胃、肠、肝、胆、胰 | 胃炎、溃疡、便秘、肝炎、肝硬化、胆结石 |
| **泌尿** | 肾、输尿管、膀胱 | 肾炎、肾结石、尿毒症（肾衰竭） |
| **生殖** | 子宫、卵巢、前列腺等 | 子宫肌瘤、卵巢囊肿、不孕不育 |
| **内分泌** | 甲状腺、胰岛等 | 糖尿病、甲亢 |
| **运动** | 骨骼、关节、肌肉 | 风湿、关节炎、腰椎间盘突出、骨折 |
| **感官与皮肤** | 眼、耳、皮肤 | 近视、失明、耳聋、湿疹 |

另有两类不按系统分、却最要紧的：**肿瘤**（良性、恶性，恶性即癌）和**精神心理**（抑郁、焦虑、精神分裂、智力障碍）。

**中医：五脏六腑与五行**

| 五行 | 脏 | 腑（表里） | 开窍 | 主 | 情志 |
|---|---|---|---|---|---|
| 木 | **肝** | 胆 | 目 | 筋 | 怒 |
| 火 | **心** | 小肠 | 舌 | 血脉、神志 | 喜 |
| 土 | **脾** | 胃 | 口 | 肌肉、四肢 | 思 |
| 金 | **肺** | 大肠 | 鼻 | 皮毛、呼吸 | 悲 |
| 水 | **肾** | 膀胱 | 耳 | 骨、髓、生殖 | 恐 |

⭐ **中医有一句「见肝之病，知肝传脾」**（出自《金匮要略》）：五行木克土，肝有病会连累脾胃——**病根在一处，症状在另一处**。命理资料里正好有一模一样的判法（见二·5「表现在哪≠病根在哪」）。

### 1.2 病的性质：急、慢、先天、外伤

| 性质 | 特点 | 例子 |
|---|---|---|
| **急性** | 来得快、症状重、常要急诊或手术 | 心梗、脑出血、急性阑尾炎、急性肝炎 |
| **慢性** | 慢慢起来、反复、难断根、要长期吃药管理 | 高血压、糖尿病、慢性胃炎、风湿 |
| **慢性急性发作** | 平时慢性，某一阵突然加重 | 哮喘发作、冠心病发成心梗 |
| **先天** | 生下来就有 | 先天性心脏病、小儿麻痹后遗症、先天残疾 |
| **外伤、意外** | 外力造成 | 车祸、摔伤、刀伤、溺水、中毒 |
| **肿瘤** | 良性一般切了就好；恶性会转移 | 肌瘤、囊肿；肺癌、肝癌、血癌 |
| **精神心理** | 情绪、思维、行为异常 | 抑郁、神经衰弱、精神病、智力低下 |

⭐ **跟断命有关的一点**：资料里**专门分急性和慢性**（晦、冲为慢性，穿为急性），还分「**有冲有穿易有车祸**」的外伤，和「**生来带残伤**」的先天——这几类在盘上的样子不一样。

### 1.3 生了病一般怎么走

1. **有症状** → 2. **就诊、检查**（抽血、拍片、B 超、CT、核磁、胃镜、活检）→ 3. **诊断**（定是什么病）→ 4. **治疗**：
   - **药物**（口服、输液打针）
   - **手术**（切除、修补、移植、剖腹产）
   - **放疗化疗**（多用于恶性肿瘤）
   - **康复、长期管理**（慢性病）
5. **结局**：痊愈、带病生存、复发、留后遗症（如中风后偏瘫）、去世。

⭐ **跟断命有关的一点**：资料里的断语经常落在这条路上的某一步——「**打针**」「**两次手术**」「**手术能救过来**」「**留下后遗症**」「**看病住院先破财**」。断病不只是断哪里病，还要断**走到哪一步**。

### 1.4 常见的「要命」原因

中国人死因排前面的大致是：**心脑血管病**（心梗、中风）、**恶性肿瘤**、**呼吸系统病**、**意外伤害**（车祸、跌落、溺水）。所以资料里断寿元、断急病的命例，多半落在心脏、脑、肺、肝、车祸这几处。

### 1.5 生育相关

不孕不育、流产、宫外孕、子宫肌瘤、卵巢囊肿、剖腹产——在命理里，这一类常常和**子女、婚姻**连着断（食伤、子女宫、夫星），资料里也是放在一起讲的。

> 下面 1.6–1.14 是**加厚的中医、西医常识**。每一块后面的「⭐ 跟断命有关」只摆**资料里真出现过的**对应；资料没讲的写明。

### 1.6 中医：先分清「中医的脏」和「西医的器官」

**这是最容易错的一条**：中医说的「肾」「肝」「心」「脾」「肺」，**不等于**西医解剖上那个器官，范围大得多。资料里说「肾差」，可能是西医的泌尿、生殖、腰、骨、耳的问题，不一定是肾脏病。

| 中医的脏 | 管的范围（中医） | 西医里大致对应到 |
|---|---|---|
| **肝** | 藏血、主疏泄（情绪、气机通畅）、主筋、开窍于目 | 肝胆，**情绪（抑郁、易怒）**、神经、筋腱、眼、**月经** |
| **心** | 主血脉、**主神志**、开窍于舌 | 心脏血管，**精神、睡眠、思维** |
| **脾** | 主运化（消化吸收）、主肌肉四肢、统血 | 胃肠、消化吸收，**肌肉无力**，部分出血 |
| **肺** | 主气、司呼吸、主皮毛、开窍于鼻 | 呼吸系统，**皮肤**、鼻、免疫力（易感冒） |
| **肾** | 藏精、**主生殖发育**、主骨生髓、主水、开窍于耳、其华在发 | 泌尿，**生殖、内分泌**、骨骼、牙齿、**腰**、耳、头发、衰老 |

⭐ **跟断命有关**：资料里「**亥是命主甲的长生，又是水主肾、腰、膀胱**，在月柱就是主腰」〔v课 754 讲【题436】〕；「**火燥缺水肾差**」配的是「**丈夫不能生育**」〔【题532】〕——这里的「肾」说的是**生殖**，不是肾脏。**看到资料说某脏，先按中医的大范围理解，再落到具体的西医病**。

### 1.7 中医：病是怎么来的（病因）

| 病因 | 内容 | 常见表现 |
|---|---|---|
| **六淫**（外邪） | **风、寒、暑、湿、燥、火** | 风：游走、头痛、抽搐；寒：怕冷、疼痛、收缩；湿：沉重、肿、痰多、缠绵；燥：干咳、皮肤干；火（热）：红肿、发烧、上火 |
| **七情**（内伤） | 喜、怒、忧、思、悲、恐、惊 | 怒伤肝、喜伤心、思伤脾、悲伤肺、恐伤肾 |
| **饮食劳倦** | 吃得不对、累着了、太闲 | 脾胃病、气虚 |
| **外伤** | 跌打、刀伤、虫兽 | 见「意外」篇 |
| **痰饮、瘀血** | 病中产生、又成新的病因 | 痰：咳痰、肿块；瘀：刺痛、固定不移、肿瘤 |

⭐ **跟断命有关**（资料里出现过的）：

| 中医病因 | 资料里的盘象 | 出处 |
|---|---|---|
| **湿**（阴湿重） | 「**活木生在寒冬腊月没有火，命里缺阳气，阴湿之气重**」⇒ 腿脚风湿关节疼；丙寅被双丑湿土暗合 ⇒ **湿气重四肢肿痛** | 【题436】【题718】 |
| **寒** | 「辰是水库……库没开，又是亥月水凉，又在时柱生殖系统，所以有**宫寒**之意」 | 【题436】 |
| **燥** | 「火燥缺水肾差」；「日时戌午太燥不育」 | 【题532】【题533】 |
| **痰** | 「火被晦，无力化湿气，**痰出不来**」⇒ 哮喘 | 【题719】 |
| **瘀血** | 寅亥合灭丙火 ⇒ 脑出血**淤血**严重 | 【题731】 |
| **怒伤肝** | 「肝受伤引起**肝气郁结，脾气大**」 | 【题436】 |
| **邪症** | 「亥带劫煞，合到卯了，这个亥就为**邪症**」 | 【题379】 |

⭐ 资料的规矩：**湿、寒、燥这类定语来自全局气候，不来自单个字**〔【题436】〕——看全盘是寒是燥，再定「湿」「寒」「燥」。
⚠️ **资料未讲**：风、暑这两种外邪的专门盘象。

### 1.8 中医：八纲——阴阳、表里、寒热、虚实

| 纲 | 意思 | 大致样子 |
|---|---|---|
| **阴阳** | 总纲 | 阳虚怕冷、没精神；阴虚燥热、盗汗 |
| **表里** | 病在浅还是深 | 表：感冒、皮肤；里：脏腑 |
| **寒热** | 性质 | 寒：怕冷、喜热饮；热：发烧、口干、上火 |
| **虚实** | 正气弱还是邪气盛 | 虚：没力气、气短；实：胀、痛、拒按 |

常听到的几个词：
- **气虚**：没力气、气短、容易累、爱出汗
- **血虚**：脸色白、头晕、心慌、月经少
- **阳虚**：怕冷、手脚凉
- **阴虚**：手心脚心热、口干、盗汗
- **气滞**（郁结）：胀、闷、情绪压抑
- **血瘀**：刺痛、固定一处、有肿块

⭐ **跟断命有关**：资料断病的**第一条就是阴阳**——「**伤病：主要看阴阳平衡，结合五行，宫位来看**」〔面授 p74〕；**阴制阳** ⇒ 心脑血供不足、心脏堵塞；**阳制阴** ⇒ 肾、血液、生殖〔面授 p74–80〕。资料里的中医词：「**肝阳不足**」「**气虚**」（辛被亥泄、金表呼吸）「**宫寒**」〔【题436】〕；「**供血不足**」「神经衰弱」〔【题379】〕。
⚠️ **资料未讲**：阴虚、血虚、表证里证的专门盘象。

### 1.9 中医：五行生克在病上（病怎么传）

| 关系 | 中医说法 | 例子 |
|---|---|---|
| **相生（母病及子）** | 母脏病了连累子脏 | 肾（水）虚 → 肝（木）失养 |
| **相生（子病犯母）** | 子脏病了拖累母脏 | 肝（木）火旺 → 耗肾（水） |
| **相克太过（乘）** | 克的一方太强 | **肝（木）旺克脾（土）**——「见肝之病，知肝传脾」 |
| **反克（侮）** | 被克的一方太强反过来 | 肺（金）弱，肝（木）火反灼肺 |

⭐ **跟断命有关**（资料里出现过的）：

| 传变 | 资料 | 出处 |
|---|---|---|
| **肝病传脾** | 「表现在脾胃上，**源在肝**；西医治胃好不了，中医治肝很快好起来」 | 面授 p77【题716】 |
| **肝不好则脾不受约束** | 腰疼、常闹肚子、大吐血查不出原因 | 【题297】 |
| **肝肾一起** | 「有风湿、心血、肝胆、妇科、脾胃等多病在身，但**主要是肝肾引发的综合症**」 | 【题296】 |
| **病根与痛处分开** | 「**病根在酉**，断她腰部位痛」 | 【题375】 |

### 1.11 西医：检查和指标（听得懂病人说什么）

| 检查 | 查什么 |
|---|---|
| **血常规** | 贫血、感染、白血病线索 |
| **肝功能、肾功能** | 转氨酶高＝肝有损伤；肌酐高＝肾功能差 |
| **血糖、血脂** | 糖尿病、高血脂 |
| **肿瘤标志物** | 癌的线索（不能单凭它确诊） |
| **B 超、CT、核磁** | 看器官、肿块 |
| **胃镜、肠镜** | 消化道 |
| **病理（活检）** | **确诊癌症的金标准** |

**几个常听到的数**：
- **高血压**：一般 ≥140/90 毫米汞柱
- **糖尿病**：空腹血糖一般 ≥7.0 毫摩尔／升
- **癌症分期**：Ⅰ–Ⅳ 期，Ⅰ期早、Ⅳ期晚（已转移）；**早发现早治疗，很多能治好**
- **良性**（肌瘤、囊肿、息肉）一般切了就好；**恶性**（癌）会转移

### 1.13 精神心理

| 类别 | 样子 |
|---|---|
| **失眠、神经衰弱** | 睡不着、多梦、头痛、记性差 |
| **焦虑** | 紧张、心慌、坐立不安 |
| **抑郁** | 情绪低落、没兴趣、想不开，**重的有轻生念头** |

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 顺序：先找受伤的字，再翻部位

> 「**并非八字一排出来就要准确按照干支宫位所对应的人体来读，那方面最容易发生误判。**」〔疾病篇；教材第 15 章 3.1〕

```
第1步  哪个字被冲、穿、克、合、入墓了？（先找伤）
第2步  这个字对应身体哪里？（三套坐标叠加）
第3步  急性还是慢性？会不会动手术？
第4步  哪一步运、哪一年发？
```

⚠️ **门槛**：「**至少两种以上的信息可以确定一项事情**，把确定的事情用适当合理的语言表述出来，称为铁口直断。」〔v课第 753 讲〕——一条信息只叫「倾向」。示范是【题436】：寅是木（比卯粗＝腿）、在年柱（下盘）、是比劫（手足）、是甲之禄（身体），**四点合一**才敢说「腿脚」。

### 2.3 急性还是慢性

> 「**活木，喜午火，一旦被辰晦、子冲，就用慢性病。**（不是穿所以为慢性病，有了穿就是急性病发作）」〔大任 · 2012 面授 p75；括号为整理者旁注〕

| 作用 | 病性 | 出处 |
|---|---|---|
| **晦、冲**（原话）；合、入墓（教材归纳） | **慢性**，难治 | 面授 p75；【题718】「阴制了阳是晦，不是一下子」 |
| **穿**（原话）；破（【题721】卯午破＝两次手术） | **急性发作、手术** | 面授 p75；【题721】 |

⚠️ **「冲」归哪一边，资料前后不一**：面授原话是「被辰晦、**子冲**，就用**慢性**病……有了**穿**就是急性病发作」——冲归慢性；教材第 15 章 4.2·B 的归纳写成「穿、**冲**、破 ⇒ 急性」。**这里以原话为准**，冲先按慢性看；遇到冲又急性发作的命例再回头核。

**对照常识 1.2**：慢性病＝晦、冲、合、入墓（被罩住、被锁住，慢慢耗）；急性发作＝穿、破（突然被扎破）。

| **合** | 酸 |

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬占病是**问这一场病**：凶不凶、救不救得回、病在哪、什么时候好。

### 3.1 主线：白虎与鬼

> 「**病症之源寻虎鬼，沉屙之际看生龙。须防虎鬼驾马恶，死墓绝空最为凶。**」〔通解上 p224｜PDF p239〕

| 见到 | 断 |
|---|---|
| **虎鬼**（白虎乘日鬼） | 凶；临干支、三传、年命更凶（「虎临干鬼凶速速」） |
| 虎鬼**空亡** | **不治自愈** |
| 虎鬼**乘驿马**克日干 | 大凶，来势迅速凶猛 |
| **青龙乘生气生日干** | **危而复生** |

⚠️ 原书特意说「白虎乘金主肝病」这类**并非定律**，断病源**要结合课体、五行格局，还要结合中西医常识**——这正是本篇第一部分的用处。

### 3.2 解药：子孙与贵医

> 「**子孙克官鬼**，因此子孙象征**痊愈、药物**……**医神加年命，生其年命，必愈**。」〔通解上 p224–225｜PDF p239–240〕

**对照常识 1.3**：子孙＝药、治疗；天医地医＝医生——这一场病有没有好医生、好药。

### 3.3 病在哪：人身类神

> 「甲胆乙肝丙小肠，丁心戊胃己脾乡。庚是大肠辛主肺，壬癸膀胱癸肾藏。子肾膀胱耳腰液，丑脾腹兮与两足。寅胆风门筋脉发，卯肝血筋手背目。辰皮肤肩暨背项，巳焦小肠面齿股。午心目神气与舌，未胃腹口唇齿户。申为大肠筋骨间，酉肺口鼻声血路。戌乃命门膝胁胸，亥膀头髓二便呼。」〔通解中 p482｜PDF p118〕

**用法**：拿病神（多是白虎所临之神、或克日之鬼）查这张表，**干和支两边都指向同一处才准**。⚠️ 别拿这张表去「算」没问过的病。

### 3.4 几条要紧的配合

| 规则 | 出处 |
|---|---|
| **久病占空必主死；暴病逢空反吉** | 通解上 p69（第 7 课） |
| **老怕帝旺，少怕衰** | 通解上 p77（第 10 课） |
| **自生入墓**（寅加戌、巳加丑、申加辰、亥加未）占病必死 | 通解上 p67（第 11 课） |
| 八专**独足格**占病主死 | 通解上 p40（第 6 课） |

**对照常识 1.2**：「**久病占空必主死；暴病逢空反吉**」〔通解上 p69〕——慢性病到了「空」是油尽灯枯，急病遇「空」是来得快去得快，正好对上急慢之分。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁**：本人还是家人？ | 太极点不同，看的字不同（断命台「摆正立场」） | 把父亲的病断到本人身上 |
| **现在有没有病、什么病、医院怎么说**？ | 已经确诊的，断的是**走向**（会不会好、要不要手术、哪年要小心） | 人家已经确诊肝癌，你还在说「肝不太好」 |
| **急还是慢**：突然发作还是多年老病？ | 2.3：急慢看作用方式，问清了好对盘 | 把慢性病断成「这两年会突然出事」吓人 |
| **年龄** | 「老怕帝旺，少怕衰」；60 岁前不谈寿数 | 对年轻人谈寿元 |
| **在哪里生活**：城市还是山区？开不开车？ | 「大山里应蛇咬，城市里应车祸」 | 车象断成车祸，人家根本不开车也不坐车 |
| **做什么工作** | 同样的象，可能是职业不是病（修车、医生、护士） | 【题668】子卯破＝手术，人家就是外科医生 |

## 六、读完这一篇，你能断什么

1. 先找**哪个字受伤**，再翻**部位**（五行＋宫位＋干支，至少两条对上才说）。
2. 分出**急性还是慢性**，会不会**开刀、打针、住院破财**。
3. 看出**病根和症状不在一处**（肝传脾）。
4. 看**车祸、外伤**，出不出人命看阴阳在不在。
5. 看**先天、残疾**（互患空亡）。
6. 六壬看**这一场病**：凶不凶（虎鬼）、有没有药（子孙、医神）、病在哪（人身类神）、久病暴病逢空怎么分。

**还断不了的**（资料未讲）：慢性病哪年加重；精神心理病和神经系统病怎么分；内分泌病的象；肿瘤和普通病的通用判据。
