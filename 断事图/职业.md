# 断事图 · 职业：做什么行当、在体制内还是外面、稳不稳

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**；面授里也直说「**职业：比较难看，要注意配合，及地方风俗环境来论**」〔2012 面授 p91〕。同一个「申＋穿＝刀」，可能是外科医生、理发师、厨师，也可能是屠户——你得知道现实里有哪些行当、一个行当里有哪些岗位，才能从象里挑出对的那一个。
>
> **这一篇分五部分**：
> **一、常识**：职业怎么分、就业的几种形式、一份工作要分几层来看（这部分是常识，不是命理规则）
> **二、八字怎么对上**：三条判断路径 → 三步定职业 → 体制内还是外面 → 行业取象 → 工作稳不稳 → 普通人与特殊行当（全部出自资料，逐条带出处）
> **三、六壬怎么看**
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开资料写的常识；第二部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。

## 一、常识：职业是怎么回事

### 1.1 职业大类

《中华人民共和国职业分类大典》（2022 年版）把职业分成八个大类：

| 大类 | 包括 |
|---|---|
| 一 | **党的机关、国家机关、群众团体和社会组织、企事业单位负责人** |
| 二 | **专业技术人员**（医生、教师、工程师、律师、会计、艺术工作者……） |
| 三 | **办事人员和有关人员**（行政、文秘、保卫……） |
| 四 | **社会生产服务和生活服务人员**（销售、餐饮、运输、快递、美容理发、保安……） |
| 五 | **农、林、牧、渔业生产及辅助人员** |
| 六 | **生产制造及有关人员**（工人、技工） |
| 七 | **军队人员** |
| 八 | 不便分类的其他从业人员 |

### 1.2 就业的几种形式

| 形式 | 特点 |
|---|---|
| **体制内** | 公务员、事业编（学校、医院）、国企——稳定、有级别 |
| **私企、外企** | 打工拿工资，流动性大 |
| **自己当老板** | 个体户、开公司 |
| **自由职业** | 设计、写作、咨询、主播，按单子挣钱 |
| **灵活就业** | 外卖、网约车、快递——按件按单 |
| **务农** | 种地、养殖 |
| **兼职、副业** | 一份正职之外再挣一份 |

### 1.3 一份工作要分几层看

说一个人「做什么」，其实有好几层：

| 层 | 例 |
|---|---|
| **行业** | 金融、教育、医疗、建筑、餐饮、运输…… |
| **单位** | 银行、学校、医院、工地、饭店…… |
| **岗位** | 同在银行：柜员、信贷、会计、行长、保安、司机 |
| **层级** | 普通员工、主管、负责人 |
| **收入方式** | 工资、提成、分红、按件 |
| **稳不稳** | 铁饭碗、合同工、常换工作 |

⭐ **跟断命有关的一点**：老师给的定职业示范正好是一层层往下缩——「**定行业 → 缩范围 → 定职位**」（见 2.2）。说「金融」还不够，要说「银行里管放贷的」。

### 1.4 工作的变动

换工作、跳槽、失业、下岗、调动、退休、创业、转行——一辈子做好几个行当在现在很常见。

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 三条判断路径

> 教材第 15 章把资料里定职业的方法归成三条路。

**路径一：十神组合定行业**〔十八道法门 p11〕

| 组合 | 行业方向 |
|---|---|
| **食伤制官杀** | 显贵掌权，**多数为公检法** |
| **官杀制比劫** | 领导老板、社会管理者，或**军宪武职** |
| **官印相生** | **公职、国企**，多为领导 |
| **财生官** | 官当财看 → 富命；容易与政府人员打交道，**投资金融** |
| **食伤佩印** | **文化人、学者、教师、技术人员**、营销 |
| **印制食伤** | 文化部门官员、企业老板、技术人员、教育工作者 |
| **食伤生财** | **自主创业、技术求财**的生意人、企业家 |
| **财制印** | **求财为主，开办企业、店面**；部分表制印得权 |

**路径二：象定行业**（第 10 章）

| 象 | 行业 |
|---|---|
| **申** | 传送、有车之象；军队、司法、金融、医院 |
| **酉** | 法律、银行、钟表、传媒、技术、玄学 |
| **丑** | 与吃有关（丑为食）；银行、军营、厂矿、玄学 |
| **丙** | 媒体、影视、文化、传播 |
| **丁** | 文字、神秘文化、电子、网络 |
| **辛** | 金融、医药、精加工、法律、设计 |
| **癸** | 玄学、智业、谋略、墨（文书绘画） |
| **戌亥** | 数学、运算 |

**路径三：职业歌**（⚠️ 未验证，仅索引）〔十八道法门 p16〕

> 「戊临戌酉做先生，己临巳酉郎中命。劫财七杀两相连，早离家门去戍边。辛与丙合化成食，从魁登明开酒店。食神合印百家饭，行医育人细分论。戊土日元见酉戌，十有八九当老师。」

⚠️ **口诀会失灵**：【题385】「戊临戌酉做先生」应验了；【题386】同一句口诀**不应验——不是老师，是妇产科打胎的**。口诀只描述外形，要看原局有没有别的作用。

### 2.2 三步定职业

> ⭐ 面授的完整示范（【题758】邮政局领导）：先由「乙＝传播、庚与酉＝印＝书信资料」定出**传播类**；再用「**庚申为马星**」把它从电视台、出版社缩到**邮政**；最后用「**庚申酉都入了我坐下的丑库，由我统一控制**」定出是**领导**。〔2012 面授 p91–96〕

```
  第一步  定行业：用十神组合或象，定出大方向（传播类）
  第二步  缩范围：再找一个象，在同类里挑出具体的（马星 ⇒ 邮政）
  第三步  定职位：看是不是我控制、在不在主位（入我坐下库 ⇒ 领导）
```

**对照常识 1.3**：正好对上「行业 → 单位 → 层级」。

**八字里没有那样东西，就去抓它的源头**〔中级班 p6〕：

> 「**八字无财，伤食当财看，印主权**，是中央银行行长……**食为财之源，八字不见财，需抓其源**，故命主是**管银行与财政的官**，曾任财政部长。」

## 三、六壬怎么看

⚠️ **资料未讲**：《大六壬通解》和课程里**没有专门「占职业」的一门**。相关的几处：

| 问的事 | 去哪看 |
|---|---|
| 求职、升迁、调动 | 「官职」篇第三部分（日辰虚实、引从、青龙文职太常武职、内外调） |
| 生意、求财 | 「公司经营」篇第三部分 |
| 考试、考证 | 「学业」篇第三部分 |

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **现在做什么、做过什么** | 定职业最难，先拿已知的校准（老师：先点两件事校准） | 一上来就断行业，断错了后面全不信 |
| **体制内还是外面**？ | 2.3：官印相生、在单位做事、上班族、老板各有样子 | 把国企经理断成个体户 |
| **老家、在哪里工作**？ | 老师：「要注意地方风俗环境」 | 山区和城市同一个象落成不同行当 |
| **问的是哪件事**：适合做什么？要不要换？两个选择哪个好？ | 2.6：择业看两个字活不活 | 只说行业，不回答他真正想问的「换不换」 |
| **学的什么专业** | 「学业」篇：专业方向和职业常常相连 | 学医的断成做生意 |
| **问的是谁** | 太极点不同 | 孩子的职业断到本人盘上 |

## 六、读完这一篇，你能断什么

1. **三条路径**：十神组合、象、职业歌（口诀会失灵）。
2. **三步定职业**：定行业 → 缩范围 → 定职位。
3. **体制内还是外面**：官印相生；食伤在年是单位、在日时是企业；禄合官只表有工作。
4. **行业取象**：公检法、金融、医疗、教育、媒体、技术、服务、运输、体力、农业、宗教各有命例。
5. **体力、技术、智力、口才**。
6. **稳不稳、换不换**：禄被冲、伏吟、穿；**两个行业看各自的字活不活**。

**还断不了的**（资料未讲）：互联网、主播等新职业的专门象；六壬专门占职业的一门；什么时候换工作（只能借大运流年的一般规则）。
