# 断事图 · 化解：断出凶以后怎么办

> **为什么要这一篇**：断出问题以后，客人问的第一句几乎都是「**那怎么办？**」。现实里能做的事其实很多——**换个方向发力、避开某一年、处理掉某样东西、晚几年结婚、劝去体检**。不先知道哪些是实在能做的、哪些只是说法，断完凶你只能说「注意点」，或者乱开方子。
>
> **这一篇分五部分**：
> **一、常识**：断出问题后现实里能做的几类事（这部分是常识，不是命理规则）
> **二、老师的化解观**（出自资料）
> **三、资料里的具体化解办法**：按事分类，逐条带出处
> **四、六壬里的化解**（出自《大六壬通解》与毕法赋课例）
> **五、说法与分寸**
>
> ⚠️ **读法**：第一部分是常识；第二到四部分只用老师资料，逐条带出处。⚠️ **资料里有几条带玄学成分的化解（寄名、中药埋土之类），本站只作原文记录，不作方法推荐、也无从验证**——这是教材原有的按语，这里照用。

## 一、常识：断出问题后能做的事

| 类别 | 例子 |
|---|---|
| **换方向** | 不适合当官就做技术，不适合合伙就自己干 |
| **避开时间** | 那一年不做大投资、不出远门、不签大合同 |
| **处理掉风险源** | 卖掉出事的车、退出高风险的生意、离开危险的工作 |
| **提前准备** | 体检、买保险、存钱、写合同 |
| **调整期望** | 孩子不是读书的料就早做打算 |
| **找专业的人** | 看病找医生、官司找律师、心理问题找心理医生 |
| **民俗做法** | 寄名、拜干亲、祭祀、择日——**心理安慰为主** |

⭐ **跟断命有关的一点**：资料的化解观正好是第一行——「**正确解读八字本身就是化解**（吉的方向多投入，凶的方向避开）」〔小任 · 初中级第12课〕。

## 二、老师的化解观

| 原话 | 出处 |
|---|---|
| ⭐ 「**可以减凶，很难改命**」 | 小任 · 初中级第12课 |
| ⭐ 「**正确解读八字本身就是化解**（吉的方向多投入，凶的方向避开）」；特定方法只能部分化解、因人而异 | 同上 |
| 正途是「**知命行事**」，做到**个人最优** | 同上 |
| ⭐ 「**改命的前提是知命**」 | 小任 · 公开课第4课 |

## 三、资料里的具体化解办法

### 3.1 换方向（对照常识「换方向」「调整期望」）

| 办法 | 原话 | 出处 |
|---|---|---|
| ⭐ 孩子学习 | 8 岁女孩「**食伤库在年柱、时柱都被闭了** ⇒ 父母别在成绩上太纠结，按她的干支意向和喜忌早做打算」 | 小任 · 初中级第12课 |
| 改行 | 「戌穿酉不动，不赚钱」⇒ **改行**买酒水开店就赚钱了 | 【题757】 |
| 不合伙 | 「与此命合作，一不会长久，二会为利益有争，**还是别合作为好**」 | 【题70】 |
| 修行 | 「**不给你磨难你不知道往哪里走，就逼你走另一条路的**」 | 【题476】 |

### 3.2 处理掉出事的那个字

| 办法 | 原话 | 出处 |
|---|---|---|
| ⭐ **卖车** | 卯酉冲在外出事、换司机都不行——「**不到辛卯年改行，把车卖掉，可以化解的**」 | 面授【题729】 |
| ⭐ **破财免灾** | 「财生官 ⇒ **官非来了让财去生它（花钱）⇒ 它就不克你**」 | v课 855 讲【题510】 |

⭐ **原理**：盘上是哪个字出事，**现实里就把那个字代表的东西处理掉**——车、行当、那笔钱。

### 3.3 用另一个字来通关、来制

| 办法 | 原话 | 出处 |
|---|---|---|
| 冲要化解 | 「庚甲相冲要化解，**找壬水来通关**（庚生壬、壬生甲）」 | 小任 · 初中级第14课 |
| 丙火忌癸 | 「化解用**戊土**——戊癸合着克癸，成『食神制杀』，反而比好事还好」 | 小任 · 初中级第10课 |
| ⭐ 克配偶 | 「一方八字克配偶，办法是『**硬碰硬**』——给他找一个也克配偶、命硬的」 | 小任 · 初中级第17课 |

⚠️ **资料未讲**：这些「找一个字」在现实里**怎么找**——是找那个五行的人、行业、方位，还是颜色？资料只给了命理上的原则。

### 3.4 避开时间

| 办法 | 原话 | 出处 |
|---|---|---|
| 四大空亡 | 「化解：**入空门，或三十三岁前不结婚不生子**」 | 小任 · 高级第9课 |
| ⭐ 交运 | 「**交大运前后三天之内（共六天）尽量不要外出，不要参加红白喜事，不要到人多的地方活动**」；「人在交运时，身心是很弱的，就像蛇在蜕皮一样」 | 大任 · 2012面授 p11 |
| 男女 | 「⭐ **男怕进女怕出**：男进了坏运的第一年就不好，女怕出坏运最后一年不好」 | 同上 |
| 防几月 | 「防午未月」 | 【题169】 |

### 3.5 生活方式

| 办法 | 原话 | 出处 |
|---|---|---|
| ⭐ **惜福** | 「原局财星浅薄……吃的穿的比较少，所以这个命如果提前看，**省吃俭用可以延寿，佛家讲惜福**」 | v课 802 讲【题497】 |
| 早断早调 | 「申亥穿伤亥中甲木：**早断早调理，肝病未成癌**」 | 【题299】 |

### 3.6 民俗做法（只作记录）

| 办法 | 原话 | 出处 |
|---|---|---|
| 灭门煞 | 「**破解：拜干亲**，以当地风俗为准，主指小孩」；「规避：**道家寄名、拜干亲**」 | 第15章；小任 · 高级第9课 |
| 干妈 | 「**男孩找克自己年柱纳音的，女孩找生自己年柱纳音的**——纳音在全局之外，表往外走的关系」 | v课 876 讲【题538】 |
| 中药埋土 | 银行官员被调查——「用猪毛、水蛭、矾三味中药加山岗上的土，按指定时间放到指定地方」⇒ 两个月后事已平息 | 神煞 p51【题202】 |

⚠️ 教材对【题202】的按语：「**化解那部分，本站只作原文记录，不作方法推荐、也无从验证**」；原文「**未解释化解的机理**」。

### 3.7 做这一行的人自己要守的

> ●⭐⭐ 「**选时辰要必须兼看六亲，钱可赚钱，但要负责，不然就要遭报应的。**」〔大任 · 面授 p76〕

## 四、六壬里的化解（出自《大六壬通解》与毕法赋课例）

| 课例 / 规则 | 断 |
|---|---|
| ⭐ 例146 避难逃生 | **认准生我之方逃，可脱险**——避克害就生护 |
| ⭐ 例158 舍损就益 | **舍掉身边的坏、投向三传的好** |
| 例58 传鬼为生 | **逢凶化吉、转祸为福** |
| 例134 抱鸡不斗 | 对头虚张声势、其实咬不动我，**虽斗无祸** |
| ⭐ 例184 | 「本月因长辈旧债起口舌……**忍一忍就过去**，若使气恐闹到官府」——「**断凶要留出『能不能忍』的余地**」 |
| 子孙为解神 | 「**子孙克官鬼**，因此子孙象征**痊愈、药物**」；「**子为杀鬼之神，主有良医解救**」 |
| 例72、例73 | 古人的病例：宜祭祷并服补剂、祭送后可安——**原书照录，现代先就医** |
| 「凶神凶将无克战，灾迍不作永和平」 | 凶将不克日干，灾就起不来 |

〔通解上 p101、p224-225；毕法赋〕

⭐ **对照常识**：例184「忍一忍就过去」就是最实在的化解——**有些凶是人自己闹大的**。

## 五、说法与分寸

| 做法 | 为什么 |
|---|---|
| **先说能做什么，再说凶** | 客人要的是办法 |
| **化解要落到实事上** | 卖车、改行、晚几年结婚、去体检——能做、能验证 |
| **病先劝就医** | 疾病、寿元、玄学各篇都写了 |
| **不夸大民俗做法** | 资料自己说「无从验证」 |
| **不收钱吓人** | 「钱可赚钱，但要负责」 |
| 「60 岁前不主动告知寿数」 | 小任讲义 p44 |

## 六、读完这一篇，你能做什么

1. 化解观：**可以减凶，很难改命；正确解读八字本身就是化解；改命的前提是知命**。
2. 具体办法：**换方向、处理掉出事的那个字（卖车、改行、破财免灾）、通关制化、避开时间、惜福**。
3. 民俗做法（寄名、拜干亲、干妈、埋药）**只作记录**。
4. 六壬：**认准生我之方、舍损就益、忍一忍**。

**资料未讲**：通关、制化的那个字在现实里怎么找；化解的机理。
