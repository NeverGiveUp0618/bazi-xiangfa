# 断事图 · 感情：恋爱、桃花、同居、情人——还没进婚姻（或在婚姻外）的那一段

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。来问「感情」的人，问的往往不是婚姻：**这个人能不能成**、**什么时候遇到对的人**、**分了还能不能复合**、**他是不是有家室**、**我为什么总谈不成**。不先知道一段感情有哪几个阶段、会卡在哪里，盘上看出「有桃花」，你说不清是正常恋爱、是情人、还是婚外情。
>
> **这一篇和「婚姻」的分工**：「婚姻」讲**结了婚以后**（好坏、离婚、几次婚、丧偶）；这一篇讲**婚前恋爱**和**婚姻外的感情**。两篇共用一套「宫与星」，框架去「婚姻」2.1 查。
>
> **这一篇分五部分**：
> **一、常识**：感情的几个阶段、几种关系、为什么谈不成、几种常见难题（这部分是常识，不是命理规则）
> **二、八字怎么对上**：恋爱对象还是结婚对象 → 桃花怎么看 → 情人、暧昧、私奔 → 几次恋爱都不成 → 单身 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**：这一段成不成（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。

## 一、常识：感情是怎么回事

### 1.1 一段感情的几个阶段

| 阶段 | 样子 |
|---|---|
| **认识** | 同学、同事、朋友介绍、相亲、网上 |
| **暧昧** | 互有好感、没挑明 |
| **恋爱** | 确定关系 |
| **同居** | 住在一起但没领证 |
| **谈婚论嫁** | 见家长、谈彩礼、定日子 |
| **结婚** | 领证（之后见「婚姻」篇） |
| **分手** | 任何一个阶段都可能停下 |

⭐ **跟断命有关的一点**：多数人一辈子谈过不止一个，但结婚的只是其中一个。资料里专门分「**婚前朋友**」和「**配偶**」（见 2.1）——**谈过的人不一定上盘当配偶看**。

### 1.2 几种关系

| 关系 | 样子 |
|---|---|
| **正常恋爱** | 双方单身、公开 |
| **早恋** | 中学阶段 |
| **异地恋** | 两地分开 |
| **姐弟恋、老少恋** | 年龄差大 |
| **相亲** | 介绍认识、以结婚为目的 |
| **情人、婚外情** | 至少一方有家室 |
| **暧昧、不确定关系** | 不挑明、不负责 |
| **私奔** | 家里不同意，自己走了 |
| **同性** | — |

### 1.3 为什么谈不成（常见原因）

| 原因 | 样子 |
|---|---|
| **条件不合** | 家境、学历、收入、地域差太多 |
| **家里反对** | 父母不同意、彩礼谈不拢 |
| **性格不合** | 吵架、冷战 |
| **时机不对** | 异地、一方要读书、工作调动 |
| **有第三者** | 一方另有人 |
| **自己不想** | 不想结婚、不想被拘束 |
| **眼光太高或太低** | 挑来挑去，或总遇到不合适的 |

### 1.4 常见难题

| 来问的 | 实际要断的 |
|---|---|
| 「他到底喜不喜欢我」 | 这段关系有没有、成不成 |
| 「我什么时候遇到对的人」 | 应期 |
| 「分了能不能复合」 | 这一段还有没有后续 |
| 「他是不是有家」 | 对方的身份 |
| 「我为什么总谈不成」 | 命里的结构 |
| 「我要不要一直单身」 | 有没有婚姻 |

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 恋爱对象还是结婚对象（对照常识 1.1）

> 「凡与**日干或配偶宫有关系**的星方可当配偶星看，**如无关系，只表示婚前朋友**。」〔婚姻篇 p2〕
> 关系＝「**刑、冲、克、害、合、生，都叫关联**」〔十八道法门 p52〕

| 盘上 | 断 | 出处 |
|---|---|---|
| 星与日干、配偶宫**有关联** | 配偶 | 婚姻篇 p2 |
| 星与日干、配偶宫**没关联** | **婚前朋友** | 同上 |
| ⭐ **年上桃花** | **正常恋爱，不是婚外情**——年柱对应少年时期 | v课 705、687 讲 |
| ⭐ 大运带来的字 | 「**过路的**」——同居九年未婚 | v课 707、708 讲【题399】 |

### 2.2 桃花怎么看

| 盘上 | 断 | 出处 |
|---|---|---|
| ⭐ **女命的禄与别的十神合（除印星外）** | 一般都表示桃花——「**禄表示女人的身体、肉体**……用肉体去合别人」 | 实战技巧 p6-7【题24】 |
| **禄合财官** | 桃花；禄在时上主要看，在年一般不看，月令上连体或生过来才看 | v课 687 讲 |
| **食伤合财、合官**；食伤坐财；食伤生财、食伤合住比劫 | 桃花 | 同上 |
| 女命**食伤生财** | 犯桃花（很早谈恋爱） | v课 875 讲【题538】 |
| 女命**食伤合官** | 桃花（食伤＝欲望）；加上官带财帽 | 836 讲；【题451】 |
| 男命**官杀当财看** | 易犯桃花 | v课 773 讲【题472】 |

| ⭐ 酉与日主发生关联 | 「**酉同日主发生了关联，所以才有桃花**」 | 面授 p70【题698】 |

### 2.3 情人、暧昧、私奔（对照常识 1.2）

| 现实 | 盘上 | 出处 |
|---|---|---|
| **婚前就有情人，婚后还保持** | 「**月乙表情人**，乙坐丑表乙**有家庭**，**寅丑暗合，偷偷的与情人好**」 | 例题解 p10【题8】 |

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬占**这一段**：这个人成不成、对方是不是真心。

### 3.1 主线

> 「**夫卜妻姻成不成，财居旬后总无情。女推夫婿将何断，鬼坐天中同此评。**」注：「**财为妻，官鬼为夫**……**财官无气空亡，则婚姻失败**。」〔通解上 p217｜PDF p232〕

| 谁占 | 看什么 | 天将 |
|---|---|---|
| 男占女 | **妻财** | **青龙** |
| 女占男 | **官鬼** | **天后** |
| 和合、媒人、私情 | — | **六合**（「和合、交易、婚姻、**私情**」） |

〔通解上 p78、p103〕

### 3.2 成不成：两法对

> 「**传将生合百年配，干支刑克朝夕背**……**男女年命孰相加，欲其事遂两法对**。」〔通解上 p217〕

干支之间看一遍生合刑克，**男女年命上神**之间再看一遍，两处都吉才是真吉；**男年旬空亦不能成事**。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **已婚还是未婚** | 桃花在婚前是恋爱，婚后是婚外情 | 把正常恋爱说成婚外情 |
| **问自己还是问对方** | 六壬男占看财、女占看官 | 类神取反 |
| **有没有具体的人** | 有人就占这一段，没人就看应期 | — |
| **年龄、在什么地方** | 「要结合地域风俗」 | 早婚晚婚标准不对 |

⚠️ 断出「对方有家庭」「女方虚意」这类话，**说得委婉**，给人留余地。

## 六、读完这一篇，你能断什么

1. **恋爱对象还是结婚对象**：跟日干、配偶宫有关联才是配偶；年上桃花是正常恋爱；大运带来的是过路的。
2. **桃花**：不看子午卯酉；女命禄合十神（除印）、食伤合财官、男命官杀当财。
3. **情人、私奔**：暗合偷偷、藏而不透暗藏、移到时柱远方。
4. **谈不成**：宫制不住星、合而被穿。
5. **单身**：三种情况，各有盘象。
6. 六壬：这一段成不成，谁主动、是否虚意、有没有人搅。

**还断不了的**（资料未讲）：分手复合的专门断法；异地恋、姐弟恋的专门象；同性恋；网恋。
