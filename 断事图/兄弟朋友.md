# 断事图 · 兄弟朋友：手足、朋友、同事、合伙人，是帮我还是分我

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。八字里「比劫」一个字，管的人最杂：亲兄弟、同父异母的兄妹、同学、同事、合伙人、竞争对手、骗你钱的表兄弟、团伙里的同伙。盘上看出「劫财夺财」，你得分清是**生意被同行抢了**、**钱借给朋友收不回**，还是**被亲戚骗了**——现实里这几种人和事完全不同。
>
> **这一篇分五部分**：
> **一、常识**：兄弟姐妹的几种关系、朋友同事合伙人的几种人（这部分是常识，不是命理规则）
> **二、八字怎么对上**：谁代表他们 → 是一伙还是外人 → 兄弟姐妹的情况 → 比劫多的人 → 被分、被抢、被骗 → 合伙与团伙 → 领导、同事、下属（全部出自资料，逐条带出处）
> **三、六壬怎么看**
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。
>
> ⚠️ 合伙做生意的细节另见「公司经营」篇 2.5。

## 一、常识：身边的同辈人

### 1.1 兄弟姐妹

| 关系 | 是什么 |
|---|---|
| **亲兄弟姐妹** | 同父同母 |
| **同父异母、同母异父** | 父母一方再婚生的 |
| **继兄弟姐妹** | 父母再婚、对方带来的孩子，没有血缘 |
| **堂、表兄弟姐妹** | 叔伯家、姑舅姨家的孩子 |
| **独生子女** | 没有兄弟姐妹 |

**兄弟姐妹之间常见的事**：小时候一起长大或分开长大；成年后互相帮扶、或为父母养老和遗产起争执；一方有病残要另一方照顾；一方欠债拖累家里。

### 1.2 朋友、同事、合作的人

| 人 | 是什么 |
|---|---|
| **朋友、同学** | 平辈交往 |
| **同事** | 一个单位的平级 |
| **合伙人** | 一起出钱做事（另见「公司经营」篇） |
| **竞争对手、同行** | 抢同一块生意 |
| **团伙** | 一起做事——好事坏事都可能（另见「官司」篇） |
| **贵人** | 帮你的人，常是长辈、领导 |
| **小人** | 背后坑你、骗你的人 |

### 1.3 职场里的上下左右

| 方向 | 人 |
|---|---|
| **上** | 领导、老板 |
| **平** | 同事、同行 |
| **下** | 下属、员工、客户 |

⭐ **跟断命有关的一点**：十神里正好有对应——**官杀＝领导**、**比劫＝同辈、同伙、竞争者**、**财＝下属、客户**、**印＝长辈、师长**（教材第 5 章十神人物表）。

### 2.2 是一伙，还是外人

这是断比劫最要紧的一步。

> 「**禄比分三层**：坐禄＝我（不能坏）｜连体＝以我为主｜**不连＝纯粹的别人，可以制**。」〔断命台 ⑤·B〕
> 「比劫与日主**连成一体**（日时相连、月日同气）⇒ 比劫已并入『我』。此时**劫财合财＝帮我合财**（合作得财、团队分润但助我掌控），**不能断成别人夺财**。」〔讲义 p229〕

| 盘上 | 现实 |
|---|---|
| 比劫与日主**连体** | **自己人**：一起干、帮我（团队、合作得财） |
| 比劫**不连体** | **外人**：竞争者、来分的人 |
| ⚠️ 比劫能否为体，看与日主的作用关系 | 「**是否有情、有生、有利**；不能单凭五行相同就认为比劫是帮我的」〔小任 · 初中级第 20 课〕 |

**对照常识 1.2**：同样是「朋友」，有的是一起打拼的伙伴，有的是来抢生意的同行——盘上就分在「连体」和「不连」两边。

## 三、六壬怎么看（出自《大六壬通解》）

> **人类神歌**：「**兄弟姊妹责太阴，及兼兄弟之爻神**……**朋友单来责六合**。」〔通解中 p482｜PDF p118〕

| 要占的人 | 看哪几个 |
|---|---|
| **兄弟姐妹** | **太阴**；兼兄弟爻（与日干同五行者） |
| **朋友** | **六合** |
| **贵人、领导** | **贵人**（天乙）；第 3 课 |

**求财时忌兄弟爻**：「占求财**最忌讳兄弟爻过旺**」——比肩太旺＝分夺〔通解上 p239〕。对照现实：同行多、合伙人多，钱就被分走。

**谁是我、谁是对方**：日干＝我，日支＝对方（第 14 课）。「**日辰各受上神生**＝两家顺利有生意」「**日辰各受上神克**＝两家俱伤都不利」「**日辰互见刑害**＝宾主不投怀猜忌」〔通解上 p131〕——问「和这个人合作行不行」，先看这几句。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁**：亲兄弟、朋友、同事、合伙人、对手？ | 2.1：比劫管的人太多，先定是哪一种 | 把同行竞争断成兄弟不和 |
| **有几个兄弟姐妹、是不是同父同母**？ | 2.3：血缘不清、重组家庭 | 漏掉同父异母的线索 |
| **问的是哪件事**：合不合得来？能不能合作？会不会被骗？ | 2.2：先分一伙还是外人 | 把一起打拼的伙伴断成「夺财」 |
| **有没有对方的生辰**？ | 六壬看日辰两家；八字合作最好两盘对 | 只看一方就断对方人品 |
| **现在有没有借钱、担保、合伙**？ | 2.5、2.6：被分被骗多出在钱上 | 断出「破财」却说不出从哪来 |

## 六、读完这一篇，你能断什么

1. **谁代表谁**：比劫＝兄弟、朋友、同伙、竞争者；官杀＝领导；财＝下属客户；印＝长辈贵人。
2. **一伙还是外人**：连体是自己人，劫财合财是帮我；不连是外人，可以制。
3. **兄弟姐妹的情况**：穿月令比劫＝血缘不清的兄妹。
4. **比劫多的人**：任性、辛苦、易糊涂、不爱学；也胆子大。
5. **被分、被抢、被骗**：主位临财外遇劫；财合劫财是别人指使。
6. **合伙、团伙**：不能合伙的几种盘；劫财伤官拉帮结派。
7. **领导同事**：卯申暗合会搞关系；食伤制官让领导听我的。
8. 六壬：兄弟看太阴、朋友看六合；求财忌兄弟爻旺；日辰两家生克看合作。

**还断不了的**（资料未讲）：兄弟姐妹有几个的通用数法；独生子女的样子；八字里「贵人」的专门判法。
