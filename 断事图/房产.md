## 一、常识：房子是怎么回事

### 1.1 房子的种类

| 种类 | 是什么 | 要点 |
|---|---|---|
| **商品房（新房）** | 开发商建、对外销售 | 可能是期房（还没建好）或现房 |
| **二手房** | 别人住过、转卖的 | 过户、税费 |
| **自建房（宅基地）** | 农村在自家宅基地上盖的 | 一般不能卖给村外人 |
| **小产权房** | 建在集体土地上对外卖的 | 没有正式产权，有风险 |
| **安置房、拆迁房** | 拆迁后分的房 | 有时有限制交易年限 |
| **保障房** | 经济适用房、公租房等 | 有条件限制 |
| **商铺、写字楼、厂房** | 非住宅 | 土地年限一般短于住宅 |
| **祖屋、老房** | 上辈留下的 | 继承、分家 |

### 1.2 产权与归属

- **不动产权证（房产证）**：证明房子归谁。没证的房子买卖、继承都麻烦。
- **住宅土地使用权一般 70 年**，商业 40 年左右。
- **共有**：夫妻共有、家庭共有、几个人按份共有。
- **婚前婚后**：婚前一方全款买的一般归个人；婚后共同还贷的部分涉及共同财产。
- **继承**：父母去世后房子按遗嘱或法定继承分，兄弟姐妹之间常有纠纷。
- **抵押**：贷款买房时房子抵押给银行；做生意也常拿房子抵押借钱。

### 1.3 买房一般怎么走

```
  看房 → 交定金 → 签合同（网签）→ 付首付 → 办贷款 → 过户（二手）/ 等交房（新房）
       → 拿钥匙 → 装修 → 入住 → 每月还贷
```

- **首付 ＋ 按揭**：大多数人是首付三成左右，其余向银行贷款，分二三十年还。
- **公积金贷款**利息低，有额度限制。

### 1.4 房子常出的问题

| 问题 | 是什么 |
|---|---|
| **房价下跌** | 买贵了，房子值不了贷款那么多 |
| **断供** | 还不起月供，银行收房拍卖（法拍房） |
| **烂尾** | 开发商没钱，房子建不完 |
| **抵账房** | 开发商、老板没钱给，拿房子车子抵欠款，常是旧房、二手房 |
| **产权纠纷** | 继承、离婚分房、一房多卖 |
| **违建、拆除** | 没手续被拆 |
| **拆迁** | 有补偿，也有补偿谈不拢的 |
| **搬家频繁** | 租房、工作调动、换房 |

⭐ **跟断命有关的一点**：资料里有「**房子跌、负债**」「**拿房子车子抵账，抵来的是二手旧房旧车**」「**要移家，且要移四次**」「**祖业得不到**」——都是这张表里的事。

### 1.5 搬家、装修、动土（2026-10-23 并入）

| 事 | 常识 |
|---|---|
| **搬家的几种** | 租房换房、买新房入住、工作调动、回老家、出国定居、子女接老人同住 |
| **入住新房** | 新房装修后一般建议通风几个月再住（甲醛等） |
| **装修** | 自己装、找装修公司；常见纠纷：**超预算、拖工期、偷工减料、装修公司跑路** |
| **动土、盖房** | 农村自建房要审批（宅基地、规划）；**没手续盖的可能被认定违建** |
| **施工安全** | 自建房、装修高处作业，**摔伤**常见 |
| **拆迁** | 有补偿；补偿谈不拢、强拆是常见纠纷 |
| **民俗** | 很多人搬家、动土要**择日**——这一块属于择日，不在这一篇 |

⭐ **跟断命有关的一点**：资料里有「父亲**盖房从高处摔下来**」〔【题104】〕、「**买了一块连带门面的地皮盖房**，对方反悔想收回，一直纠缠」〔【题58】〕——都是这张表里的事。

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 什么字代表房子

| 字 | 为什么 | 出处 |
|---|---|---|
| ⭐ **印** | 印的事物类象有两大主题：**庇护性**——房屋、衣物、食物；**制度性**——证书、公章；物有**房屋、车子、证件（房产证）** | 小任 · 初中级第 5、18 课 |
| **印通根** | 实际的房产；印虚透＝有名无实 | 教材第 3 章 |
| **财星** | 「印大部分情况代表房子但**不绝对，财星也可以代表房产**」；**正财＝固定资产（房产土地）** | 小任 · 初中级第 18 课；第 5 章 |
| **官杀**（官当财看时） | 「**官杀多 ⇒ 房多**——官杀代表可支配的产业房产」 | 讲义 p192 |
| **日柱** | 宫位「用物」层：日＝**房子、卧室、私产** | 教材第 4 章 |
| **墓库** | 「把墓库理解成**一间房子**：外壳都是土，里面可以装不同的东西」 | 小任 · 高级第 4 课 |
| **戊、己** | 戊＝政府、建筑、**房地产**；己＝庭院、**房屋**、墓地、建材 | 教材第 2 章十干类象 |
| **甲** | 「**甲也是房，房上见房是楼房**」 | 中级班 p15 |
| **偏印** | 房子带「偏」：**地下室、密室**；卖房子的 ⇒ 卖墓地的 | 小任 · 初中级第 18 课 |

**对照常识 1.1**：同样是「房」，正印像住的家，偏印像地下室、墓地这类特殊的房；印是「住」，正财是「资产」——自住和投资是两回事。

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：占家宅（这个家安不安、人宅谁旺），或占**这一套房**能不能买、该不该搬。

### 3.1 日为人，支为宅

> 第 13、14 课：**日干＝我、人；日支＝家宅、所占之物。**

**人和宅谁旺**（通解上 p131）：

| 课象 | 断 | 对照常识 |
|---|---|---|
| 日临辰上去生辰 | **宅旺人衰**，虚耗频 | 房子越弄越好，人越来越累（还贷、装修） |
| 日临辰上去克辰 | 事虽费力**得财** | — |
| 日辰逢败 | **人宅颓** | 家道中落 |
| 辰课不足 | **家宅忧** | — |
| 日见辰马 | **宅动**（君子迁官，小人宅动） | 搬家 |
| 日辰乘墓坐墓 | 俱主昏迷云雾中 | — |

**毕法赋两法**（第 29、30 法）：

| 法 | 讲什么 | 对照常识 |
|---|---|---|
| 「**眷属丰盈居狭宅**」 | 三传生干＝**人旺宅狭** | 人多房小 |
| 「**屋宅宽广致人衰**」 | 三传盗脱日干、反生支＝**宅胜人、屋广人稀** | 房大人少 |

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是哪件事**：有没有房？买不买？卖不卖？搬不搬？家里安不安？ | 八字看一辈子的房产和时机，六壬看这一次 | 用八字回答「这套房该不该买」 |
| **自住还是投资**？ | 2.1：印偏「住」，财偏「资产」 | 投资的事按自住断 |
| **房子是谁的**：自己买、父母给、继承、婚后共有？ | 1.2：归属不同 | 父母的房断成本人的 |
| **有没有贷款、抵押**？ | 1.4：跌价、断供的风险 | 断出「房子跌」，说不出要不要紧 |
| **做什么工作**？ | 2.7：做房地产、建筑的人，房子象可能是职业 | 把盖楼的职业象断成本人买房 |
| **城市还是农村、老房还是新房**？ | 1.1：宅基地、拆迁、祖屋各有各的事 | 农村祖屋按商品房断 |
| **问的是买卖，还是搬家、装修、盖房**？ | 1.5、2.5·B、3.4：搬不搬看人宅旺衰和马星 | 把「该不该搬」当成「该不该买」断 |

## 六、读完这一篇，你能断什么

1. **什么字代表房子**：印、财、官当财、日柱、墓库、戊己、甲。
2. **有没有房、几套**：官当财看时数官；印虚透是名下有、手里没有。
3. **祖业**：年月是祖业；空了拿不到；离祖。
4. **买、卖、盖、拆**：财库冲开置房；偏财说卖就卖；合克是盖、穿克是拆。
5. **搬家**：印伏吟移位，几个伏吟搬几次。
6. **出问题**：财坏印＝房子跌、负债；来源被破＝抵来的是旧房。
7. **做房地产的人**：印看财、卯戌合。
8. 六壬看**家宅**：日人支宅，宅旺人衰、人旺宅狭，太岁临支、驿马宅动。

**还断不了的**（资料未讲）：几个印几套房；断供、烂尾、法拍、产权纠纷、拆迁补偿；六壬占买房这一单。
