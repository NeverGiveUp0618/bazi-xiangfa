# 断事图 · 出行：走不走得了、在外好不好、人回不回来

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「出行」在现实里包括好多种：出差、旅游、去外地打工、驻外、留学、移民、跑运输、搬家离乡，还有「人出去了，什么时候回来」。盘上看出「驿马逢冲」，你得知道是**出差调动**、**开车跑运输**，还是**车祸**——资料里这三种都在同一个象下面。
>
> **这一篇分五部分**：
> **一、常识**：出行的种类、出国的几条路、人在外的常见情况（这部分是常识，不是命理规则）
> **二、八字怎么对上**：远近 → 驿马 → 外地求财工作 → 出国移民 → 离乡 → 跑动多的人 → 在外出事 → 什么时候动（全部出自资料，逐条带出处）
> **三、六壬怎么看**：这一趟能不能走、人什么时候回来、跑掉的人找不找得到（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。

## 一、常识：出行是怎么回事

### 1.1 出行的种类

| 种类 | 是什么 | 一般多久 |
|---|---|---|
| **旅游** | 出去玩 | 几天到几周 |
| **出差** | 单位派出去办事 | 几天到几个月 |
| **驻外、外派** | 长期派到外地或国外的分支机构 | 一年到几年 |
| **外地务工** | 离开家乡去城市打工 | 常年在外，过年回家 |
| **调动** | 工作调到别的城市 | 长期 |
| **留学** | 去国外读书 | 几年 |
| **移民** | 换国籍或长期定居国外 | 长期 |
| **搬家、迁居** | 换城市生活 | 长期 |
| **跑动型职业** | 司机、运输、快递外卖、销售、导游 | 天天在路上 |

⭐ **跟断命有关的一点**：资料把这些分得很细——驿马配财是「**异地求财**」，配官是「**出差调动外派**」，配印是「**外出求学、考证、搬家置业**」，马在时是「**休闲旅游**」。先问清是哪一种出行。

### 1.2 出国的几条路

| 途径 | 要点 |
|---|---|
| **旅游签证** | 短期 |
| **留学签证** | 读书期间可居留 |
| **工作签证** | 被国外单位聘用 |
| **绿卡、永久居留** | 可长期居住，仍是原国籍 |
| **入籍（换国籍）** | 取得外国国籍；**中国法律不承认双重国籍**，入外籍会自动失去中国国籍 |
| **劳务输出** | 通过中介去国外务工 |

### 1.3 人在外的常见情况

| 情况 | 样子 |
|---|---|
| 在外**发展得好** | 外地有事业、成家、定居 |
| **奔波辛苦** | 在外工作累、不称心 |
| **想走走不了** | 签证、工作、家里拖住 |
| **出去了想回来** | 半路回头、在外待不住 |
| **一去不回** | 在外定居，或失联 |
| **在外出事** | 车祸、生病、被骗、官司 |
| **跑掉、失联** | 离家出走、躲债、私奔 |

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 远和近

| 盘上 | 断 | 出处 |
|---|---|---|
| ⭐ **年柱＝远方，时柱＝门户**（出门的进出口） | 「比如你要出远门，命中对应的宫位就是年柱或者时柱」 | 初级班 p10 |
| **年时主远，月日主近** | 配偶星在年本主外地，被月柱合住 ⇒ 可能是「祖上外地、实为本地」 | 公开课课时 3 |
| **坐下为近，年上为远方** | 「近处好，远方则不行」 | 【题707】 |
| **月日一体** | 断本地、外地最常用：子＝本地、丑＝外地 | 【题387】 |
| **两宫相克＝远，相生＝近**；绝＝彻底无关 | — | 教材第 4 章 |
| ⭐ **穿也管距离** | 「本来两家很近，**一穿就距离远了**」 | 【题659】 |
| **穿跑** | 「**穿跑＝动到远方或流失**（年月穿离祖；**穿得远主出国远行**）」 | 讲义 p151 |
| **大运带来的字** | 「**原局没有的字、大运带来的字＝外来的、远方的、临时的、过路的**」 | 【题399】 |
| 出门用的车 | 「看车，那就在时柱上找，因为时柱代表门户」 | 初级班 p10 |

⭐ **离日柱越近，越是「你的」**；年柱、时柱上的好东西，常常**是别人的、或要到远方才有**〔教材第 16 章〕。

### 2.2 驿马：动神

**查法**：以年支查——申子辰马在寅、寅午戌马在申、亥卯未马在巳、巳酉丑马在亥〔小任 · 高级课时 9〕

| 分类 | 是什么 |
|---|---|
| **真马** | 按上法查出的那一支 |
| **假马** | 寅申巳亥四长生都可当马看；⭐ **申最显**——金属外壳＋壬水燃油，**像汽车** |
| **地马** | 地支见马 |
| **天马** | 天干透马的禄（如马在寅、透甲）——**主飞机、高空**、灵感、思维跳跃 |

〔小任 · 高级课时 9〕

**对照常识 1.1**：

| 马配什么 | 现实里的出行 | 出处 |
|---|---|---|
| **马＋财** | **异地求财**（「马奔财乡，发如猛虎」，前提是控得住财） | 高级课时 9 |
| **马＋官** | **出差、调动、外派** | 同上 |
| **马＋印** | **外出求学、考证、搬家置业** | 同上 |
| **马在时** | **休闲旅游** | 同上 |

| 马落哪一柱 | 断 |
|---|---|
| 年 | 早年迁徙、祖上离乡 |
| 月 | 青年期工作生活变动 |
| 日 | 配偶外地人、分居或聚少离多 |
| 时 | 晚年走动、子女远行 |

〔高级课时 9〕

**吉凶**：

| 规则 | 出处 |
|---|---|
| 「**马星是喜神不可坏，坏则凶；是忌神可以制，制则吉**」 | 小任 · 高级第 9 课 |

### 2.3 外地求财、外地工作

| 现实 | 盘上 | 出处 |

### 2.4 出国、移民（对照常识 1.2）

| 现实 | 盘上 | 出处 |
|---|---|---|
| **到国外求财工作** | 印禄相随好学习，食伤得库聪明有文凭 | 【题765】 |
| **出国远行** | 穿得远 | 讲义 p151 |
| **移民** | 癸卯 甲子 甲午 己巳（坤，移民美国）：根在年支卯（出生地），养她的是月上子水；**子卯破、破则不生 ⇒ 生你的地方和养你的地方不是一处**；⭐ **印星可以表示政策、文书、证件、身份** ⇒ 两个印两个地方 ⇒ 资料原话作「两个国籍」 | 小任 · 初中级（教材第 14 章八·F） |

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一趟**能不能走、路上顺不顺、**这个人**什么时候回来。

### 3.1 这一趟能不能走：五成七战

> 「**出行先看天干踪，务求地道五成逢。中末两仪玩其意，七战当须断是凶。**」
> 注：「**天干踪**指**天盘日干所临处**。**五成，为德、合、生、旺、相**。**七战，指刑、害、冲、克、空、墓、绝**。」〔通解上 p228｜PDF p243〕

| | 内容 | 断 |
|---|---|---|
| **五成** | 德、合、生、旺、相 | 吉，可行 |
| **七战** | 刑、害、冲、克、空、墓、绝 | 凶，不可行 |

> 💡 找到日干寄宫在天盘的位置，看它落在什么关系上，五成里占一个就偏吉，七战里占一个就偏凶。

### 3.2 路上：三传看行程

> 「**中末逢空初不空，行人半路欲回程。初中空陷末传助，在此艰难在彼丰。**」〔通解上 p228｜PDF p243〕

| 三传 | 断 | 对照常识 1.3 |
|---|---|---|
| 初传不空、**中末空** | **半路要回来** | 出去了待不住 |
| 初中空陷、**末传有长生财禄** | **在此艰难在彼丰**——这里难，到那边好 | 外地发展得好 |
| 末传脱气、空亡、官鬼 | 不可进，**不动为吉** | 别去 |
| **支墓做干财** | 「**商贩哭将来**」——出行经商凶 | 外出做生意赔 |

**驿马**：「占出行见驿马是**好事**（主动、可成行）；占家宅、疾病比较忌讳驿马」〔第 20 课〕——**同一个马，占出行吉，占家宅凶**。

### 3.3 人什么时候回来：行人

> 「**二马**，天马、驿马**临初传，又逢生旺，主行人即回**。中传稍迟，末传又稍迟。如**乘传送、白虎则急**……**如入墓夹克则不行**。」〔通解上 p231｜PDF p246〕

| 二马落在 | 归期 |
|---|---|
| **初传**且生旺 | **即回** |
| 中传 | 稍迟 |
| 末传 | 又稍迟 |
| 乘传送（申）、白虎 | **急** |
| **入墓**（如亥马加辰）、**夹克** | **回不来** |

> ⭐ 「**传逆贵逆日用前，白虎催程返故园**」——「**顺则游，逆则归**」：三传顺行、贵人顺治＝人还在往外走；**逆行＝要回来了**。〔通解上 p231｜PDF p246〕
> 「行人逢**马落长生**或**马落空亡**，则**行人不归**。」〔通解上 p76｜PDF p91〕

### 3.4 跑掉的人找不找得到：逃亡

> 「**追寻达士详日德，捕捉逃奴看支刑。德克刑神必易获，刑克日德定难寻。**……**伏吟主近无依遐**。」〔通解上 p244｜PDF p259〕

| 见到 | 断 | 对照常识 1.3 |
|---|---|---|
| 日德克支刑 | **容易找到** | — |
| 支刑克日德 | **难找** | — |
| **伏吟** | **人没走远** | 离家出走、躲在附近 |

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **哪种出行**：旅游、出差、外派、打工、留学、移民、搬家？ | 1.1、2.2：马配财、官、印、在时各是一种 | 把出差断成移民 |
| **问的是哪件事**：能不能走？在外好不好？什么时候回来？ | 八字看一辈子在本地还是外地，六壬看这一趟 | 用八字回答「这周的航班能不能走」 |
| **现在人在哪**：家里、外地、国外？ | 远近是相对的，先定「本地」是哪里 | 本地外地颠倒 |
| **做什么工作**？ | 2.6：司机、外卖、销售本来就在跑 | 把职业的马当「要出远门」 |
| **问的是谁**：本人、孩子、配偶？ | 马落哪一柱管的人不同 | 孩子远行断到本人身上 |
| **开不开车、坐什么车** | 2.7：马星的灾多与车有关 | 人家不开车，你断车祸 |

## 六、读完这一篇，你能断什么

1. **远和近**：年时远、月日近；穿管距离；大运带来的是过路的。
2. **驿马**：真马假马天马；配财、官、印、在时各是一种出行。
3. **外地求财、工作**：申亥穿在时＝驻外地，辛苦不称心。
4. **出国、移民**：印表身份证件，两个印两个地方。
5. **离乡**：月柱吉神被日冲、年月穿。
6. **跑动多的人**：日坐马星、禄当财。
7. **在外出事**：马逢冲穿＝急行或车祸。
8. 六壬看**这一趟**：五成七战；中末空半路回；**顺则游、逆则归**；伏吟人没走远。

**还断不了的**（资料未讲）：八字里几岁出去、几岁回来；签证、入籍办不办得成；旅游这一趟顺不顺（八字层面）。
