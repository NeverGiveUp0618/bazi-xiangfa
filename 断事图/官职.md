> **四、案例**：题库里的命例按级别排好，从村干部到部长
> **五、断之前先问清**：哪些事不问清就断不准
>
> ⚠️ **读法**：第一部分是我按公开的制度写的常识；第二、三部分只用老师资料，**资料没讲到的格子留空、写明「资料未讲」**，不自己编规则。两部分并排放的「对应」，是我把常识和资料原话摆到一起，方便你对照——**原话在右栏，配对是否妥当，以老师讲的为准**。

## 一、常识：中国的官是怎么分级的

### 1.1 「公务员」「干部」「官」不是一回事

平时说「当官」，其实混着三种人：

| 说法 | 指谁 | 要点 |
|---|---|---|
| **公务员** | 依法履行公职、纳入国家行政编制、由国家财政负担工资福利的工作人员 | 党委、人大、政府、政协、监委、法院、检察院、民主党派、群团机关里的在编人员都算。**进门要考**（国考、省考） |
| **参公人员** | 「参照公务员法管理」的事业单位人员 | 如部分协会、中心、局属单位。待遇、级别比照公务员 |
| **事业编** | 学校、医院、科研院所等事业单位人员 | **不是公务员**。校长、院长也有「行政级别」的说法（如副厅级高校），但那是单位的规格 |
| **国企干部** | 国有企业管理人员 | 部分央企、省属国企的负责人有对应的行政级别，但身份是企业人员 |
| **村干部** | 村党支部书记、村委会主任等 | **不是公务员，没有行政级别**。村委会是群众自治组织 |
| **军官** | 现役军官 | 有自己的职务等级和军衔，与地方级别怎么对应说法不一，以本人讲的职务为准 |

⭐ **跟断命有关的一点**：老师在【题518】里说「**公务员不叫官，副科级起才算**」——普通科员只是公务员，**副科级领导职务起才叫「官」**。这和现实制度是一致的：科员是「职级」，副科长才是「领导职务」。

### 1.2 两条线：领导职务和职级

2019 年起公务员实行「**职务与职级并行**」，一个人身上有两条线：

**① 领导职务**（管人管事、有实权的位子），从高到低十个层次：

| 层次 | 正职 | 副职 |
|---|---|---|
| 国家级 | 国家级正职 | 国家级副职 |
| 省部级 | 省部级正职（省长、部长） | 省部级副职（副省长、副部长） |
| 厅局级 | 厅局级正职（地级市长、厅长） | 厅局级副职（副市长、副厅长） |
| 县处级 | 县处级正职（县长、处长） | 县处级副职（副县长、副处长） |
| 乡科级 | 乡科级正职（乡镇长、科长） | 乡科级副职（副乡镇长、副科长） |

**② 职级**（只定待遇、不带实权），综合管理类从高到低：

| 职级 | 大致相当于 |
|---|---|
| 一级、二级巡视员 | 厅局级正职、副职的待遇 |
| 一级至四级调研员 | 县处级正职、副职的待遇 |
| 一级至四级主任科员 | 乡科级正职、副职的待遇 |
| 一级、二级科员 | 科员 |

⭐ **跟断命有关的一点**：职级是「**有级别、没位子**」——工资待遇上去了，但不管人不管事。很多人到了年纪从领导岗位退下来改任职级，或者一直升不上领导职务就走职级。这正好是命理里「**有名无实**」那一类情况的现实样子（见二·3「实职还是虚职」）。

### 1.3 常见职位对应什么级别

| 级别 | 常见职位（地方） | 常见职位（中央、省直） |
|---|---|---|
| **正部级** | 省委书记、省长、直辖市市长 | 部长、主任（国务院组成部门） |
| **副部级** | 副省长、省委常委；**副省级城市**（如深圳、宁波、厦门、青岛、大连等）的市委书记、市长 | 副部长 |
| **正厅级** | **地级市**市委书记、市长；省直厅局的厅长、局长 | 部委的司长、局长 |
| **副厅级** | 地级市副市长、市委常委 | 副司长 |
| **正处级** | **县**委书记、县长、县级市市长、市辖区区长；地级市的局长 | 处长 |
| **副处级** | 副县长、县委常委；地级市的副局长 | 副处长 |
| **正科级** | **乡镇**党委书记、乡镇长；县里的局长；市局里的科长 | 科长（中央部委的科长、副处长级别会偏高，看具体单位规格） |
| **副科级** | 副乡镇长；县局副局长；股长（部分地方） | 副科长 |
| — | 村支书、村主任（无行政级别） | — |

⚠️ **三个容易看错的地方**：
1. **同一个名称，级别可以差很远**。「局长」可以是正科（县局）、正处（市局）、正厅（省厅）、正部（国家局有的是副部级）。断盘时说「局长」不够，要说「哪一级的局长」。
2. **高配和低配**。重要的县委书记有时由副厅级干部担任（高配），这时「县委书记」就是副厅。
3. **副省级城市**的市长是副部级，比一般地级市长高半级。

### 1.4 正职和副职、一把手和班子成员

- 每一级都分**正职**和**副职**。正职是「一把手」或「主要负责人」，副职分管一块。
- 党政机关里，**党委书记是一把手**，同级行政首长（县长、市长）排第二。
- 副职能不能扶正，要看有没有正职位子空出来，常常卡很多年。

⭐ **跟断命有关的一点**：资料里专门有「正职还是副职」的判法（见二·4），还有「**当了二十年县长，一直是副职**」这种案例（【题284】）——现实里这种人很多。

### 1.5 部门：管什么的官

| 系统 | 包括 | 特点 |
|---|---|---|
| **党委** | 党委本身、组织部、宣传部、统战部、政法委、办公室等 | **组织部管干部的任免**——管当官的人 |
| **政府** | 发改、财政、教育、卫健、国土、住建、交通、税务等 | 管具体事务，财政、国土、发改这类管钱管地的部门实权大 |
| **政法** | 政法委、公安、检察院、法院、司法局 | **执法、司法**，管人身自由与案件 |
| **纪检监察** | 纪委、监委 | **管当官的人犯不犯错**，可以对公职人员留置 |
| **人大、政协** | 各级人大常委会、政协 | 地位高、实权相对小 |
| **军队、武警** | 军、师、团、营、连 | 有自己的职务等级和军衔 |
| **国企、金融** | 国有企业、国有银行 | 有级别对照，管钱管业务 |

**军队**有自己的职务等级（军、师、旅、团、营、连各分正副），军衔（少将、大校、上校……）又是另一套。和地方级别怎么对应，说法不一，**断盘时以本人讲的职务为准**，不要硬换算成地方级别。

### 1.6 怎么上去

1. **进门**：考公（国考、省考）、军转、选调生，或者从事业单位、国企调入。
2. **任职年限**：提拔有最低年限，例如由副职提任正职，一般要在副职岗位干满两年；由下级正职提任上级副职，一般要在下级正职岗位干满三年；提任县处级领导职务，一般要有五年以上工龄。
3. **提拔程序**：动议 → 民主推荐 → 考察 → 讨论决定 → **任前公示** → 任职。
4. **常见的上升路径**：在本单位逐级提拔；下派基层挂职、任职再回来；交流到别的地方或部门（平调换岗，常常是提拔的前一步）。

⭐ **跟断命有关的一点**：现实里「升」和「调」常常连在一起——六壬资料里专门讲**内调还是外调**、**几年几月迁**（见三·4），断升迁时要把「位置变动」一起断。

### 1.7 怎么下来

| 方式 | 是什么 |
|---|---|
| **到龄退休** | 一般 60 岁退休，部分可延至 63–65 岁 |
| **改任职级、退居二线** | 不再担任领导职务，保留待遇 |
| **免职、调整** | 工作需要或不适宜担任现职 |
| **处分** | 政务处分六种：**警告、记过、记大过、降级、撤职、开除** |
| **留置** | 监察机关对涉嫌职务违法犯罪的公职人员采取的措施 |
| **「双开」** | 开除党籍、开除公职，常伴随移送司法 |

⭐ **跟断命有关的一点**：资料里「官运好却出牢狱」「升村书记儿子却住牢」这类案例不少（【题288】【题743】），**官和灾常常同一组字**——断官运时要同时看会不会出事。

## 二、八字怎么对上（出自资料，逐条带出处）

> 教材第 13 章把三套资料——**大任官运篇五条**、**v课官运九条**、**2012 面授官运五条**——合成了一张表，**三套高度一致**。下面按「够不够得上 → 几级 → 实还是虚 → 正还是副 → 什么部门 → 会不会出事」排，每一步左边是现实情况，右边是资料原话。

### 2.1 够不够得上「官」

| 现实情况 | 盘上看什么 | 出处 |
|---|---|---|
| 是不是吃「官饭」的人 | **命中要有官杀或印**：「官命的核心必须有官、杀及印星。官杀表职务，印表权」 | 大任 · 官运篇 p3 ①；面授 p57 ① |
| 是真有职务，还是只有名气 | ⭐ **必须通根**：「官命的官杀及印星不管如何做功，都必须有根。官杀虚透表示名气」 | 官运篇 p3 ②；面授 p57 ②「不通根仅有虚名」 |
| 只是普通公务员 | 「**公务员不叫官，副科级起才算**」 | v课 ·【题518】 |
| 看着像官、其实不是 | ⚠️ 三种不算官：**官虚透不为官**｜**带象被冲开不为官**（【题675】）｜**金没有透就不是官命**（【题678】） | 面授三例 |

### 2.2 当到几级

这是最想知道的一步。资料给了四个判据，**一起看**：

| 判据 | 资料原话 | 出处 |
|---|---|---|
| ⭐⭐ **做了几次功** | 「**一次功是科级，二次功是处级，三次级是厅级**」。数法：**有几个字通过各自的手段（冲、绝、合、穿）与那个被制的字发生了关联**。该例「一个午二个巳，午子冲、巳子绝」＝三次功 ⇒ 厅级 | 面授 p59 ·【题682】地委书记 |
| ⭐⭐ **制到哪一层** | 「**制官与制官的元神或者墓库为大官**」；「制官和官的原神为大官」「制官杀库为大官」 | v课第 825 讲；面授 p57 ③④ |
| ⭐ **制的是不是库** | 被制方是癸亥不是库 ⇒ **派出所所长**；被制方是库、又落在月上 ⇒ **厅级**（「他能够制一库人，当然就官大了」） | 【题687】【题688】 |
| ⭐ **落在哪一柱** | 「**年月为大，日时为小**」；「官的大小还需要结合宫位」 | 面授 p57 ⑤；v课 |
| **做功效率** | 申寅冲制印（效率高）⇒ 元朝丞相；午克酉制印（力小）⇒ 开出租车糊口 | 教材第 13 章七 |

**把常识和资料并排**：

| 现实级别 | 资料里的对应 | 案例 |
|---|---|---|
| 村干部（无级别） | 资料未给定量判据；案例多是「**制不干净**」「官虚透」一类 | 【题64】【题288】【题289】【题291】 |
| 科员（只是公务员） | 「公务员不叫官」 | 【题392】国考进司法局（科员） |
| **科级** | **一次功** | 【题57】金多入库＝科长；【题4】企业里当小官（科长） |
| **处级** | **二次功** | 【题788】省政府处长；【题563】【题564】正处级 |
| **厅级** | **三次功**；**制库**、库在月上 | 【题682】地委书记；【题688】厅级；【题349】市长厅级 |
| **部级及以上** | ⚠️ **资料未讲**「几次功是部级」。案例里有「印制食伤制得干净 ⇒ 中央银行行长、财政部长」，靠的是**制得干净＋效率高**，不是数次数 | 【题352】【题361】 |

⚠️ **资料没讲到的格子**（留着下次问老师）：
- 四次功、五次功是不是副部、正部？
- 「做功次数」和「制到哪一层（本身／原神／库）」两条怎么叠加？比如「一次功但制的是库」算几级？
- 副职的级别怎么数？「副处」是二次功打折，还是另有算法？

### 2.3 实职还是虚职

| 现实情况 | 盘上看什么 | 出处 |
|---|---|---|
| **实权**（领导职务、管人管事） | 「**官印通根可以表示实权**」 | v课第 825 讲 |
| **虚职**（只有名、待遇，没实权；如只挂职级、荣誉职务） | 「**虚透为虚职**」；「官杀虚透表示名气」；「不通根仅有虚名」 | v课；官运篇 ②；面授 ② |
| 官印虚透、但制的是地支 | 「**官印虚透但制的是地支的东西＝仍是实权**」 | v课 ·【题515】 |
| 官不是自己的 | 「**只有和主位关联的官才算数**」 | 【题286】财政局长 |

### 2.4 正职还是副职

资料给了**三个互不相同的维度**，要一起看：

| 维度 | 规则 | 出处 |
|---|---|---|
| **十神** | 「**正官是正职，偏官为副职**」 | v课第 825 讲 |
| **柱位** | 「年月为大，日时为小」 | 面授 ⑤ |
| **主宾** | **中神在主位＝正职，在宾位＝副职** | 教材第 9 章、第 13 章七 |
| ⚠️ **被穿偏** | **寅巳穿把寅穿偏了＝副职**；辰卯穿＝**副职终身不正** | 面授命例 ·【题41】【题284】【题685】 |

⭐ **对照现实**：【题284】「当了二十年县长，一直是副职」——现实里就是副县长干到退，盘上是被穿偏。

### 2.6 稳不稳、会不会出事

| 现实情况 | 盘上看什么 | 出处 |
|---|---|---|
| **稳坐江山** | ⭐ **双印护身**：两个通根的印护着日主，官来找麻烦印就化掉 | v课 ·【题516】 |

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是「这次能不能升」「什么时候调」，不是一辈子当多大的官。所以六壬这边没有「几次功几级」，看的是**这一次**的前景、升迁、进退、文武、应期。

### 3.1 主线：日辰虚实

> 「**欲问前程有与无，日辰虚实定荣枯。临官帝旺干支遇，爵禄峥嵘任帝都。**」
> 注：看事业、官运**以日干支为核心**，日干支上临**日禄、帝旺**，或日干支及其上神**得时令**，都象征事业发达。**日为身，辰为任**，**最忌落空乘空**，干支俱忌刑冲破害。〔第 21 课二·1〕

**对照现实**：日＝这个人，辰＝他的**职位**。日辰旺＝人和位子都稳；辰落空＝位子不实（虚职、挂名、悬而未决）。

### 3.2 升迁的标志：引从

> 「如遇**初传居干前为引，末传居干后为从**，直此**必升迁官职**。」〔第 21 课二·2；毕法赋第 1 法「前后引从升迁吉」〕

| 格 | 怎么成 | 主 |
|---|---|---|
| 前后引从 | 初传在日干前、末传在日干后 | 升迁 |
| 拱贵引从天干格 | 初末引从日干，且拱住贵人 | 升迁官职 |
| 两贵引从天干格 | 初传昼贵、末传夜贵引从 | **上司提拔或两处贵人引荐** |

**对照现实**：1.6 讲的「民主推荐、考察」需要有人推、有人保——「两贵引从」就是两处有人说话。

### 3.3 三传进退

> 「**三传退间蛇倒拔，三传引进龙飞天。将逢内战官超转，德禄天门名显传。**」〔第 21 课二·3〕

三传进＝往上走，三传退＝往下走或原地。

### 3.4 文职武职、内调外调、应期

> 「占**文职以青龙为类神**……**青龙生日为内部调动，日生青龙为外调**……**离日干几位是几年迁，离日支几辰是几月迁升**。」〔第 21 课二·4–5〕

| 现实 | 六壬看什么 |
|---|---|
| 文职（行政、党务、文教） | **青龙** |
| 武职（公安、军队、执法） | **太常** |
| 本单位内部提拔、调整 | 龙常**生日、比日、克日** ⇒ 内调 |
| 交流到别的地方、部门 | 日**生、克**龙常 ⇒ 外调 |
| 几年、几月 | 龙常离日干几位＝几年；离日支几辰＝几月 |

⚠️ **资料未讲**：六壬怎么断**级别**（科、处、厅）——第 21 课没有给。

## 五、断之前先问清

老师说「算不了认知以外的命」，反过来就是：**先把现实情况问清，才知道盘上该看哪个字、该说到哪一级**。

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **在什么单位**：机关、事业单位、国企、军队、村里？ | 1.1：身份不同，「官」的含义不同 | 把国企中层断成「处级干部」，把村书记断成「科级」 |
| **现在什么级别**？ | 断的是「还能升几级」，起点不同结论不同 | 已经是正处的人，你断「能到处级」等于没说 |
| **哪个系统**：党委、政府、政法、纪检、军队？ | 2.5：部门组合要对上 | 盘上群阳制阴，人在教育局，就要换个读法 |
| **问的是哪件事**：能不能升？什么时候升？会不会出事？ | 八字定上限，六壬断这一次 | 用八字回答「这次能不能提」，用六壬回答「一辈子多大官」，两头都不准 |
| **年龄**？ | 1.6、1.7：提拔有年限，60 岁退休 | 55 岁的副处断「还能到厅级」，现实里基本没有通道 |
| **是正职还是副职**？ | 2.4 | 断出「副职终身不正」，人家现在已经是正职 |

## 六、读完这一篇，你能断什么

1. 一个人**能不能吃官饭**、是实职还是虚名。
2. 大致**几级**：村、科、处、厅；部级以上看「制得干净、效率高」。
3. **正职还是副职**，会不会一辈子副职。
4. **什么系统**：法律、公安、军队、纪检、文职、金融。
5. **稳不稳、会不会出事**，升官会不会连带家里吃亏。
6. 用六壬断**这一次**能不能升、内调还是外调、几年几月。

**还断不了的**（资料未讲，下次听课可以问）：四次功以上的级别；做功次数和制库怎么叠加；副职级别怎么数；组织部、人大政协、管钱管地部门的专门组合；六壬怎么断级别。
