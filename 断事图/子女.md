# 断事图 · 子女：有没有、几个、男女、能不能生、孩子怎么样

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「没有孩子」在现实里可能是不孕、可能是不想生、可能是生了没养住、也可能是抱养来的；「生不出」可能是男方的问题也可能是女方的问题，还可能靠试管生了。盘上看出「子女宫太燥」，你得知道这对应的是**生育困难**，而不是「命里没孩子」——资料里专门说「**不生育一般是宫坏了，不是星坏了**」。
>
> **这一篇分五部分**：
> **一、常识**：怀孕生育、不孕、收养、孩子成长的常见情况（这部分是常识，不是命理规则）
> **二、八字怎么对上**：子女宫与子女星 → 能不能生 → 几个、男女、先后 → 抱养 → 生产与健康 → 孩子好不好、在不在身边（全部出自资料，逐条带出处）
> **三、六壬怎么看**：占这一胎（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的医学和法律常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。

## 一、常识：孩子这件事

### 1.1 怀孕与生育

| 事项 | 要点 |
|---|---|
| **怀孕** | 自然怀孕；或借助医学：人工授精、**试管婴儿**（辅助生殖） |
| **孕期** | 约 40 周，分早、中、晚期；早期流产风险较高 |
| **生产方式** | **顺产**（自然分娩）或**剖腹产**（手术） |
| **双胞胎、多胞胎** | 自然概率不高，试管更常见 |
| **流产** | 自然流产、人工流产；还有**宫外孕**（要手术） |
| **男女** | 生男生女大致各半；⚠️ **非医学需要的胎儿性别鉴定在中国是违法的** |
| **生育政策** | 2021 年起放开到三孩 |

### 1.2 生不出孩子的常见原因

| 方面 | 常见原因 |
|---|---|
| **女方** | 排卵问题、输卵管不通、子宫问题（肌瘤、内膜）、卵巢问题、年龄大 |
| **男方** | 精子数量或活力不足等 |
| **双方** | 原因不明、反复流产 |
| **主观** | 不想生、丁克 |

⭐ 不孕不育**男女都可能是原因**，大致各占一部分——断「不生」时别默认是女方的问题。

### 1.3 收养、抱养、过继

| 方式 | 是什么 |
|---|---|
| **依法收养** | 到民政部门办收养登记，法律上成为父母子女 |
| **民间说的「抱养」** | 从别人家抱来养；以前很多没办手续 |
| **过继** | 把孩子过给亲戚（常是兄弟）名下，传宗接代 |
| **继子女** | 再婚家庭里配偶带来的孩子 |

### 1.4 孩子长大的常见情况

| 情况 | 样子 |
|---|---|
| **成才、孝顺** | 有出息、对父母好 |
| **叛逆、不服管** | 青春期对着干、乱花钱、赌 |
| **不争气、啃老** | 长大了还靠父母 |
| **远走** | 在外地、国外工作定居，不在身边 |
| **健康问题** | 先天疾病、残疾、智力问题 |
| **早夭** | 孩子早年去世 |
| **出事** | 坐牢、意外 |

⭐ **跟断命有关的一点**：资料里这些全有——「**儿子不争气**」「**儿子不服管、四处赌借**」「**儿子远走搞技术**」「**女儿反而争气**」「**两个儿子是傻子**」「**女儿夭折**」「**儿子却住牢**」。

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一胎**——有没有怀上、保不保得住、顺不顺。

### 3.1 胎财与生气死气

> 「第十九法：**胎财生气妻怀孕**，第二十法：**胎财死气损胎推**。」〔通解中 p488｜PDF p124〕

| 组合 | 断 | 对照常识 1.1 |
|---|---|---|
| 胎神＋妻财＋**生气** | **妻怀孕** | 怀上了 |
| 胎神＋妻财＋**死气** | **损胎** | 流产风险 |

### 3.2 三位天将各管一面

| 天将 | 管什么 | 原文 |
|---|---|---|
| **六合** | **有没有** | 「六合主婚姻、喜庆……**胎产**」〔通解上 p103〕 |
| **螣蛇** | **顺不顺** | 「蛇附旺相神，更相生者，主胎产之喜……若附**血忌、带刑煞，占胎必坠**，当产即生」〔通解上 p100〕 |
| **白虎** | **险不险** | 「能损骨肉，**亦为胎孕**」〔通解上 p109〕 |

### 3.3 子孙空亡

> 「如占**子孙带空**，纵有子是**空中来**，或奸生，或过继，不然主有伤。」〔通解上 p69｜PDF p84〕

⚠️ **资料未讲**：六壬占生男生女（且非医学需要的胎儿性别鉴定本身违法，不宜断）；占孩子的学业、前途要按「学业」「出行」篇的占法。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **现在有没有孩子、几个、男女、多大**？ | 已经有的，断的是孩子的情况和缘分 | 人家两个儿子，你断「无子」 |
| **问的是哪件事**：能不能生？什么时候生？孩子将来怎么样？这一胎保不保得住？ | 八字看一生，六壬看这一胎 | 用八字回答「这一胎稳不稳」 |
| **有没有在治疗**：试管、保胎？ | 2.2：盘上的「难」和现实里的「靠医学生了」可以同时成立 | 断「生不出」，人家试管成功了 |

## 六、读完这一篇，你能断什么

1. **看哪里**：子女宫（日支、时柱）；子女星（男官杀、女食伤，时柱食伤男女都看）。
2. **能不能生**：宫太燥太寒不育——不生育一般是宫坏不是星坏；食伤入墓。
3. **男女**：看同柱天干；食神伤官；**穿会翻转男女**。
4. **几个、先后**：取天干数；时柱的是老大；谁到大运先生谁。
5. **抱养**：子星根气通年上、与祖上穿、宫燥；合住别人的字抱得到，破了连念头都没有。
6. **生产与健康**：子卯破清破＝剖腹产；三刑坏子女宫＝孩子不健康。
7. **孩子怎么样**：时柱吉神出众孝顺，时柱为忌不孝；被制的字被生起来＝不争气。
8. 六壬看**这一胎**：胎财生气怀孕、死气损胎；六合有没有、螣蛇顺不顺、白虎险不险；子孙空亡。

**还断不了的**（资料未讲）：试管能不能成；男方女方原因怎么在一张盘上分开；双胞胎；六壬占孩子前途。
