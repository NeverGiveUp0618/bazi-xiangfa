# 断事图 · 流年运势：「我今年怎么样」——这一年、这一步运、这个月

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「今年运气怎么样」是来问最多的一句，但它太空：现实里「运气」落下来，就是**工作动没动、钱进没进、身体好不好、家里有没有事、感情有没有变**。不先把「运气」拆成这几件实事，盘上看出「冲」，你只能说「今年有变动」，说不出变的是哪一件。
>
> **这一篇和别篇的分工**：别的篇讲一件事**会不会发生**；这一篇讲**时间**：这一年、这一步运、这个月，**哪件事被引动**。它和「人生年龄」篇配着用——那一篇管「这个年龄做这件事正不正常」，这一篇管「这一年轮到哪件事」。
>
> **这一篇分五部分**：
> **一、常识**：「运气」落到现实是哪几件事、一年怎么算、民间说法（这部分是常识，不是命理规则）
> **二、八字怎么看**：三层结构 → 大运 → 流年的三类应期 → 四字诀 → 虚实与「到运就失去」→ 几条硬规则（出自资料，逐条带出处）
> **三、六壬怎么看**：占这一年、这个月、这一辈子（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是常识；第二、三部分只用老师资料，逐条带出处；资料没讲的写明。

## 一、常识：「运气」是什么

### 1.1 「今年运气」落到现实是哪几件事

| 方面 | 好的样子 | 不好的样子 |
|---|---|---|
| **工作** | 升职、调到好岗位、找到工作 | 被裁、调岗、闲置、换工作 |
| **钱** | 涨薪、生意好、有外快 | 亏损、被骗、大额支出 |
| **身体** | 平安 | 生病、手术、意外 |
| **家庭** | 添丁、孩子考上 | 老人生病去世、家里吵 |
| **感情** | 结婚、恋爱 | 分手、离婚 |
| **是非** | 顺 | 口舌、官司、小人 |
| **住处** | 买房、搬好地方 | 搬迁、拆迁 |

⭐ **跟断命有关的一点**：资料的规矩是「**定住所问之事**……**分析要专一**」〔第16章第0步〕——问「今年怎么样」，要把这几件**一件一件过**，不能笼统说「好」「不好」。

### 1.2 一年怎么算

| 口径 | 从哪天开始 |
|---|---|
| 公历年 | 1 月 1 日 |
| 农历年 | 正月初一（春节） |
| **命理的年** | **立春**（一般在公历 2 月 4 日前后） |
| 命理的月 | **节气**（立春、惊蛰、清明……），不是初一 |

⚠️ **腊月里常常已经过了立春**——客人说「去年腊月」的事，在命理里可能已经是「今年」。

### 1.3 民间的几种说法

| 说法 | 是什么 |
|---|---|
| **本命年** | 流年地支与自己属相相同（如属蛇的人逢巳年） |
| **犯太岁** | 流年与属相冲、刑、害等（各派口径不一） |
| **交运、换运** | 十年一步大运交接 |
| **转运** | 坏运走完、好运开始 |

⭐ **跟断命有关的一点**：资料里的「犯太岁」只取一种——「**年支（属相）与流年地支相冲**——如乙巳年，属猪（亥）的巳亥冲 ⇒ 冲太岁」〔小任 · 初中级第14课〕。别把民间各种「犯太岁」都搬进来。

### 1.4 运是大势，年是落点

- **十年一步运**：这十年的大方向（上升期、平台期、低谷期）
- **一年一个流年**：大方向里具体哪一年出事
- **一个月**：再细到月

## 二、八字怎么看（出自资料）

### 2.1 三层结构（先看原局）

> 「一般来讲，**原局定层次，大运定吉凶，流年定应期**。」〔初级班 p51〕
> 「**只有先从原命局中分析出某件人生大事是必然发生的，然后才可能断出在某运某年中发生此事。**」〔初级班 p51〕
> 「**命中没有的事，大运来了也不算！**」〔2012面授 p55〕

⭐ **所以「今年怎么样」的第一步不是看今年**，是看**原局里有哪几件事**（1.1 那张表），再看今年轮到哪一件。

### 2.2 大运：这十年

> 「大运是命局的延伸，也可称之为**命局的第五柱**……大运还可以**改变原命局的吉凶状况**。」〔十八道法门 p55〕

| 情形 | 断法 |
|---|---|
| ① 原局的**事**到大运体现 | 此运要**应这件事** |
| ② 原局的**字**到大运出现 | 应与这个字有关的事 |
| ③ 原局**没有的字**在大运出现 | 看它让原局组合**变成了什么** |

〔十八道法门 p55〕

| 规则 | 出处 |
|---|---|
| ⭐ **判运吉凶的一句话**：「原局要做的那件事，这步运是**帮它做完**，还是**把它做反了**」 | 中级班 p2、p6（第12章六·B） |
| 制的结构，**喜大运把要制的字虚透送来**——虚的好制，补上原局的缺口 | 中级班 p6 |
| **大运天干管前 5 年，地支管后 5 年** | v课 775 讲【题475】 |
| ⭐ **进气退气**：前一运后三年有下一运的气进，下一运前三年前一运的气在退；**换运精确到月** | v课 804 讲【题498】 |
| **大运定结局、流年只是过程** | v课 783 讲【题485】 |
| ⭐ 「**谁到大运就说谁**」 | 应期总提纲 · v课 722 讲 |

### 2.3 流年：这一年

| 规则 | 出处 |
|---|---|
| 「**一般以流年为准，大运是粗线条**」；会出现「**流年应期提前**」 | 例题解 p25 |
| 流年与原局作用，一般表示「**动**」；大运与原局作用，原局的字**易受伤** | 初级班 p52 |
| 流年与命**天地合绊** ⇒ 此字被绊住，不发挥作用 | 同上 |
| ⭐ **流年出来的字控制得住，大运出来的字不受控制** | v课 787 讲【题488】 |
| ⭐ **断年一律按交节**（对照常识 1.2） | 例题解 p46 |

### 2.4 流年应期的三类

| 类 | 原话 | 出处 |
|---|---|---|
| **① 字到即应** | 「八字中某字在流年（大运）中出现**或见其禄神与原身**，则此年（运）要发生与该字有关的事情」；**作用照搬原局** | 中级班 p37 |
| **② 藏干透出即应** | 「地支中某字遁藏，在大运或流年的**天干出现**，也是地支此字的应期」——原局有戌，运年出现丁，丁就代表戌 | 中级班 p38 |
| **③ 运年与原局作用即应** | 「流年或大运与八字产生**冲、合、刑、穿、墓**，都是一种应期……作用到哪个字，哪个字在此运此年就会发生应事」 | 中级班 p38-39 |

### 2.5 ⭐ 四字诀（对照常识 1.1 的「好」「不好」）

| 作用 | 主什么 | 落到现实 |
|---|---|---|
| **合** | 主**到** | 来了：结婚、得财、得职位 |
| **冲** | 主**动** | 动了：搬家、换工作、出行、也可能吵架 |
| **墓** | 主**收** | 收了：存起来、关起来、也可能是走了 |
| **穿** | 主**伤** | 伤了：手术、破财、关系破裂 |

〔中级班 p38-39〕

**反向规则**：原局**有合** ⇒ 以**冲**为应；原局**有冲** ⇒ 以**合**为应；流年合大运＝合动；流年冲大运：**当运为冲去，不当运为冲起**〔中级班 p38-39〕。

### 2.6 虚实与「到运就失去」

| 规则 | 出处 |
|---|---|
| ⭐ **虚怕实，实怕虚**；**天干（虚透）通禄入地府**——一个虚透之干，运年把它的禄、根送来那年出事 | v课 746 讲【题435】 |
| ⭐ **命中干支到大运，表人表物要失去**——不是加倍好，是**脱离** | v课 721 讲【题411】 |
| ⭐ **地支实的东西到了天干＝没有了、上天了** | v课 769、780 讲 |
| ⭐ **原局没有、运带来的字＝过路的、外面来的** | v课 834、849 讲 |
| ⭐ **冲你＝送来，被别人合走＝失去** | v课 834 讲 |
| ⭐ **原局里被作用的字是「别人」，运年来的同一个字就是「命主自己」** | v课 851 讲【题509】 |
| ⭐ 「**受伤状态的字，出现之时就是受伤的应期**」 | 初级班 p20 |

### 2.7 定到月、定到日

| 规则 | 出处 |
|---|---|
| **定月份**：从「哪个字动」倒推 | v课 781 讲【题483】 |
| **定到日**：地支找三刑之字、天干找合虚干之字 | v课 837 讲【题520】 |
| 「**应期一环套一环**：运来合克 ⇒ 流年找被合的年 ⇒ 月再找合」 | v课 807 讲【题500】 |
| 「防午未月」 | 【题169】 |

### 2.8 定应期五步（教材原样）

```
第1步 先从原局确认：这件事是不是必然要发生的？
第2步 锁定代表这件事的那一个字
第3步 看这个字在原局是什么状态（被制？做功？入墓？受伤？）
第4步 找大运：①原局的事到运了 ②原局的字到运了 ③运带来新字改变组合
第5步 找流年：字到／藏干透干／冲合刑穿墓；以流年为准；年份按交节
```
〔第12章八〕

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬一课占一件事，也可以占「**这一年**」「**这个月**」，甚至用生辰起课断「**一辈子**」。

| 课例 | 占什么 | 怎么看 |
|---|---|---|
| ⭐ 例183 | **这一年的流年**（43 岁人） | 「⭐ **干支两仪定体：人宅／动静／男女／内外**」「**哪边旺就往哪边走**」——干旺支衰 ⇒ **宜出外、不利家居**；三刑刑到日干本体＋哪几位空＝凶应在谁 |
| ⭐ 例184 | **这个月的运气** | 「⭐ **判来意看正时之支与初传，重象必验**」——本月因长辈旧债起口舌、破点财；「**断凶要留出『能不能忍』的余地**」 |
| ⭐ 例186 | **用出生年月日时起课断一辈子** | 「⭐ **终身可用生辰演课**」；旬仪在初传＝早年安乐；空亡的贵人要等**填实或冲实**之年 |
| 例182 | 替家人占终身 | 干上神＝一生所处的场所，其阴神＝所仰仗的人；**替人占可能应在占者身上** |
| 例185 | 问寿数还是功名 | 同盘两问答案相反——**先问清所占何事** |
| 例187 | 断他中在哪一科 | **行年从本旬在地盘的位置起一岁顺数**；行年上的字与天将决定哪一年应 |

⭐ **对照常识 1.1**：例183「本人在外清吉，家中妻子儿女却大凶」——同一年，**人和宅分开看**，好坏可以完全相反。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **最关心哪一件**：工作、钱、身体、家里、感情？ | 1.1：「运气」要拆开看 | 笼统说「今年不错」 |
| **今年到现在发生了什么** | 用已发生的对原局读法 | 断的事已经过去了还在说 |
| **事情发生在哪个月** | 1.2：腊月、正月要查立春 | 年份差一年 |
| **现在走哪步运、换运没有** | 2.2：进气退气 | 用错了大运 |
| **问自己还是问家人** | 例183：人宅分开 | 家里的事断到自己身上 |

## 六、读完这一篇，你能断什么

1. 「今年怎么样」先拆成**工作、钱、身体、家庭、感情、是非、住处**七件。
2. **原局定有没有，大运定吉凶，流年定哪一年**；以流年为准，年按交节。
3. 流年三类：**字到、藏干透出、冲合刑穿墓**；四字诀**合到、冲动、墓收、穿伤**。
4. **命中干支到大运＝失去**；运带来的字＝过路的；虚透之干逢禄根之年出事。
5. 六壬：占一年看**干支两仪、哪边旺往哪边走**；占一月看**正时与初传**；可用生辰起课断终身。

**还断不了的**（资料未讲）：本命年本身的吉凶（资料只讲冲太岁）；「当运／不当运」怎么算（教材列存疑）；没有原局大事的平常年份怎么说。
