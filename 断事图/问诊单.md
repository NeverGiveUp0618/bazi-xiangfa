# 断事图 · 问诊单：见客人之前要问清的事（各篇汇总）

> 这一页由各篇末尾的「**断之前先问清**」自动汇总而成，内容以各篇为准。
> **用法**：先按「来意」篇判断他为什么来，再翻到这里对应的一节，把表里的问题过一遍。

## 通用（每一盘都问）

| 先问 | 为什么 |
|---|---|
| **出生时间准不准、在哪出生** | 交节、子时、换气要排两个盘；「大山里应蛇咬，城市里应车祸」 |
| **问自己还是替人问** | 盘是被问的人的，来意是来问的人的（「来意」篇） |
| **多大年纪、在哪个城市** | 年龄尺、地域尺（「人生年龄」「层次」篇） |
| **现在的大概情况** | 「八字即生活：断出来跟生活不符就是错了」〔小任 · 初中级第7课〕 |

## 流年

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **最关心哪一件**：工作、钱、身体、家里、感情？ | 1.1：「运气」要拆开看 | 笼统说「今年不错」 |
| **今年到现在发生了什么** | 用已发生的对原局读法 | 断的事已经过去了还在说 |
| **事情发生在哪个月** | 1.2：腊月、正月要查立春 | 年份差一年 |
| **现在走哪步运、换运没有** | 2.2：进气退气 | 用错了大运 |
| **问自己还是问家人** | 例183：人宅分开 | 家里的事断到自己身上 |

## 性格

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁的性格**：本人、配偶、孩子、合作对象？ | 太极点不同 | 把孩子的盘断成父母的脾气 |
| **问性格是为了什么**：择偶、用人、教育孩子、自我了解？ | 同一个特点，放在不同的事里好坏不同 | 「多疑」在审计是优点，在婚姻是问题 |
| **先说一两条让对方确认** | 老师：先点两件事校准 | 一上来说一长串，没法验证 |
| **人前人后有没有差别**？ | 2.1：天干表象、地支内在 | 只说外表，说不中内心 |

⚠️ **说话的分寸**：性格的负面（自私、说谎、人品不好）要换成提示式说法；而且性格会随经历变化，**说倾向，不下定论**。

## 官职

老师说「算不了认知以外的命」，反过来就是：**先把现实情况问清，才知道盘上该看哪个字、该说到哪一级**。

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **在什么单位**：机关、事业单位、国企、军队、村里？ | 1.1：身份不同，「官」的含义不同 | 把国企中层断成「处级干部」，把村书记断成「科级」 |
| **现在什么级别**？ | 断的是「还能升几级」，起点不同结论不同 | 已经是正处的人，你断「能到处级」等于没说 |
| **哪个系统**：党委、政府、政法、纪检、军队？ | 2.5：部门组合要对上 | 盘上群阳制阴，人在教育局，就要换个读法 |
| **问的是哪件事**：能不能升？什么时候升？会不会出事？ | 八字定上限，六壬断这一次 | 用八字回答「这次能不能提」，用六壬回答「一辈子多大官」，两头都不准 |
| **年龄**？ | 1.6、1.7：提拔有年限，60 岁退休 | 55 岁的副处断「还能到厅级」，现实里基本没有通道 |
| **是正职还是副职**？ | 2.4 | 断出「副职终身不正」，人家现在已经是正职 |

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **现在做什么、做过什么** | 定职业最难，先拿已知的校准（老师：先点两件事校准） | 一上来就断行业，断错了后面全不信 |

## 财运

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **做什么工作、拿工资还是自己做** | 2.3：工薪和经营盘上不同 | 给打工的人断「发大财」 |

## 婚姻

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁**：本人、子女、父母？ | 太极点不同，看的宫星不同 | 把女儿的婚姻断到母亲身上 |
| **现在什么状态**：单身、恋爱、已婚、分居、离异、丧偶、再婚？ | 1.3：状态不同，问题的重点不同 | 人家已经离了两次，你还在断「早婚」 |

## 子女

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **现在有没有孩子、几个、男女、多大**？ | 已经有的，断的是孩子的情况和缘分 | 人家两个儿子，你断「无子」 |
| **问的是哪件事**：能不能生？什么时候生？孩子将来怎么样？这一胎保不保得住？ | 八字看一生，六壬看这一胎 | 用八字回答「这一胎稳不稳」 |
| **有没有在治疗**：试管、保胎？ | 2.2：盘上的「难」和现实里的「靠医学生了」可以同时成立 | 断「生不出」，人家试管成功了 |
| **是亲生、抱养还是继子女**？ | 2.4：抱养在盘上另有样子 | 把继子女按亲生断 |
| **问的是谁的盘**：本人、配偶？ | 2.2：配偶不育看配偶星坐绝地；最好两人盘都看 | 只看一方就断「谁的问题」 |
| **年龄** | 1.2：年龄大本身就影响生育 | 对 45 岁的人断「还能生好几个」 |

⚠️ **断子女时别说重话**：老师的规矩是「重话换成提示式说法」；涉及孩子早夭、残疾，更要至少两个点、说得留余地。

## 疾病

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁**：本人还是家人？ | 太极点不同，看的字不同（断命台「摆正立场」） | 把父亲的病断到本人身上 |
| **现在有没有病、什么病、医院怎么说**？ | 已经确诊的，断的是**走向**（会不会好、要不要手术、哪年要小心） | 人家已经确诊肝癌，你还在说「肝不太好」 |
| **急还是慢**：突然发作还是多年老病？ | 2.3：急慢看作用方式，问清了好对盘 | 把慢性病断成「这两年会突然出事」吓人 |
| **年龄** | 「老怕帝旺，少怕衰」；60 岁前不谈寿数 | 对年轻人谈寿元 |
| **在哪里生活**：城市还是山区？开不开车？ | 「大山里应蛇咬，城市里应车祸」 | 车象断成车祸，人家根本不开车也不坐车 |
| **做什么工作** | 同样的象，可能是职业不是病（修车、医生、护士） | 【题668】子卯破＝手术，人家就是外科医生 |

## 意外

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **多大年纪** | 1.2：各年龄段风险不同 | 给小孩断开车撞人 |

## 官司

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **民事还是刑事**？ | 1.1：一个看输赢，一个看坐不坐牢 | 讨债官司断成「有牢狱」，把人吓坏 |

## 父母

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **父母现在都在吗、身体怎样**？ | 已发生的先拿来校准 | 父亲已过世，你还在断「父亲 36 岁有坎」 |
| **从小跟谁长大**：父母、爷爷奶奶、养父母、继父母？ | 1.1：「与父无缘」有好几种落法 | 断成「早年丧父」，其实是父母离婚 |
| **问的是什么**：缘分？父母身体？自己出身？ | 太极点要放对 | 问父母身体，却在看命主自己的病 |
| **有没有兄弟姐妹、是不是同父同母**？ | 2.5：血缘不清的兄妹、两姓 | 漏掉重组家庭的线索 |
| **父母的生辰有没有**？ | 父母自己的事，最好看父母自己的盘 | 只凭子女盘断父母寿数，太重 |

⚠️ **说话的分寸**：父母寿数、父母离婚这类事，老师的规矩是**至少两个点才说、重话换成提示**；而且「**六亲分析都是缘分关系，不代表命主命运好坏**」——别让来问的人因此觉得自己命不好。
