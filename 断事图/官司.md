# 断事图 · 官司：打不打得赢、会不会坐牢、判多久

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「官司」在现实里差别极大：讨一笔欠款的民事官司，和偷盗、诈骗、杀人的刑事案，完全不是一回事；「被抓」「判刑」「坐牢」「缓刑」「减刑」也是不同的环节。盘上看出「食伤入墓」，你得知道是**进了看守所**、**判了实刑**，还是**只是住了院**——资料里这三种都有。
>
> **这一篇分五部分**：
> **一、常识**：民事、刑事、行政三种官司，刑事案从被抓到出狱怎么走，刑罚有哪几种（这部分是常识，不是命理规则）
> **二、八字怎么对上**：会不会犯事 → 为什么犯 → 犯事和被抓 → 关在哪 → 判多久 → 民事官司输赢 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**：占这一场官司谁输谁赢（出自《大六壬通解》）
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开的法律规定写的常识；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起方便对照——**原话为准**。

## 一、常识：官司是怎么回事

### 1.1 三种官司

| 种类 | 是什么 | 谁和谁打 | 例子 |
|---|---|---|---|
| **民事** | 平等的人之间的纠纷 | 个人、公司之间 | 欠钱不还、合同纠纷、离婚、继承、房产、劳动争议、交通事故赔偿 |
| **刑事** | 国家追究犯罪 | 检察院代表国家起诉被告人 | 盗窃、诈骗、抢劫、伤害、杀人、贪污受贿、非法集资、交通肇事 |
| **行政** | 告政府 | 个人、公司告行政机关 | 不服罚款、拆迁、吊销执照 |

⭐ **跟断命有关的一点**：资料里的官司多数是**刑事**（牢狱），也有**民事**（讨债官司、财产官司）。先分清是哪一种，才知道该看「输赢」还是看「坐不坐牢」。

### 1.2 民事官司怎么走

```
  起诉 → 法院立案 → （调解）→ 开庭 → 一审判决
          → 不服可上诉 → 二审判决（二审终审）→ 申请强制执行
```

- **赢了不等于拿到钱**：对方没钱或转移财产，判了也执行不到。
- 很多纠纷在**调解**阶段就和解了。

### 1.3 刑事案怎么走

```
  犯事 → 被发现、立案 → 公安侦查（刑事拘留 → 逮捕 或 取保候审）
       → 检察院审查起诉 → 法院审判 → 判决 → 执行（进监狱）
       → 服刑中可能减刑、假释 → 刑满释放
```

| 环节 | 要点 |
|---|---|
| **刑事拘留** | 人先被关进**看守所**；一般最长 30 多天，要么转逮捕，要么放人或取保 |
| **取保候审** | 交保证金或找保证人，人先放出来等审判 |
| **逮捕** | 继续关押等起诉、审判 |
| **职务犯罪** | 公职人员涉嫌贪腐，由**监察委留置**调查，再移送检察院 |
| **判决** | 有罪或无罪 |

⭐ **跟断命有关的一点**：资料专门说「**『犯事』与『被抓』是两件事**」——有人犯事多年抓不到，有人一犯就被抓。现实里也是这样：很多案子要过很久才被发现。

### 1.4 刑罚有哪几种

| 刑罚 | 是什么 |
|---|---|
| **管制** | 不关押，在社区里限制自由 |
| **拘役** | 短期关押（一个月到六个月） |
| **有期徒刑** | 六个月到十五年；几罪并罚最高可到二十年或二十五年 |
| **无期徒刑** | 关押终身（服刑表现好可以减刑） |
| **死刑** | 包括死刑立即执行、死刑缓期两年执行（死缓） |
| 附加刑 | 罚金、没收财产、剥夺政治权利 |

| 后续 | 是什么 |
|---|---|
| **缓刑** | 判了刑但暂不执行（拘役、三年以下有期徒刑才可能），考验期内不再犯就不用坐牢 |
| **减刑** | 服刑期间表现好，刑期减少 |
| **假释** | 服刑到一定程度，提前有条件放出 |

⭐ **跟断命有关的一点**：资料里的取数案例正好走了这一整条：「**判 9 年 → 减到 7 → 减到 4 → 缓刑 3 年必须花钱**」（【题511】）；还有「**无期变有期**」「**死刑**」「**住了不到一年**」——每一层在盘上都有来处。

### 1.5 常见罪名和起因

| 起因 | 常见罪名 |
|---|---|
| **为钱** | 盗窃、诈骗、抢劫、贪污、受贿、职务侵占、非法集资 |
| **冲动、打斗** | 故意伤害、聚众斗殴、故意杀人 |
| **为色** | 强奸、绑架（有时为钱） |
| **被人带坏、跟团伙** | 共同犯罪：主犯、从犯 |
| **工作中失职** | 交通肇事、重大责任事故、滥用职权 |

⭐ **跟断命有关的一点**：资料的牢灾门开篇就说「**人生私欲三把刀，色诱财腐争权中**」——**色、财、权**三条，正好对上这张表。

### 2.4 关在哪：牢房还是医院

> 「**丑是阴中之阴，最阴暗的地方，把午控制在这个地方，肯定就是牢房了；假设有辰晦火没有丑出现，辰是阳中之阴，表医院，这就是医院之灾了**。」〔面授 p87 ·【题737】〕

| 现实 | 盘上 |
|---|---|
| 看守所、监狱 | **丑**；食伤入墓**又逢官杀** |
| 医院 | **辰**；食伤入墓**没有官杀** |

### 2.5 判多久、能不能减（对照常识 1.4）

**① 轻重**：

> 「**双辰夹午为晦火，比丑午穿和午酉破要轻些**」〔面授 p87 ·【题735】〕——**晦 ＜ 穿／破**：同样是牢狱，一个死刑、一个有期（【题734】↔【题735】只差一个时辰）。

| 现实 | 盘上 | 出处 |
|---|---|---|
| **无期** | **官杀从年到时两头都是＝管你一辈子** | v课第 822 讲 ·【题506】 |
| **死刑** | 阴包阳、灭了阳就没有命了；申入丑墓又被合闭 | 【题734】【题314】【题732】 |
| 无期变有期 | 有甲木救 | 【题735】 |
| **几次坐牢** | **两个官杀＝两次牢狱**（数量对应次数） | 【题68】 |

**② 取数**（v课第 816、856–860 讲）：

> 「**事要定准，才能再说取数。水16，火27，木38，金49，土5 10。**」「**阳数大阴数小，生助大，克泄小，多数大，少数小**。」

```
① 先把事定准（确实要坐牢）
② 找关键字（因哪个字坏、入墓、合）
③ 查五行数：水1/6 火2/7 木3/8 金4/9 土5/10
④ 取大取小：阳大阴小、生助大克泄小、多数大少数小
⑤ 整柱同五行翻倍；两次合取 10
⑥ 破你的字＝减；互带象的字＝加
⑦ 用出狱年反推验证；两条路算出同一个数才敢定
```

| 案例 | 刑期 | 怎么来的 |
|---|---|---|
| 【题502】 | 6 年 | 入辰墓的水，被申生、官多取大；戌年冲辰出 |
| 【题503】 | 5 年 | 辰（土），土不重取小 |
| 【题504】 | 8–9 年 | 辛 4/9 ＋ 卯 3/8，金重取大 |
| 【题505】 | 10 年 | 辰 5，戊辰整柱 ×2；戌年出 |
| ⭐【题511】 | 9→7→4→缓刑 3 年 | 酉 9，被午破 −2；再减；甲（木 3）缓刑、要花钱 |
| 【题512】 | 11 年 | 戊 10 ＋ 癸 1 |

⚠️ **边界**：地支一般不取数、取天干；这些数字**只在事定准之后才有意义**，别拿来「算命」。

**③ 化解**：

> 「⭐ **破财免灾的原理**：财生官 ⇒ 官非来了让财去生它（花钱）⇒ 它就不克你。」〔v课第 855 讲 ·【题510】〕——该例「住了不到一年」。

**对照常识 1.4**：现实里「花钱」可以是退赃、交罚金、赔偿取得谅解——这些确实影响量刑。

### 2.6 民事官司：输还是赢（对照常识 1.2）

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一场官司**谁赢谁输、会不会有事。

### 3.1 主线：日辰分主客、官鬼断输赢

> 「**占讼日辰分主客，课传官鬼断输赢。**」
> 「**日为客，辰为主；先动为客，后动为主。**」
> 「**日上有鬼不利客，支上有鬼不利主。发用克日客输，克支主输**。」〔通解上 p242｜PDF p257〕

| 情形 | 断 |
|---|---|
| 日上有鬼 | **不利客**（先动的那方） |
| 支上有鬼 | **不利主** |
| 发用克日 | **客输** |
| 发用克支 | **主输** |

**对照常识 1.2**：**先动为客**＝原告（起诉的一方）；**后动为主**＝被告。定主客先问**谁先起诉**。

### 3.2 其余要点

> 「**子孙制鬼患有救，父母化官祸无伤**……**朱勾克日莫兴词，妄举轻为自投死。二将若也生日干，勘官昭雪人欣喜**。**虎头蛇尾祸不凶，雀入勾乡讼为最**。」〔通解上 p242｜PDF p257〕

| 见到 | 断 | 对照常识 |
|---|---|---|
| **子孙制鬼** | 患有救 | 有人帮忙、有转机 |
| 父母化官 | 祸无伤 | — |
| **朱雀、勾陈克日** | **别打这个官司**——「妄举轻为自投死」 | 劝人和解、别起诉 |
| 朱、勾**生日干** | 勘官昭雪 | 冤情得到平反 |
| **雀入勾乡** | 讼事最重 | 拖得久、闹得大 |
| 虎头蛇尾 | 祸不凶 | 雷声大雨点小 |

> 「占词讼，**最爱天空发用及终传，主讼解、谋不成**。若求财物，又深忌之。」〔通解上 p107｜PDF p122〕——天空让事情落空，占讼时＝**官司散了**（好事），占财时＝财没了（坏事）。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **民事还是刑事**？ | 1.1：一个看输赢，一个看坐不坐牢 | 讨债官司断成「有牢狱」，把人吓坏 |
| **问的是谁**：本人还是家人？ | 太极点不同 | 把儿子的官司断到父亲盘上 |
| **原告还是被告**（谁先起诉）？ | 六壬「先动为客」 | 主客颠倒，输赢全反 |
| **现在到哪一步**：还没事、已被调查、已拘留、已判、在服刑？ | 1.3：要断的点完全不同 | 人已经判了，你还在断「会不会被抓」 |
| **什么事由**：为钱、打架、职务、被连累？ | 2.2：起因不同，盘上看的字不同 | 只说「有官非」，说不出是哪一类 |
| **做什么工作** | 资料里公检法、执法的人盘上本就有「官杀、群阳制阴」 | 把警察、法官的职业象断成牢狱 |

⚠️ **断出牢狱之象时**：老师的做法是**提前预警、劝人守法**（【题312】提前一年预警），不是吓人；而且要**至少两个点**才说。

## 六、读完这一篇，你能断什么

1. **会不会犯事**：牢灾门歌诀、阴坏阳、食伤＝自由、倒象。
2. **为什么犯**：为财、为色、打架、团伙、贪污、被连累。
3. **犯事和被抓分开断**：穿＝抓不到，官来合＝官方来找。
4. **关在哪**：丑是牢房，辰是医院。
5. **判多久**：晦轻于穿破；官杀两头＝无期；取数七步。
6. **怎么化解**：破财免灾。
7. 六壬断**这一场官司**：先动为客，日上有鬼客输、支上有鬼主输；朱勾克日别起诉。

**还断不了的**（资料未讲）：民事官司在八字里的成套判法；行政官司；**取保候审、缓刑**在盘上和实刑怎么分（只有【题511】一例缓刑）；赢了官司**执行不到钱**怎么看。
