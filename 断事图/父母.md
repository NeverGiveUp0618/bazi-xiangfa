# 断事图 · 父母：出身、缘分、父母的身体与婚姻

> **为什么从常识讲起**：老师说过，**算不了认知以外的命**。「与父无缘」在现实里可能是父亲早逝、父母离婚跟了母亲、被送人抱养、父亲长年在外、父亲偏瘫卧床——资料里「财坏印」这一个组合，就有**送人、父偏瘫、父母离婚、随母改嫁**四种落法。不知道现实里有这几种家庭，盘上看出来也说不准是哪一种。
>
> **这一篇分五部分**：
> **一、常识**：家庭的几种样子、父母和孩子的几种关系（这部分是常识，不是命理规则）
> **二、八字怎么对上**：谁是父谁是母 → 宫为主 → 缘分 → 父母的身体与寿限 → 父母离婚、改嫁、继父母、抱养 → 出身与家境 → 什么时候（全部出自资料，逐条带出处）
> **三、六壬怎么看**
> **四、案例**
> **五、断之前先问清**
>
> ⚠️ **读法**：第一部分是我按公开常识写的；第二、三部分只用老师资料，**资料没讲到的写明「资料未讲」**。并排放的「对应」是我把常识和资料原话摆到一起——**原话为准**。
>
> ⭐ **老师自己划的界**：「**以上六亲分析都是缘分关系，不代表命主命运好坏**——打仗时候很多将军都是孤儿。」〔v课〕看父母，看的是这层缘分，不是给命主定好坏。

## 一、常识：家是怎么回事

### 1.1 家庭的几种样子

| 样子 | 是什么 |
|---|---|
| **双亲家庭** | 父母都在、一起生活 |
| **单亲家庭** | 父母离婚或一方去世，跟一方生活 |
| **重组家庭** | 父或母再婚，有了继父、继母，可能有同父异母、同母异父的兄弟姐妹 |
| **收养、抱养** | 不是亲生父母养大 |
| **过继** | 过给亲戚（常是伯叔）名下 |
| **隔代抚养** | 父母在外打工，由爷爷奶奶、外公外婆带（留守儿童） |
| **上门女婿** | 男方到女方家落户，孩子有时随母姓 |

### 1.2 和父母的几种关系

| 关系 | 样子 |
|---|---|
| **缘深** | 常在身边、感情好、得父母帮助 |
| **缘浅** | 不在身边、早早离家、感情淡 |
| **得父母帮** | 父母安排工作、给房给钱 |
| **父母帮不上** | 家里条件差，一切靠自己 |
| **父母成了负担** | 父母生病要照顾、欠债要还 |
| **早年失去父母** | 父或母早逝 |

### 1.3 父母那一头的事

- **父母的健康**：老了以后的慢性病、中风偏瘫、意外。
- **父母的婚姻**：离婚、再婚、一方有外遇。
- **父母的职业和家境**：决定孩子的「出身」，有的孩子接父母的班。
- **父母的寿数**：⚠️ 资料要求谨慎（见 2.4）。
- **财产继承**：父母去世后的房产、存款（另见「房产」篇 2.3）。

### 2.2 宫为主，星为辅

> 「**以宫为主**：父母宫在年月，**这是不动的**；时柱也有父母星，但要转化到父母宫看。」〔v课第 835 讲〕
> 「**宫为主、星为辅；宫星同坏六亲遭殃**。」〔十八道法门 p38〕
> 「三刑：**刑到哪宫，哪宫六亲有灾**。」〔同上〕

| 宫位 | 六亲 |
|---|---|
| 年柱 | 祖业、父母、外戚长辈 |
| 月柱 | 父母、兄弟 |

⚠️ 「**不可见时柱偏财就断为父**」——父母只在年月找〔教材第 4 章〕。

⭐ **看六亲只看宫星，不论对命主的喜忌**：同一个财坏印，看工作是好事，看六亲就是与父无缘〔v课第 843 讲 ·【题524】〕。

### 2.4 父母的身体与寿限（对照常识 1.3）

| 现实 | 盘上 | 出处 |
|---|---|---|
| ⭐ **藏着的六亲，出到运年才出事** | 「藏干/库里的六亲**不出来没事，出到运年就出事**……任何命都通用的规则」 | v课第 835 讲 |
| **寿限按宫位段** | 与父的联系在年月 ⇒ **过不了年月段（36 岁）**；与母的联系落在日支 ⇒ 到日柱段 | v课第 875 讲 ·【题538】 |
| **「患」** | 「**患父患母，必克父母**」——同五行两现＝患；**患在年柱＝早年克** | v课第 781、837 讲 |
| 有源头生的患**不论早走** | 只论身体不好 | 【题521】↔【题484】 |
| **原局已被制死的六亲反而不克** | 「死猪不怕开水烫」 | 【题484】 |
| ⚠️ **三刑全反而不做功** | 三个字都坏了，主要表示**六亲有问题** | 十八道法门 p38 |
| 母亲腿瘸 | 连走路姿势都说得出 | 【题175】 |
| 父偏瘫 | 辰伏吟 | 【题649】 |
| 父亲车祸而亡 | 午财表父，己丑年丑到穿午 | 【题325】 |
| 父亲从高处摔下、死里逃生 | 原局卯午双破 → 大运庚辰 → 流年戊子 | 【题104】；初级班 p52 |

**对照常识 1.3**：「出到运年才出事」正好对上现实——父母多数时候好好的，某一年突然病倒或出事。

⚠️ **说话的规矩**：断父母寿数要格外慎重。老师的做法是**提示**而不是直说（「重话换成提示式说法」）；寿元要「**全坏才敢断，单点别断**」。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **父母现在都在吗、身体怎样**？ | 已发生的先拿来校准 | 父亲已过世，你还在断「父亲 36 岁有坎」 |
| **从小跟谁长大**：父母、爷爷奶奶、养父母、继父母？ | 1.1：「与父无缘」有好几种落法 | 断成「早年丧父」，其实是父母离婚 |
| **问的是什么**：缘分？父母身体？自己出身？ | 太极点要放对 | 问父母身体，却在看命主自己的病 |
| **有没有兄弟姐妹、是不是同父同母**？ | 2.5：血缘不清的兄妹、两姓 | 漏掉重组家庭的线索 |
| **父母的生辰有没有**？ | 父母自己的事，最好看父母自己的盘 | 只凭子女盘断父母寿数，太重 |

⚠️ **说话的分寸**：父母寿数、父母离婚这类事，老师的规矩是**至少两个点才说、重话换成提示**；而且「**六亲分析都是缘分关系，不代表命主命运好坏**」——别让来问的人因此觉得自己命不好。

## 六、读完这一篇，你能断什么

1. **谁是父母**：财父印母；食伤看母；官杀当父；与父同柱即母；任何十神按实力都可代表。
2. **宫为主**：父母宫在年月不动；宫星同坏六亲遭殃；三刑到哪宫哪宫有灾。
3. **缘分**：财坏印四种落法；六亲口诀四句；只看宫星不论喜忌。
4. **父母身体与寿限**：藏着的出到运年才出事；寿限按宫位段；患父患母。
5. **离婚、改嫁、继父母、抱养**：伏吟、印移位、天干看姓。
6. **出身**：年月看祖业；坐财库不开家穷。
7. **应期**：被制的字一出现；墓绝同现；可精确到年。
8. 六壬：父母看生气、日本，父兼德神、母兼天后。

**还断不了的**（资料未讲）：隔代抚养（爷爷奶奶带大）怎么看；六壬里父母缘分的专门断法；「天干＋地支混着也叫患」老师已列待查。
