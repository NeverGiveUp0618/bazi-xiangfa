## 一、常识：读书这件事

### 1.1 学制

```
  幼儿园（3 年）→ 小学（6 年）→ 初中（3 年）→【中考】
     → 普通高中（3 年）→【高考】→ 专科（3 年）／本科（4 年）
                                        → 硕士（2–3 年）→ 博士（3–4 年以上）
     → 或：中职、技校（3 年）
```

- **义务教育**：小学加初中共 9 年。
- **中考**是第一道分流：大约一半去普通高中，一半去职业学校。
- **年龄对照**：小学 6–12 岁，初中 12–15 岁，高中 15–18 岁，大学 18–22 岁。

### 1.2 学历的层次

| 层次 | 常说的叫法 |
|---|---|
| 初中及以下 | 「没什么文化」「早早出来打工」 |
| 高中、中专、技校 | — |
| **专科（大专）** | 高职高专 |
| **本科** | 口语里还在说「一本、二本、三本」（按录取批次；不少省份已合并批次，但叫法还在用） |
| 重点大学 | 「985」「211」「双一流」 |
| **硕士**（研究生） | 考研 |
| **博士** | — |

### 1.3 不只一条路

| 途径 | 是什么 |
|---|---|
| **全日制** | 高考进大学，正常读完 |
| **非全日制、在职** | 一边工作一边读（在职研究生、在职本科） |
| **成人教育** | 成人高考、自学考试（自考）、函授、开放大学——**工作以后补学历**很常见 |
| **留学** | 去国外读书 |
| **职业资格** | 会计证、律师证、教师资格证——不是学历，但对工作很要紧 |
| **考公、考编** | 考公务员、事业编，对学历有门槛 |

⭐ **跟断命有关的一点**：资料里有「**56 岁的本科生**」「**穿两次就算正式了**」——现实里就是工作以后再补的在职学历；还有「**两个大本**」「**多学科于一身**」——一个人拿两个以上文凭也常见。

### 1.4 文科、理科、专业

- 高考以前分文科、理科；**新高考**改成选科（物理或历史选一，再从化学、生物、政治、地理里选两门），但「偏文」「偏理」的说法还在。
- 大学专业大类：文学、历史、哲学、法学、经济、管理、教育、理学、工学、医学、农学、艺术、军事。

### 1.5 学业出问题的常见情形

| 情形 | 样子 |
|---|---|
| **不爱学、贪玩** | 坐不住、心思不在读书上 |
| **偏科** | 文强理弱或相反 |
| **叛逆、早恋** | 青春期和家里对着干 |
| **早早辍学打工** | 家里条件差，或自己不想读 |
| **考试发挥失常** | 平时好，考场差 |
| **专业选错、读不下去** | 中途转专业或退学 |
| **学历高、出路一般** | 读得好，钱和地位不一定跟着来 |

⭐ **跟断命有关的一点**：最后一条正是老师那句「**学历仅是一个名**」——现实里也是这样，名校毕业不等于富贵。

## 二、八字怎么对上（出自资料，逐条带出处）

### 2.1 用什么字看学历

> 「**年月重看学历星，有三种：印、官杀、食伤——都可以当学历星看，也要结合十天干喜忌来看。**」〔v课第 761 讲〕
> 「**学历：食伤、印、官杀都可看学历，但命中印不宜太重，财来制印时，财也可当学历看**。」〔2012 面授 p97〕

| 学历星 | 条件 | 案例 |
|---|---|---|
| **印** | 最常用；但**印不宜太重** | 【题763】寅卯印为文凭 |
| **食伤** | — | 【题761】食伤酉当文凭；【题765】食伤得库＝聪明有文凭 |
| **官杀** | ⭐ **杀必须是为我所用时才行**（被化、被制、合到身）；「**杀表名气**」 | 【题762】杀为文凭 ⇒ 中文本科；【题760】 |
| **财** | **印太重、财来制印时** | 【题759】卯辰穿了印，卯财当文凭，两个大本 |

### 2.2 读到什么程度（对照常识 1.2）

## 三、六壬怎么看（出自《大六壬通解》）

> 六壬是**一事一课**：问的是**这一场考试**考不考得上。

### 3.1 干为考生，支为考场

> 「**占考试，干为举子，支为场屋**。」〔通解，第 14 课〕

| | 代表 |
|---|---|
| 日干 | **考生本人** |
| 日支 | **考场、考试本身**（场屋） |

⚠️ 「支上神受克，说明**考试这一头出问题**（场屋不利）——具体还要看谁克它、乘什么将。」〔第 14 课自测答案〕

### 3.2 登科与不第

> 「**登科者禄马扶会**」——禄神驿马临于干支之上，主前程远大。
> 「**不第者刑害俱骈**」——三刑六害并临干支之上，**刑主有缺，害主阻隔难成**。〔通解上 p176｜PDF p191〕

| 见到 | 断 | 对照常识 |
|---|---|---|
| 禄、驿马临干支 | **考得上** | 上榜、录取 |
| 三刑六害并临干支 | **考不上** | 刑＝有缺（发挥失常、差几分），害＝阻隔（被卡、录取不顺） |

### 3.3 求名看朱雀

> 「求官龙常及官星，**求名文书朱雀中**。」〔通解中 p482〕——考试、出名、证书，看**文书**与**朱雀**。

⚠️ **资料未讲**：六壬占考试的**分数、名次**、**录取到哪一所学校**。

## 五、断之前先问清

| 先问 | 为什么 | 不问会错在哪 |
|---|---|---|
| **问的是谁**：孩子还是本人？ | 太极点不同；孩子还小时看的是将来 | 断父母的学历断到孩子身上 |
| **现在多大、读到哪一步**？ | 2.7：年柱管中小学，月柱管大学以后 | 对已工作的人断「能上重点」 |
| **问的是哪件事**：能读到什么程度？学什么？这次考不考得上？ | 八字看程度和方向，六壬看这一场 | 用八字回答「明年考研能不能上」 |
| **全日制还是在职**？ | 2.3：在职学历盘上另有样子 | 把在职本科断成「没学历」 |
| **文科还是理科、什么专业**？ | 2.4：方向要对上 | 学医的断成「学法律」 |
| **问学历是为了什么**：找工作、考公、出国、面子？ | 2.8：学历只是一个名 | 断出名校就许诺「将来大富贵」 |

## 六、读完这一篇，你能断什么

1. **用什么字看学历**：印、食伤、官杀（为我所用）、财（制重印时）。
2. **读到什么程度**：看对学历星「用的度」——一本、重点、二本、专科、初中。
3. **在职学历**：穿两次就算正式。
4. **学什么**：木火文、金水理；申酉法律、戌亥数学、丑玄学……
5. **爱不爱学**：年上劫财伤官调皮；比劫多不爱学；印禄相随好学习。
6. **几个文凭**：控制几个印就几个文凭。
7. **看哪一柱**：年柱中小学、月柱大学以后，时柱的印多半是店铺。
8. **学历之后**：学历只是一个名，别顺手断富贵。
9. 六壬看**这一场考试**：干为考生、支为考场；禄马扶会登科，刑害俱骈不第。

**还断不了的**（资料未讲）：八字里考试的应期；新高考选科；职业资格证；分数名次和录取学校。
