# 断事图 · 人生年龄表：什么事一般在几岁发生——断应期前先对一遍

> **为什么要这一篇**：老师说过，**算不了认知以外的命**。断应期最离谱的错，不是推错了哪一年，而是**推出来的那一年在现实里不可能发生这件事**：给 15 岁断结婚，给 70 岁断升处长，给 8 岁断开车撞人。资料也要求「**要结合地域风俗**」〔婚姻篇 p11〕；小任说得更直：「**八字即生活**：断出来跟生活不符就是错了——**先读博士再读小学是不可能的**」〔小任 · 初中级第7课（课时11）〕。这一篇是一把**年龄尺**：盘上推出应期以后，拿来对一遍。
>
> **这一篇和别篇不一样**：不讲一件事，讲**所有事的时间**。它跨所有分类，每次断盘都用得上。
>
> **这一篇分四部分**：
> **一、常识**：一辈子的大事一般在几岁（这部分是常识，不是命理规则）
> **二、八字的时间刻度**：宫位大限、大运流年、哪段看哪柱（出自资料，逐条带出处）
> **三、合起来用**：人生大事 × 常见年龄 × 盘上看哪里（速查表）
> **四、怎么核对**
>
> ⚠️ **读法**：年龄是**大致、多数人**的情况，城乡、年代、个人都有差别。资料的规则逐条带出处；表里「盘上看哪里」一栏只摆资料讲过的，没讲的写「资料未讲」。

## 一、常识：一辈子的大事在几岁

### 1.1 上学

| 阶段 | 一般年龄 |
|---|---|
| 幼儿园 | 3–6 岁 |
| 小学 | 6–12 岁 |
| 初中 | 12–15 岁 |
| 中考 | 15 岁左右 |
| 高中 | 15–18 岁 |
| **高考** | **18 岁左右** |
| 大学本科 | 18–22 岁 |
| 研究生 | 22–25 岁；博士再加 3–5 年 |
| 成人学历、在职读书 | 任何年龄（资料里有「56 岁的本科生」〔【题440】〕） |

### 1.2 工作与事业

| 事 | 一般年龄 |
|---|---|
| 参加工作 | 18–25 岁（看学历） |
| 换工作最频繁 | 25–35 岁 |
| 创业多见 | 25–45 岁 |
| 体制内科级 | 多在 30 岁上下 |
| 处级 | 多在 40 岁上下 |
| 厅级 | 多在 45–55 岁 |
| 事业顶峰 | 40–55 岁 |
| **退休** | 正在逐步延迟：**男约 60→63 岁，女约 50/55→55/58 岁**（2025 年起渐进实施） |

### 1.3 感情与婚姻

| 事 | 一般年龄 |
|---|---|
| 早恋 | 中学 13–18 岁 |
| 恋爱多见 | 18–30 岁 |
| **法定婚龄** | **男 22 岁、女 20 岁** |
| 初婚 | 现在多在 **25–30 岁**，城市更晚；农村更早 |
| 离婚多发 | 婚后 3–10 年；另有 45–55 岁「中年离婚」 |
| 再婚 | 30–50 岁多见 |

### 1.4 生育与子女

| 事 | 一般年龄 |
|---|---|
| 头胎 | 多在 25–32 岁 |
| 高龄产妇 | 35 岁以上 |
| 女性生育能力明显下降 | 35 岁以后，40 岁以后更难 |
| 绝经 | 45–55 岁 |
| 孩子上学、高考 | 父母 30–50 岁之间 |
| 孩子结婚 | 父母 50–60 岁之间 |
| 抱孙子 | 50–65 岁 |

### 1.5 钱与房

| 事 | 一般年龄 |
|---|---|
| 第一次买房 | 25–35 岁 |
| 房贷还清 | 45–60 岁 |
| 收入高峰 | 35–50 岁 |
| 继承家产 | 父母去世时，一般自己 45–65 岁 |

### 1.6 健康

| 年龄 | 常见 |
|---|---|
| 0–6 岁 | 先天病、意外 |
| 7–18 岁 | 近视、意外、青春期心理 |
| 18–40 岁 | 意外、心理、胃病 |
| 40–60 岁 | **三高、癌症开始多、更年期** |
| 60 岁以后 | 心脑血管、癌症、骨折、痴呆 |

详见「疾病」「意外」「寿元」篇。

### 1.7 父母和长辈

| 事 | 一般在自己几岁 |
|---|---|
| 父母比自己大 | 20–35 岁 |
| 父母退休 | 自己 25–40 岁 |
| 父母生大病 | 自己 35–55 岁 |
| **父母去世** | 多在自己 **40–65 岁**（父母寿命一般 75–85 岁） |
| 祖父母去世 | 多在自己 10–40 岁 |

⭐ **跟断命有关的一点**：断「父母早亡」要先算一下——父母 50 岁前去世才算早；自己 50 岁时父母去世是正常的。

## 二、八字的时间刻度（出自资料）

### 2.1 三层结构

> 「一般来讲，**原局定层次，大运定吉凶，流年定应期**。」〔初级班 p51〕
> 「**命中没有的事，大运来了也不算！**」〔2012面授 p55〕
> ⭐ 「**应期次序：原局大限 → 大运 → 流年**；大限是区间，断应期允许 ±1–2 岁」〔初中级课时笔记11 p2〕

### 2.2 宫位大限：四柱各管一段

**粗分（一柱 18 年）**〔v课 · 第 677 讲〕：

| 柱 | 年龄段 |
|---|---|
| 年柱 | **0–18** |
| 月柱 | **19–36** |
| 日柱 | **37–54** |
| 时柱 | **54 以后** |

**细分（一字 9 年，先天后地）**〔公开课课时笔记3 p2；初中级课时笔记3、11〕：

| 柱 | 天干 | 地支 |
|---|---|---|
| 年 | 1–9 | 9–18 |
| 月 | 18–27 | 27–36 |
| 日 | 36–45 | 45–54 |
| 时 | 54–63 | 63–72（晚年统参时柱） |

⚠️ 另有一套「年 1–16／月 17–32／日 33–48／时 49 以后」〔初中级课时笔记7 p2〕——**孤例，照录不用**。

### 2.3 哪件事主看哪段

> 「**学业主看年月，事业主看月日，婚姻主宫日支但月柱极关键**（婚配黄金期）」〔初中级课时笔记11 p2〕

| 事 | 主看 | 对照常识 |
|---|---|---|
| 学业 | 年、月（0–36） | 1.1 上学到研究生都在这段 ✔ |
| 事业 | 月、日（19–54） | 1.2 工作到顶峰 ✔ |
| 婚姻 | 日支为宫，**月柱（19–36）极关键** | 1.3 初婚 25–30 ✔ |
| 晚年、子女 | 时柱（54 以后） | 1.4 子女成家、抱孙 ✔ |

### 2.4 年柱的事＝少年的事

| 规则 | 出处 |
|---|---|
| ⭐ **年上桃花是正常恋爱，不是婚外情**——年柱对应少年时期 | v课 705、687 讲 |
| 「年上伤官应晚婚」——但伤虚就不晚 | 婚姻篇 p11【题240】 |
| 「财星或财库在少年宫位又被合动 ⇒ **早恋**」 | 讲义 p53–54 |
| 「正财在时柱就断晚婚，**太死板**」——相合之字互带象，可被带到年上 | 小任 · 初中级第07课 |

### 2.5 大运、流年

| 规则 | 出处 |
|---|---|
| ⭐ **断年一律按交节**（立春，不是元旦也不是春节） | 第12章七 |
| ⭐ **进气退气**：前一运后三年有下一运的气进，下一运前三年前一运的气在退；换运精确到月 | 【题498】 |
| 「**人不过六十不论寿命**」 | 寿元门歌诀 |
| 「拿到八字**第一件事先判寿元**，免得把只到 40 岁的命断成『50 岁后大器晚成』」 | 小任讲义 p44 |
| 时限理论：原局两件事，**年月在前、日时在后** | 面授 p47–48【题670】 |

## 四、怎么核对

```
   盘上推出：X 事 在 Y 岁
        ↓
   ① 原局有没有这件事？（命中没有的事，大运来了也不算）
        ↓
   ② Y 岁落在哪柱大限？这件事主看那一柱吗？（2.3）
        ↓
   ③ Y 岁在现实里做这件事正常吗？（一、三的常识表）
        ↓   不正常 →
   ④ 换读法：是不是六亲的事？（父母、子女身上的事落到这一年）
              是不是同一个象的另一面？（「结婚」读成「谈恋爱」，「当官」读成「考公」）
              是不是时辰排错了？（换气、子时、交节）
        ↓
   ⑤ 还是对不上 → 照实说「这一年有动静」，不硬套事名
```

⭐ **举例**：盘上 16 岁有「配偶星入宫」——16 岁不会结婚，按 2.4 读成**早恋**；盘上 70 岁「官星得力」——70 岁不会升官，读成**子女有出息**或**受表彰、名气**（官杀虚透表示名气〔官运篇原则〕）。

⭐ ③ 的依据是「**八字即生活**：断出来跟生活不符就是错了」〔小任 · 初中级第7课〕。
⚠️ **④ 是推演**：「换读法」是我把资料里「年上桃花是正常恋爱」「同一个作用在不同问题下吉凶相反」〔第16章第0步〕这些规则推开来用的，**资料只说「不符就是错了」，没讲错了以后怎么换读法**。

## 五、读完这一篇，你能做什么

1. 推出应期后，**拿年龄尺对一遍**，现实里不可能的就换读法。
2. 会用**宫位大限**（一柱 18 年、一字 9 年）先定粗，再用大运流年定细。
3. 知道**学业看年月、事业看月日、婚姻月柱关键**。
4. 知道「人不过六十不论寿命」「先判寿元」。

**资料未讲**：年龄对不上以后怎么换读法（四·④ 是推演）；退休、更年期的专门象。
